### 5. 추가 수정 내역 (제미나이 검색 회피 방지)
- **문제 현상:** 생성된 프롬프트를 제미나이 등 AI에 복사하여 붙여넣었을 때, AI가 웹 검색 기능을 실행하지 않고 기존 12번 규칙을 핑계로 "최신 조사는 확인되지 않았습니다"라고 대답하며 회피하는 문제 발생.
- **해결 방안:**
  - 프롬프트 시작 부분에 `[명령: 답변을 생성하기 전에 반드시 웹 검색(Web Search) 도구를 먼저 실행하여 최신 통계를 찾아볼 것]` 트리거 추가.
  - 검색 지침 항목을 `[웹 검색 도구 강제 실행]`으로 강화.
  - 기존 12번 항목을 삭제하고, `[검색 회피 금지]` 항목으로 대체하여 최소 3회 이상 다양한 키워드로 충분히 검색한 뒤에 판단하도록 강제.
- **검증:** `python3 scripts/build.py` 정상 빌드 성공 확인 완료.

### 6. 2차 추가 수정 내역 (옵션 칩 오인식 버그 픽스)
- **문제 현상:** `[웹 검색 도구 강제 실행]` 등의 대괄호 문구가 파서에 의해 옵션 칩(interactive chip)으로 오인식되어 화면에 렌더링되는 UI 버그 발생.
- **해결 방안:** 
  - `event-budget-calculator.md` 본문의 강조용 대괄호 기호(`[ ]`)를 굵은 글씨(`** **`)와 🚨 이모지로 전면 교체하여 파싱 엔진이 옵션으로 잘못 해석하지 않도록 수정함.
- **검증:** 정상 빌드 완료.
