# 사진으로 레시피 찾기 기능 및 UI 개선 작업 로그

## 작업 내용
1. **마크다운 렌더러(base.py) 수정**
   - 기존 `![]()` 마크다운 문법이 `<img>` 태그가 아닌 텍스트로 깨지는 버그 수정.
   - `#lightbox` 옵션 추가: 이미지 alt 텍스트에 `#lightbox`가 포함될 경우, 빌드 시점(Python 렌더러)에서 자동으로 래퍼(Wrapper)와 파란색 라운딩 다운로드 버튼 HTML을 구워 넣도록 정적 생성 아키텍처 도입.

2. **UI/UX 개선**
   - 다운로드 버튼 색상을 블루 계열(`var(--color-primary)`)로 변경하고, 원형 디자인(`border-radius: 50%`) 및 그림자 효과를 주어 세련되게 수정 (`site.css`).
   - JS 렌더링 의존성 제거 (`image-lightbox.js`): DOM을 동적으로 생성하는 로직을 지우고 클릭 시 모달창(라이트박스)만 띄우는 순수 이벤트 관리 역할로 경량화.

3. **프롬프트 내용 및 안내 문구 개선**
   - 1단계 재료 인식 프롬프트의 결과가 2단계로 부드럽게 이어지도록 개선.
   - 2단계 시작 시 **"새 채팅에서 시작"** 하라는 안내 멘트와 경고문구(⚠️) 삽입.
   - 2단계 프롬프트 내에 사용자가 재료 목록을 복사해 넣기 쉽도록 마크다운 엔진의 옵션 칩 문법(`"[텍스트]"`) 적용.
   - 3단계 레시피 작성 프롬프트에서 조리 순서를 "시간, 불의 세기, 조리 과정을 포함한 타임테이블 형식"으로 출력하도록 요구사항 고도화.

4. **샘플 이미지 변경**
   - 기존의 외국 스타일 예제 이미지를, 훨씬 더 친숙하고 한국적인 기본 냉장고 형태(반찬통, 대파, 양파, 고추장 등)의 이미지로 새로 생성하여 교체함.
   - 이미지 파일명을 가독성을 위해 직관적으로 변경 (`fridge-various-ingredients.png`, `fridge-korean-basic.png`, `fridge-chatgpt-generated.png`).

## 검증 결과
- `build.py` 정상 완료 및 정적 배포용 `dist/` 빌드 확인 완료.
- 로컬 브라우저 검증을 통해 다운로드 버튼 표시 및 라이트박스 팝업 정상 작동 교차 확인 완료.
- 비밀키(Secret) 노출 사항 없음 (Pre-scan for secret leakage 통과).

# 신규 프롬프트 한 스푼 메뉴 6종 추가 (마케팅 프롬프트 범용화)

마케팅 진단용 프롬프트를 일반 사용자도 활용할 수 있도록 '프롬프트 한 스푼' 메뉴에 6종의 정적 프롬프트(`static-prompt`) 페이지를 추가합니다.

1. **먼저 진단받기 ⭐** (`diagnose-first.md`)
2. **내가 놓친 부분 찾기** (`find-missing.md`)
3. **어디에서 문제가 생겼는지 찾기** (`find-problem.md`)
4. **상대방 입장에서 다시 보기** (`change-perspective.md`)
5. **반대 의견 들어보기** (`listen-opposing.md`)
6. **결과물 다양하게 재활용하기** (`reuse-content.md`)
