# AI Learning Studio Default

이 문서는 AI Learning Studio의 기본 교육용 테마 원본입니다.
비개발자도 읽고 수정할 수 있도록 설명은 자연어로 적고, 실제 생성기는 아래의 표준 섹션과 토큰 블록만 읽습니다.

## Colors

배경, 표면, 텍스트, 강조색을 정의합니다.

```theme-tokens
background = #F3F1ED
surface = #FFFFFF
surface-muted = #EAE7E1
text-primary = #202124
text-secondary = #4F5358
text-muted = #73777C
border = #D7D3CC
accent = #355C7D
accent-hover = #294A67
focus = #2F6FED
success = #2E7D4F
warning = #A86400
danger = #B3261E
```

## Typography

본문과 제목, 숫자, 줄 간격의 기본 스타일을 정의합니다.

```theme-tokens
font-family-sans = Pretendard, "Noto Sans KR", "Apple SD Gothic Neo", sans-serif
font-size-xs = 0.75rem
font-size-sm = 0.875rem
font-size-md = 1rem
font-size-lg = 1.125rem
font-size-xl = 1.5rem
font-size-2xl = 2rem
font-weight-regular = 400
font-weight-medium = 500
font-weight-semibold = 600
line-height-tight = 1.3
line-height-normal = 1.6
line-height-relaxed = 1.8
```

## Spacing

페이지 안쪽 여백과 요소 사이 간격을 정의합니다.

```theme-tokens
space-0 = 0
space-1 = 0.25rem
space-2 = 0.5rem
space-3 = 0.75rem
space-4 = 1rem
space-5 = 1.25rem
space-6 = 1.5rem
space-8 = 2rem
space-10 = 2.5rem
space-12 = 3rem
space-16 = 4rem
```

## Radius

카드, 버튼, 입력 요소의 모서리 곡선을 정의합니다.

```theme-tokens
radius-sm = 0.375rem
radius-md = 0.625rem
radius-lg = 1rem
radius-pill = 999px
```

## Shadow

기본 음영과 강조 음영을 정의합니다.

```theme-tokens
shadow-sm = 0 1px 2px rgba(0, 0, 0, 0.08)
shadow-md = 0 8px 24px rgba(0, 0, 0, 0.10)
```

## Layout

콘텐츠 폭, 내비게이션 폭, 페이지 좌우 여백, 헤더 높이를 정의합니다.

```theme-tokens
content-max-width = 1200px
navigation-width = 280px
page-gutter = 24px
header-height = 64px
```
