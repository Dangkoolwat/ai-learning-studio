# 프롬프트 단계별 체험하기

좋은 프롬프트는 처음부터 완성되지 않습니다.

짧은 요청에서 시작해 필요한 정보를 하나씩 추가하고, 
AI의 답변을 확인하며 수정하는 과정을 반복하면 내 목적에 맞는 하나의 프롬프트가 완성됩니다.

이곳에서는 프롬프트를 외우는 것이 아니라, 직접 만들어 가는 과정을 단계별로 체험합니다.

## 프롬프트는 어떻게 완성될까요?

대부분의 작업은 다음과 같은 순서로 발전합니다.

1. 간단한 요청으로 시작합니다.

2. AI의 역할을 정합니다.

3. 상황과 목적을 알려 줍니다.

4. 필요한 조건을 추가합니다.

5. 원하는 결과 형식을 지정합니다.

6. 부족한 부분을 수정하고 보완합니다.

7. 내 목적에 맞는 최종 프롬프트를 완성합니다.

## 이곳에서 배우는 것

- 짧은 요청이 어떻게 달라지는지 비교하기
- 조건을 추가할수록 결과가 어떻게 바뀌는지 확인하기
- AI와 여러 번 대화하며 결과를 개선하는 방법 익히기
- 하나의 완성된 프롬프트를 만드는 과정 체험하기

## 실습 안내

아래 실습은 모두 같은 주제를 단계별로 발전시키는 방식으로 진행됩니다.

처음에는 간단한 요청으로 시작하고, 필요한 정보를 하나씩 추가하면서 최종 프롬프트를 완성해 보세요.

각 단계에서 왜 결과가 달라지는지 직접 비교해 보면 프롬프트의 원리를 자연스럽게 이해할 수 있습니다.
