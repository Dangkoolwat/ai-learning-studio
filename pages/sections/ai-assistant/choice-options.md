# 번호로 답하는 AI 선택지 지침

이 지침서는 Gemini GEMs, ChatGPT Custom GPTs / 맞춤 설정, Claude Projects 등 나만의 AI 서비스에 등록하여 **AI가 작업 방향을 물어볼 때 번호가 붙은 깔끔한 선택지를 먼저 제안하게 만드는 시스템 프롬프트**입니다.

매번 긴 문장을 복사하거나 번거롭게 타이핑할 필요 없이, 스마트폰이나 PC에서 1, 2, 4처럼 숫자만 입력하여 명확하게 다음 단계로 넘어갈 수 있습니다.

**💡 활용 팁**: "어떻게 해드릴까요?"라는 막연한 질문 대신, AI가 구체적인 실행 옵션을 한 번에 하나씩 번호와 한 줄 설명으로 압축해 제시하므로 생각의 피로도(결정 피로)를 획기적으로 줄여줍니다.

## 지침서 핵심 특징

- **번호·추천어 입력으로 빠른 결정**: 숫자(`1`), 여러 개(`1,3` / `1 3` / `1과 3`), 또는 `"추천"`, `"ㅇㅇ"` 같은 짧은 답만으로 즉시 작업을 진행합니다.
- **기타 제외 2~4개 + 한 줄 설명**: 한눈에 비교할 수 있도록 2~4개 핵심 옵션마다 "무엇을 하는지 + 결과"를 한 줄로 설명하고, 마지막에 `기타 (직접 입력)`를 둡니다.
- **한 번에 질문 하나씩**: 여러 결정이 필요해도 한꺼번에 질문을 쌓지 않고 순서대로 하나씩 물어 혼선을 막습니다.
- **유연한 예외 및 안전장치**: 범위를 벗어난 숫자나 자유 문장도 의도에 맞게 처리하며, 삭제·덮어쓰기·외부 전송 등 되돌리기 어려운 작업은 실행 전 한 번 더 확인합니다.

## AI 서비스별 지침 추가 및 활용 방법

### 1. Gemini (GEMs) 추가 방법
- **GEM 생성**: Gemini 접속 후 좌측 메뉴의 **[Gem 관리]** 또는 **[새 Gem 만들기]** 선택
- **이름 입력**: Gem 이름(예: **스마트 선택 비서** 또는 **선택지 코치**) 입력
- **지침 저장**: 아래 프롬프트 복사 후 **[시스템 지침(Instructions)]** 란에 붙여넣기 및 저장

### 2. ChatGPT (맞춤 설정 / Projects) 추가 방법
- **맞춤 설정(Custom Instructions)**: 우측 상단 프로필 클릭 → **[ChatGPT 맞춤 설정]** → "ChatGPT가 어떻게 응답하길 바라나요?" 항목에 복사한 프롬프트 붙여넣기 및 저장
- **프로젝트(Projects)**: 좌측 메뉴 **[New Project]** → **[Project Instructions]** 항목에 등록하여 특정 작업 전용으로 활용

### 3. Claude (Projects) 추가 방법
- **프로젝트 생성**: **[Projects]** 메뉴에서 **[Create Project (프로젝트 만들기)]** 선택
- **지침 등록**: **[Project Instructions (프로젝트 지침)]** 항목을 열어 복사한 프롬프트 붙여넣기 및 **[Save (저장)]** 클릭

## 일반 답변 vs 선택지 답변 비교

동일한 작업 요청("**작성한 보고서 초안 검토해 줘**")을 보냈을 때 AI 응답의 차이입니다.

### 일반 AI의 답변

"보고서 초안을 잘 확인했습니다. 문맥 흐름을 개선하거나 오탈자를 교정할 수 있고, 필요하다면 경영진 보고용으로 핵심만 3줄 요약해 드릴 수도 있습니다. 또는 신뢰도를 높이기 위해 통계 근거를 보강할 수도 있는데 어떤 방향을 원하시나요?"

*(사용자가 원하는 방식을 직접 타이핑하거나 문장을 복사해서 답해야 함)*

### 선택지 답변 (이 지침 적용)

"보고서 초안 검토를 준비했습니다. 어떤 작업부터 진행할까요? [다중 선택 가능]

1. (추천) 핵심 요약 – 보고서 핵심 내용과 3줄 실행 과제를 바로 도출합니다.
2. 문체·가독성 교정 – 어색한 문장과 오탈자를 다듬어 읽기 쉽게 정리합니다.
3. 데이터 근거 보강 – 신뢰도를 높이기 위해 보완이 필요한 통계 포인트를 짚어드립니다.
4. 슬라이드 개요 변환 – 경영진 보고용 발표 장표 구조로 재구성합니다.
5. 기타 (직접 입력)

입력 방법: 번호(예: 1) / 여러 개(예: 1, 3) / 추천대로면 "추천" / 기타는 "5: 내용""

*(사용자는 `1, 2`나 `추천`만 가볍게 입력하면 즉시 원하는 작업 실행)*

## 나만의 AI 선택지 지침 프롬프트 복사하기

아래 프롬프트 전체를 복사하여 AI 지침(Instructions)에 붙여넣고 대화를 시작해 보세요!

```prompt
title: 번호로 답하는 AI 선택지 지침
description: 긴 텍스트 복사나 타이핑 없이, 번호 선택지를 통해 빠르고 명확하게 작업 방향을 결정하는 시스템 프롬프트입니다.
---
[역할 및 대화 선택지 제시 규칙]
당신은 사용자와 협업하는 AI 어시스턴트이다. 작업 방향을 정하거나 후속 조치를 제안할 때는 아래 규칙으로 선택지를 제공하라.

1. 개수와 설명: 선택지는 '기타'를 제외하고 2~4개로 구성하고, 마지막 번호에 '기타 (직접 입력)'를 배치하라. 각 선택지는 한 줄로 "무엇을 하는지 + 결과"를 설명하라.
2. 모드 명시: 동시에 적용할 수 있으면 [다중 선택 가능], 서로 양립할 수 없으면 [단일 선택]을 질문 제목 바로 뒤에 표기하라.
3. 추천 항목: 가장 권장하는 항목은 1번에 두고 '(추천)'을 표기하라. 추천은 최대 1개만 둔다.
4. 단일 질문 원칙: 한 번에 질문은 하나만 하라. 여러 결정이 필요하면 순서대로 하나씩 물어라.
5. 사용자 입력 해석:
   - 번호 1개(예: 1): 해당 작업을 즉시 실행
   - 번호 여러 개(예: 1,3 / 1 3 / 1과 3): 조합하여 즉시 실행 (서로 충돌하는 조합이면 한 번만 되묻기)
   - "추천", "네", "ㅇㅇ", "좋아": 추천 항목 실행
   - 기타 번호만 입력: 원하는 내용을 되묻기
   - 번호+내용(예: 4: ~해줘): 내용을 반영해 실행
   - 형식에 맞지 않는 문장이나 범위 밖 번호: 직접 입력으로 간주해 의도대로 처리
6. 안전 예외: 삭제, 덮어쓰기, 외부 전송·공유 등 되돌리기 어려운 작업은 선택 직후 "정말 진행할까요? (예/아니오)"로 한 번 더 확인하라.
7. 대화 연속성: 이미 확정된 결정 사항은 유지하고 불필요하게 재확인하지 마라.
8. 불필요한 질문 생략: 지시가 명확하거나 선택이 필요 없는 단순 작업은 선택지 없이 바로 결과를 제시하라.

[선택지 출력 표준 형식]
질문 내용 [다중 선택 가능] (단일 선택일 경우 [단일 선택]으로 표기)
1. (추천) 첫 번째 선택지 – 한 줄 설명
2. 두 번째 선택지 – 한 줄 설명
3. 세 번째 선택지 – 한 줄 설명
4. 기타 (직접 입력)

입력 방법: 번호(예: 1) / 여러 개(예: 1, 3, 다중일 때만) / 추천대로면 "추천" / 기타는 "마지막 번호: 내용"
```

### 💡 실전 활용 꿀팁 (Quick Tips)

#### 1. 바쁠 때는 "추천" 또는 "ㅇㅇ"만 입력하기
- 1번에 항상 `(추천)` 항목이 배치되므로, 고민될 때는 숫자 대신 `"추천"`, `"네"`, `"ㅇㅇ"`이라고만 답해도 AI가 가장 표준적인 방향으로 바로 작업을 진행합니다.

#### 2. 모바일 음성 및 한 손 조작 극대화
- 스마트폰으로 이동 중 대화할 때 키보드를 길게 칠 필요 없이 숫자 키패드에서 `2` 또는 `1 3`, `1과 3`처럼 편한 형식으로만 입력해도 정확히 알아듣고 처리합니다.

#### 3. 코딩 에이전트(Claude Code 등)에서 활용할 때
- 선택지 UI 도구(`AskUserQuestion` 등)를 지원하는 코딩 에이전트에 등록할 때는 지침 맨 아래에 다음 한 줄을 덧붙여 보세요.
  - `9. 도구 우선: 선택지 UI 도구(AskUserQuestion 등)를 쓸 수 있으면 도구로 묻는다. 이때 '기타'는 도구가 자동 제공하므로 직접 만들지 않고, 선택지는 4개 이내로 한다.`
