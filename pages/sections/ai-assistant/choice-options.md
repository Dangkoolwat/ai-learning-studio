# 번호로 답하는 AI 선택지 지침

이 지침서는 Gemini GEMs, ChatGPT Custom GPTs / 맞춤 설정, Claude Projects 등 나만의 AI 서비스에 등록하여 **AI가 작업 방향을 물어볼 때 번호가 붙은 깔끔한 선택지를 먼저 제안하게 만드는 시스템 프롬프트**입니다.

매번 긴 문장을 복사하거나 번거롭게 타이핑할 필요 없이, 스마트폰이나 PC에서 1, 2, 4처럼 숫자만 입력하여 명확하게 다음 단계로 넘어갈 수 있습니다.

**💡 활용 팁**: "어떻게 해드릴까요?"라는 막연한 질문 대신, AI가 구체적인 실행 옵션을 3~5개로 압축해 번호와 함께 제시하므로 생각의 피로도(결정 피로)를 획기적으로 줄여줍니다.

## 지침서 핵심 특징

- **번호 입력으로 빠른 결정**: 번호만 입력(2)하거나 복수 선택(1, 3)하여 신속하게 지시를 완료합니다.
- **선택지 3~5개 압축**: 한눈에 파악할 수 있도록 3~5개 이내의 핵심 옵션만 추려서 제시합니다.
- **단일/다중 모드 즉시 파악**: 질문 제목에 [단일 선택] 또는 [다중 선택 가능]을 표기하여 고민할 필요가 없습니다.
- **추천 항목 가이드**: 가장 표준적이거나 유용한 선택지에 (추천)을 붙여 빠른 결정을 돕습니다.
- **자유 입력(기타) 지원**: 마지막 번호는 항상 기타 (직접 입력)로 열려 있어 필요한 추가 요구사항을 덧붙일 수 있습니다.

## AI 서비스별 지침 추가 및 활용 방법

### 1. Gemini (GEMs) 추가 방법
- **GEM 생성**: Gemini 접속 후 좌측 메뉴의 **[Gem 관리]** 또는 **[새 Gem 만들기]** 선택
- **이름 입력**: Gem 이름(예: **스마트 선택 비서** 또는 **선택지 코치**) 입력
- **지침 저장**: 아래 프롬프트 복사 후 **[시스템 지침(Instructions)]** 란에 붙여넣기 및 저장

### 2. ChatGPT (맞춤 설정 / Projects) 추가 방법
- **맞춤 설정(Custom Instructions)**: 우측 상단 프로필 클릭 → **[ChatGPT 맞춤 설정]** → "ChatGPT가 어떻게 응답하길 바라나요?" 항목에 복사한 프롬프트 붙여넣기 및 저장
- **프로젝트(Projects)**: 좌측 메뉴 **[New Project]** → **[Project Instructions]** 항목에 등록하여 특정 작업 전용으로 활용

### 3. Claude (Projects) 추가 방법
- **프로젝트 생성**: **[Projects]** 메뉴에서 **[Create Project (프로젝트 만들기)]** 선택
- **지침 등록**: **[Project Instructions (프로젝트 지침)]** 항목을 열어 복사한 프롬프트 붙여넣기 및 **[Save (저장)]** 클릭

## 일반 답변 vs 선택지 답변 비교

동일한 작업 요청("**작성한 보고서 초안 검토해 줘**")을 보냈을 때 AI 응답의 차이입니다.

### 일반 AI의 답변

"보고서 초안을 잘 확인했습니다. 문맥 흐름을 개선하거나 오탈자를 교정할 수 있고, 필요하다면 경영진 보고용으로 핵심만 3줄 요약해 드릴 수도 있습니다. 또는 신뢰도를 높이기 위해 통계 근거를 보강할 수도 있는데 어떤 방향을 원하시나요?"

*(사용자가 원하는 방식을 직접 타이핑하거나 문장을 복사해서 답해야 함)*

### 선택지 답변 (이 지침 적용)

"보고서 초안 검토를 준비했습니다. 어떤 작업부터 진행할까요? [다중 선택 가능]

1. (추천) 핵심 요약 및 3줄 실행 과제 도출
2. 맞춤법·문맥 다듬기 및 가독성 개선
3. 신뢰도를 위한 데이터·통계 보강 포인트 제시
4. 경영진 보고용 슬라이드 개요로 재구성
5. 기타 (직접 입력)

선택 방법: 1 (단일) | 1, 2 (다중) | 5: [요청 내용]"

*(사용자는 1, 2만 가볍게 입력하면 즉시 원하는 작업 실행)*

## 나만의 AI 선택지 지침 프롬프트 복사하기

아래 프롬프트 전체를 복사하여 AI 지침(Instructions)에 붙여넣고 대화를 시작해 보세요!

```prompt
title: 번호로 답하는 AI 선택지 지침
description: 긴 텍스트 복사나 타이핑 없이, 번호 선택지를 통해 빠르고 명확하게 작업 방향을 결정하는 시스템 프롬프트입니다.
---
[역할 및 대화 선택지 제시 규칙]
당신은 사용자와 협업하는 AI 어시스턴트이다. 사용자와 대화하면서 작업 방향을 정하거나 후속 조치를 제안할 때는 항상 다음 규칙을 엄격히 적용하여 선택지를 제공하라.

1. 선택지 개수: 한눈에 파악할 수 있도록 3~5개 이내(마지막 기타 항목 포함)로 번호를 매겨 제시하라.
2. 모드 판단 및 명시: 여러 선택지를 동시에 적용할 수 있으면 [다중 선택 가능], 서로 양립할 수 없는 배타적 선택이면 [단일 선택]으로 제한하고 질문 제목 바로 뒤에 반드시 표기하라.
3. 추천 항목: 가장 표준적이거나 권장하는 항목이 있다면 해당 번호 뒤에 '(추천)'을 표기하라.
4. 기타 입력: 마지막 번호는 항상 '기타 (직접 입력)' 항목으로 배치하라.
5. 사용자 입력 해석:
   - 숫자 단일 입력(예: 1): 해당 번호의 작업을 즉시 실행
   - 숫자 다중 입력(예: 1, 3): 선택된 번호들의 작업을 모두 조합하여 즉시 실행
   - 직접 입력(예: 4: 원하는 내용 또는 번호+내용): 사용자의 추가 요청을 반영하여 즉시 실행
6. 대화 연속성: 이전에 확정된 결정 사항은 그대로 유지하며, 불필요한 재확인 질문을 반복하지 마라.
7. 불필요한 질문 생략: 사용자의 지시가 명확하거나 선택이 필요 없는 단순 작업인 경우에는 선택지를 만들지 말고 즉시 결과를 제시하라.

[선택지 출력 표준 형식]
질문 내용 [다중 선택 가능] (단일 선택일 경우 [단일 선택]으로 표기)
1. (추천) 첫 번째 선택지
2. 두 번째 선택지
3. 세 번째 선택지
4. 기타 (직접 입력)

선택 방법 안내:
- 단일 선택: 1
- 다중 선택: 1, 3 (단일 선택일 경우 이 줄 생략)
- 기타 입력: 4: 원하는 내용 직접 입력
```

### 💡 실전 활용 꿀팁 (Quick Tips)

#### 1. 바쁠 때는 추천 번호 하나만 입력하기
- 어떤 옵션을 골라야 할지 고민될 때는 주저하지 말고 `(추천)`이 붙은 번호(예: `1`)만 입력하세요. AI가 가장 표준적이고 안전한 작업 방식을 알아서 적용해 줍니다.

#### 2. 모바일 음성 및 한 손 조작 극대화
- 스마트폰으로 이동 중 대화할 때 키보드를 길게 칠 필요 없이 숫자 키패드에서 `2` 또는 `1, 3`만 탭하여 즉시 지시할 수 있습니다.

#### 3. 옵션을 조합하여 완성도 높이기
- 다중 선택 모드(`[다중 선택 가능]`)일 때는 `1, 4`처럼 요약과 표 정리를 동시에 선택해 보세요. AI가 두 요구사항을 결합하여 완성도 높은 결과물을 만들어 냅니다.
