# 군더더기 없이 바로 핵심만

이 지침서는 Gemini GEMs, ChatGPT Custom GPTs / 맞춤 설정, Claude Projects 등 나만의 AI 서비스에 등록하여 **불필요한 서론과 장황한 설명을 걷어내고, 묻는 말의 핵심과 지금 실행할 행동을 바로 제시하는 AI**를 만드는 시스템 프롬프트입니다.

**💡 활용 팁**: 질문할 때마다 "짧게 말해줘", "코드만 줘"라고 매번 덧붙일 필요 없이, 시스템 지침에 한 번 등록해 두면 모든 대화의 기본 호흡이 군더더기 없는 실행 모드로 고정됩니다.

## 지침서 핵심 특징

- **서론 건너뛰기**: "좋은 질문입니다" 같은 의례적인 인사나 긴 배경 설명 없이, 필요한 명령어·코드·수정 위치부터 바로 확인합니다.
- **결정 피로 줄이기**: 한 번에 수십 가지 할 일을 늘어놓지 않고, 지금 집중할 3단계 이하의 핵심 행동으로 좁혀 줍니다.
- **다음 행동의 명확화**: 답변 맨 끝에 2분 안에 손댈 수 있는 구체적인 행동 하나만 남겨, 고민 없이 바로 작업에 착수하게 돕습니다.
- **정교한 예외 처리**: 설명이나 상담 요청에는 결론부터 제시하고, 보안·안전 단계는 생략하지 않으며, 모르는 정보는 지어내지 않고 먼저 묻습니다.

## AI 서비스별 지침 추가 및 활용 방법

### 1. Gemini (GEMs) 추가 방법
- **GEM 생성**: Gemini 접속 후 좌측 메뉴의 **[Gem 관리]** 또는 **[새 Gem 만들기]** 선택
- **이름 입력**: Gem 이름(예: **핵심 비서** 또는 **다이렉트 코치**) 입력
- **지침 저장**: 아래 프롬프트 복사 후 **[시스템 지침(Instructions)]** 란에 붙여넣기 및 저장

### 2. ChatGPT (맞춤 설정 / Projects) 추가 방법
- **맞춤 설정(Custom Instructions)**: 우측 상단 프로필 클릭 → **[ChatGPT 맞춤 설정]** → "ChatGPT가 어떻게 응답하길 바라나요?" 항목에 복사한 프롬프트 붙여넣기 및 저장
- **프로젝트(Projects)**: 좌측 메뉴 **[New Project]** → **[Project Instructions]** 항목에 등록하여 특정 작업 전용으로 활용

### 3. Claude (Projects) 추가 방법
- **프로젝트 생성**: **[Projects]** 메뉴에서 **[Create Project (프로젝트 만들기)]** 선택
- **지침 등록**: **[Project Instructions (프로젝트 지침)]** 항목을 열어 복사한 프롬프트 붙여넣기 및 **[Save (저장)]** 클릭

## 일반 답변 vs 핵심 답변 비교

동일한 작업 요청("**프로젝트에 테스트 도구 설치하고 실행하는 방법 알려줘**")을 보냈을 때의 차이입니다.

### 일반 AI의 답변

"테스트는 소프트웨어의 안정성을 지키는 데 매우 중요합니다.

자바스크립트 생태계에서는 Vitest와 Jest가 널리 쓰이고 있습니다.

Jest는 오랜 기간 검증된 도구이며, Vitest는 최신 번들러 환경과 호환성이 뛰어납니다.

만약 빠른 빌드를 원하신다면 Vitest를 추천합니다. 설치를 진행하시려면 아래 명령어를 입력해 보세요..."

*(장황한 설명 끝에 스크롤을 내려야 명령어가 나옴)*

### 핵심 답변 (이 지침 적용)

1. 터미널에서 테스트 도구를 설치합니다:
   ```bash
   npm install -D vitest
   ```

2. package.json 파일의 scripts 항목에 테스트 명령을 추가합니다:
   ```json
   "test": "vitest"
   ```

**다음 행동 (2분 컷)**: 설치가 끝나면 터미널에 **npm test**를 입력하고 첫 실행 결과를 확인해 보세요.

5. 명령어, 경로, 사실을 임의로 추측해 지어내지 말라. 필요한 정보가 없으면 추측하지 말고 먼저 물어보라.

요청: "[여기에 작업 요청 입력]"

### 💡 실전 활용 꿀팁 (Quick Tips)

#### 1. 생각이 복잡할 때 대처법
- **질문부터 하나씩 요청**: 어디서부터 손대야 할지 막막할 때는 요청 끝에 "질문부터 하나씩 던져줘"라고 덧붙여 보세요. AI가 한꺼번에 많은 내용을 쏟아내는 대신, 내가 답할 수 있는 질문을 하나씩 건네며 보폭을 맞춰 줍니다.

#### 2. 다음 단계가 부담스러울 때 대처법
- **더 작게 쪼개기 요청**: AI가 제시한 다음 행동이 2분 안에 끝내기 버겁게 느껴진다면 바로 "더 작게 쪼개줘"라고 요청하세요. 당장 망설임 없이 시작할 수 있는 아주 작은 단위로 다시 나누어 줍니다.

#### 3. 기획과 실행의 모드 분리
- **단계별 역할 분담**: 아이디어를 넓히거나 방향을 고민하는 기획 단계에서는 일반 대화 모드로 편하게 브레인스토밍하고, 코드를 짜거나 문서를 정리하는 실행 단계에 들어설 때 이 지침을 적용하세요.
