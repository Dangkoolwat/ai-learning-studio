# 누구나 쉽게 이해하는 건축 분석 도우미 (바로 써보기)

현대 건축, 전통 한옥, 랜드마크, 미술관·박물관, 종교 건축 등 **어떤 건축물이든 건축가와 건축물 정보만 입력하면 AI가 양식, 공간 구성, 재료, 구조, 동선, 빛과 그림자, 시대적 배경, 현장 감상 포인트까지 맞춤 분석**해 주는 완성형 프롬프트입니다. 현장 사진이나 도면 링크 등의 추가 자료를 함께 제공하면 더욱 정밀한 분석이 가능합니다.

원하는 분석 조건(범위, 수준, 목적, 형식, 추가 자료)을 선택하고 건축가와 건축물명을 입력한 뒤, **[프롬프트 복사]** 버튼을 눌러 AI에게 질문해 보세요.

```prompt
# 건축물 한 곳 분석하기

아래 건축물을 분석해 줘.

## 건축물
- 건축물 정보: "[건축가 - 건축물명]"

## 분석 설정
- 분석 범위: [전체 분석 / 양식·외관 중심 / 공간·동선 구조 중심 / 재료·시공 구조 중심 / 빛·환경 연출 중심 / 역사·도시 맥락 중심]
- 설명 수준: [일반인이 이해하기 쉽게 / 아주 쉽게 / 조금 깊게]
- 분석 목적: [답사·여행 감상 / 건축·공간 공부 / 실무·설계 참고 / 도슨트·답사 가이드 / 답사 보고서·수행평가]
- 결과 형식: [항목별 설명 + 핵심 요약 / 표 중심 / 핵심만 간단히]
- 추가 자료: [없음 / 현장 사진 업로드 / 도면·웹 링크 첨부 / 메모·질문 입력]

## 분석 요청

먼저 입력한 건축물의 유형(주거, 미술관·박물관, 종교시설, 상업·복합공간, 공공건축, 전통 고건축 등)과 기본 양식을 파악해 줘.

모든 건축물에 같은 기준을 억지로 적용하지 말고, 해당 건축물의 유형과 시대적 특성에 따라 중요한 분석 요소를 선택하고 비중을 조절해 줘.

선택한 분석 범위가 `전체 분석`이라면 다음 항목을 참고해서 이 건축물에 의미 있는 내용을 중심으로 분석해 줘.

### 1. 건축 양식과 전체적인 인상
- 어떤 건축 사조나 양식(모더니즘, 포스트모더니즘, 해체주의, 전통 양식 등)의 특징이 나타나는지
- 외관(파사드)과 전체적인 형태(매스)에서 느껴지는 분위기를 3~5개의 단어로 표현
- 그런 분위기를 만드는 주요 조형적 요소

### 2. 공간 구성과 사용자·관람객 동선
- 공간의 배치(평면 및 단면 구성)와 층별 조닝의 특징
- 진입로에서부터 내부로 이어지는 사용자 또는 관람객의 이동 동선과 시선의 변화
- 열린 공간(보이드, 아트리움 등)과 닫힌 공간의 대비와 비례감

### 3. 구조 방식과 주요 건축 재료
- 핵심 구조 방식(철근 콘크리트, 철골, 목구조, 조적조 등)의 특징
- 주요 외장재 및 내장재(유리, 노출콘크리트, 목재, 석재, 벽돌, 금속 등)의 질감과 조화
- 재료와 구조가 공간의 감각적 분위기에 미치는 영향

### 4. 자연광과 조명 (빛과 그림자)
- 창호, 개구부, 천창(탑라이트) 등을 통해 자연광을 끌어들이는 방식
- 건물의 방향, 창호 배치, 위치 등 확인 가능한 정보를 바탕으로 자연광이 들어오는 방식을 설명
- 시간대와 계절에 따른 빛의 변화가 자료나 공간 조건으로 판단 가능한 경우 그 특징을 설명
- 인공조명 설계가 야간 경관이나 내부 분위기에 미치는 효과

### 5. 주변 환경 및 도시 맥락
- 대지(사이트)의 지형과 입지 조건을 활용한 방식
- 주변 자연경관이나 도시 맥락과의 조화(또는 파격적인 대비)
- 지역 사회에서 랜드마크로서 수행하는 역할과 공공성

### 6. 시대적 배경과 건축 철학
- 건립 당시의 역사적·사회적 요구와 시대적 배경
- 건축가의 핵심 설계 철학과 문제의식 (공식 기록이나 신뢰할 수 있는 자료로 확인되는 경우에만 설명)
- 널리 받아들여지는 건축 비평적 평가가 있다면 그 근거와 함께 설명

### 7. 이 건축물에서 특히 중요한 특징
- 위 항목에 포함되지 않더라도 이 건축물을 이해하거나 감상하는 데 중요한 특징이 있다면 추가해 줘. (예: 친환경·에너지 설계나 새로운 공법, 독창적인 공간 실험, 건축사적 의의 등)
- 위 예시에 억지로 맞추지 말고 해당 건축물에서 실제로 중요한 요소를 선택해 줘.

### 8. 현장에서 직접 볼 때의 감상 포인트
- 실제로 그 공간을 방문했을 때 놓치지 말고 눈여겨봐야 할 뷰포인트, 시선의 변화, 디테일 3가지를 알려줘.
- 각 항목은 건축을 잘 모르는 사람도 현장에서 쉽게 찾아보고 체감할 수 있게 설명해 줘.

### 9. 핵심 정리
- 마지막에는 이 건축물의 공간적 개성과 경험을 만드는 데 중요한 핵심 요소 3가지를 골라 짧게 정리해 줘.

## 분석 범위 적용
선택한 분석 범위가 `전체 분석`이 아니라면 선택한 영역을 중심으로 분석하고, 이해에 꼭 필요한 다른 요소만 간단히 덧붙여 줘.

- `양식·외관 중심`: 건축 사조, 형태와 파사드, 입면 디자인과 첫인상 중심
- `공간·동선 구조 중심`: 평면 배치, 이동 동선, 시선의 흐름, 공간의 분할과 연결 중심
- `재료·시공 구조 중심`: 구조 공법, 주요 내외장재의 물성과 질감, 디테일 마감 중심
- `빛·환경 연출 중심`: 자연광 유입, 천창과 창호, 빛과 그림자의 공간감 연출 중심
- `역사·도시 맥락 중심`: 건립 배경, 대지와 도시 환경의 조화, 건축사적 의미 중심

## 설명 수준 적용
- `일반인이 이해하기 쉽게`: 전문적인 건축 용어가 없어도 공간의 매력을 직관적으로 이해할 수 있게 설명
- `아주 쉽게`: 건축 용어를 최소화하고 일상적인 표현과 쉬운 비유를 사용
- `조금 깊게`: 건축 설계 및 도시 이론 용어를 적절히 사용하면서 원리와 미학적 특징까지 설명

전문 용어를 사용할 때는 선택한 설명 수준에 맞게 뜻을 함께 풀어 줘.

## 분석 목적 적용
선택한 목적에 따라 설명의 초점을 조절해 줘.

- `답사·여행 감상`: 실제 현장을 방문했을 때 공간의 디테일을 깊이 있게 체험할 수 있는 포인트 중심
- `건축·공간 공부`: 구조 방식, 공간 구성 원리, 환경 설계 등의 실제 적용 사례 중심
- `실무·설계 참고`: 평면 구성, 매스 스케일, 재료 매칭, 디테일 마감 등 설계에 참고할 요소 중심
- `도슨트·답사 가이드`: 관람객에게 공간의 숨은 매력과 스토리를 흥미롭게 전달할 수 있는 해설 중심
- `답사 보고서·수행평가`: 공간 분석과 방문 소감을 체계적이고 논리적인 문장으로 엮어내는 글쓰기 중심

## 결과 형식 적용
- `항목별 설명 + 핵심 요약`: 분석 항목별로 설명한 뒤 마지막에 핵심 내용을 정리
- `표 중심`: 주요 분석 내용을 보기 쉬운 표로 정리하고 필요한 설명만 덧붙임
- `핵심만 간단히`: 중요한 특징과 감상 포인트만 짧게 정리

## 추가 자료 적용
- 사용자가 제공한 현장 사진, 도면 발췌, 건축 관련 웹페이지나 공식 자료 링크, 메모 등의 추가 자료가 있는 경우 해당 AI가 직접 접근하거나 분석할 수 있는 자료는 우선 참고해 줘.
- 자료에 접근할 수 없거나 내용을 직접 확인할 수 없는 경우에는 확인한 것처럼 말하지 말고, 확인할 수 없다고 알려 줘.
- 추가 자료가 없으면 건축물 정보와 사용할 수 있는 검색 기능, 신뢰할 수 있는 자료를 바탕으로 확인 가능한 범위에서 분석해 줘.

## 분석 원칙
- 건축가, 건립 연도, 위치(주소), 규모, 용도처럼 사실 확인이 필요한 정보는 가능하면 신뢰할 수 있는 공인 자료로 먼저 확인한 뒤 분석해 줘.
- 입력한 건축물명이 불완전하거나 동명의 건축물이 여러 개 있어 대상을 특정하기 어렵다면, 임의로 선택하지 말고 먼저 어떤 건축물인지 확인해 줘.
- 입력한 건축물명이 실제 등록된 명칭과 조금 다르지만 어떤 건축물인지 명확하게 확인할 수 있다면, 정확한 명칭과 위치를 먼저 알려 준 뒤 분석을 진행해 줘.
- 평면도·단면도나 신뢰할 수 있는 건축 자료를 확인하지 못한 경우, 사진이나 외관만 보고 내부 공간 구성이나 동선을 확정적으로 설명하지 마.
- 구조 방식, 시공법, 상세 재료처럼 외관만으로 확인하기 어려운 정보는 추측하지 말고, 신뢰할 수 있는 자료에서 확인되지 않으면 '확인 필요'라고 표시해 줘.
- 건축가의 설계 의도는 인터뷰, 공식 도록, 작품집 등 신뢰할 수 있는 자료로 확인되는 경우에만 설명하고, 확인되지 않은 내용은 추측해서 단정하지 마.
- 주요 건축 비평적 평가와 일반 방문자의 다양한 주관적 감상을 구분해 줘.
- 해당 건축물에 적용되지 않는 요소(예: 한옥에 노출콘크리트 분석 등)는 억지로 끼워 맞춰 설명하지 마.
```

   - 유명 건축물이나 문화재는 건축가와 건축물명을 입력하면 공개된 건축 정보와 확인 가능한 자료를 바탕으로 분석할 수 있습니다.
   - 현장에서 직접 촬영한 사진(외관, 천장, 창가 등)이나 배치도, 건축 관련 웹페이지나 공식 자료 링크가 있다면 AI 채팅창에 함께 붙여넣고 `추가 자료` 옵션을 선택해 보세요. AI가 링크나 자료를 직접 확인할 수 있는 경우, 해당 공간의 시각적 특징을 우선 분석합니다.

2. **분석 범위와 결과 형식을 조합해 보세요**
   - **빠른 핵심 파악**: `분석 범위: 전체 분석` + `결과 형식: 핵심만 간단히`
   - **한눈에 보는 비교 정리**: `분석 범위: 전체 분석` + `결과 형식: 표 중심`
   - **공간·디자인 스터디**: `분석 범위: 공간·동선 구조 중심` 또는 `재료·시공 구조 중심` + `분석 목적: 건축·공간 공부`

3. **💬 더 깊은 분석을 위한 '이어서 질문하기' 예시**
   - 기본 분석을 받은 뒤, 아래 문장을 그대로 복사해서 AI에게 추가 질문해 보세요.

   **🏛️ 건축·공간 설계 & 인테리어 스터디**
   - 이 건축물에 쓰인 주요 내외장재의 매칭 방식과 마감 디테일의 특징을 분석해 줘. 건축가의 의도가 공식 자료로 확인된다면 함께 설명해 줘.
   - 진입로부터 메인 홀까지 사용자의 시선과 발걸음을 유도하는 동선 설계 기법을 설명해 줘.
   - 빛과 그림자를 극대화하기 위해 천창이나 창호를 설계한 방식을 공간감 측면에서 분석해 줘.
