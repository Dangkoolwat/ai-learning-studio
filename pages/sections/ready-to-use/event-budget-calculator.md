# 상황에 맞는 경조사비 결정 프롬프트 (바로 써보기)

필요한 조건을 선택해 맞춤형 경조사비 결정 프롬프트를 만들어 보세요.

```prompt
title: 맞춤형 경조사비 결정 프롬프트
description: 본문 텍스트 내의 파란색 칩을 클릭해 원하는 조건을 선택하세요.
---
🚨 **명령: 답변을 생성하기 전에 반드시 웹 검색(Web Search) 도구를 먼저 실행하여 최신 통계를 찾아볼 것** 🚨

경조사비를 얼마로 정하고 어떤 방식으로 마음을 전해야 할지 고민하고 있어.

아래 상황을 바탕으로 나와 비슷한 조건의 최신 국내 조사와 공식 자료를 검색한 뒤, 사회적 경향과 상대방과의 관계, 나의 경제적 부담을 함께 고려해 현실적인 선택을 추천해 줘.

경조사비에는 모두에게 적용되는 하나의 정답이 있는 것처럼 말하지 말고, 최신 조사 결과는 최근 사회적 경향을 살펴보는 참고자료로 활용해 줘.

## 상황 입력

- **경조사 종류**: [결혼 / 장례 / 출산·돌 / 회갑·칠순 / 개업 / 승진·퇴직 / 기타]
- **상대방과의 관계**: [가족 / 가까운 친척 / 일반 친척 / 가까운 친구 / 일반 친구 / 친한 직장 동료 / 같은 부서 동료 / 다른 부서 동료 / 직장 상사 / 직장 후배 / 거래처 관계자 / 지인 / 직접 입력]
- **평소 교류 정도**: [매우 자주 연락함 / 가끔 연락함 / 직장이나 모임에서만 만남 / 최근에는 거의 연락하지 않음 / 직접 입력]
- **참석 또는 방문 여부**: [직접 참석·방문 / 참석하지 못하고 마음만 전달 / 아직 결정하지 못함]
- **마음을 전하는 방식**: [현금 / 계좌이체 / 단체로 전달 / 선물 / 화환·화분 / 현금과 선물 함께 / 아직 결정하지 못함]
- **행사장(예식장 등) 수준**: [일반 예식장(대중적 수준) / 호텔 등 고가 / 공공·종교 시설 / 잘 모르겠음 / 해당 없음]
- **동반 인원**: [혼자 참석 / 2명 참석 / 가족과 참석 / 해당 없음]
- **식사 여부**: [식사함 / 식사하지 않음 / 아직 모름 / 해당 없음]
- **과거에 받은 경조사비 또는 도움**: [받은 적 없음 / 받은 금액이 있음 / 금액은 모르지만 도움을 받음 / 해당 없음 / 직접 입력]
- **직장이나 모임의 분위기**: [정해진 기준이 있음 / 주변 사람들과 비슷하게 맞추는 편 / 특별한 기준 없음 / 잘 모르겠음]
- **현재 경제적 부담**: [여유 있음 / 보통 / 다소 부담됨 / 많이 부담됨]
- **법적 제한 확인 필요 여부**: [일반적인 개인 관계 / 공직자·교직원·언론인 등과 관련 있음 / 업무상 이해관계가 있음 / 잘 모르겠음]
- **추가로 고려할 상황**: "[예: 최근에 큰 도움을 받음, 여러 경조사가 겹침, 개인이 아닌 부서 이름으로 전달함, 선물도 함께 준비함]"

## 경조사별 추가 확인

선택한 경조사 종류에 따라 필요한 조건을 추가로 살펴봐 줘.

- **결혼**: 참석 여부, 식사 여부, 동반 인원, 예식장 수준, 과거에 주고받은 축의금
- **장례**: 직접 조문 여부, 고인과의 관계, 유가족과의 관계, 개인 또는 단체 조의 여부
- **출산·돌**: 행사 참석 여부, 현금과 선물 중 적절한 방식, 가족과의 관계
- **회갑·칠순**: 행사 참석 여부, 가족 또는 지인 관계, 현금과 선물을 함께 준비하는지
- **개업**: 직접 방문 여부, 화환·화분·선물을 별도로 제공하는지, 개인 또는 업무 관계
- **승진·퇴직**: 개인 또는 단체 전달 여부, 현금보다 선물이 자연스러운 관계인지
- **기타**: 해당 경조사의 성격과 일반적인 전달 방식을 먼저 확인

판단에 꼭 필요한 정보가 빠졌다면 임의로 추측하지 말고, 가장 중요한 질문을 한 번에 하나씩 물어봐 줘.

## 최신 조사 및 자료 검색 원칙

1. 금액이나 전달 방식을 추천하기 전에 선택한 경조사와 관련된 최신 국내 조사와 자료를 검색해 줘. 
2. **웹 검색 도구 강제 실행**: 학습된 과거 데이터로 즉시 답변하지 말고, 반드시 실시간 웹 검색(Web Search)을 실행하여 최근 1년 이내의 관련 통계 및 뉴스 기사를 먼저 찾아봐 줘. 적합한 자료가 없다면 최근 2년까지 범위를 넓혀 줘.
3. 🚨 **검색 1순위:** 어떤 경조사이든 무조건 **'한국민속대백과사전'**을 최우선으로 검색하여 해당 행사(결혼, 장례, 돌잔치 등)의 전통적 의미와 관례(예: 돌반지, 짝수 회피 등)를 먼저 파악해 줘.
4. 그 다음으로 아래 출처를 우선 확인해 줘.
   - 신한은행 보통사람 금융생활 보고서, 주요 금융지주 연구소 통계, 인크루트 등 HR기업의 직장인 설문조사 등 공신력 있는 정기 보고서 원문 발표
   - 정부기관, 공공기관, 공식 법령 자료
   - 조사 조건과 결과를 구체적으로 인용한 주요 언론
5. 개인 블로그, 온라인 커뮤니티, 광고성 콘텐츠의 금액표는 핵심 근거로 사용하지 마.
6. 조사자료를 활용할 때는 다음 내용을 확인해 줘.
   - 조사기관
   - 조사 시기
   - 조사 대상
   - 응답자 수
   - 조사에서 가정한 상황
   - 주요 응답 결과
7. 사용자의 상황과 비슷한 조건의 자료를 우선 활용해 줘.
   - 경조사 종류
   - 상대방과의 관계
   - 참석 또는 방문 여부
   - 행사장 식사 비용 수준
   - 혼자 또는 동반 참석
   - 개인 또는 단체 전달
   - 과거에 주고받은 금액
8. 결혼식 축의금 조사를 장례식 조의금이나 다른 경조사에 그대로 적용하지 마.
9. 참석하고 식사하는 경우의 조사 결과를 참석하지 않고 송금만 하는 경우에 그대로 적용하지 마.
10. 단순 평균 금액만으로 판단하지 마. 고액 응답이 포함된 평균과 가장 많은 사람이 선택한 금액은 다를 수 있으므로 최빈 응답과 금액 분포도 함께 확인해 줘.
11. 같은 조사를 여러 언론이 인용한 경우에는 서로 다른 조사처럼 중복해 다루지 마.
12. 조사 결과가 서로 다르면 하나만 정답처럼 선택하지 말고, 조사 시기와 조건의 차이를 설명해 줘.
13. **검색 회피 금지**: 검색 도구를 사용하지도 않고 임의로 '최신 조사가 확인되지 않았다'고 답변하는 것을 엄격히 금지해. 반드시 다양한 키워드(예: 최근 축의금 통계, 신한은행 보통사람, 인크루트 경조사비 등)로 충분히 검색한 뒤에 판단해 줘. 단, 철저한 검색 후에도 정확한 자료가 없다면 그때만 '현재 상황과 정확히 일치하는 최신 자료는 없습니다'라고 밝혀 줘.
14. 검색 기능을 사용할 수 없다면 최신 자료를 확인한 것처럼 말하지 마.

## 판단 원칙

1. 최신 조사 결과뿐 아니라 상대방과의 관계, 평소 교류, 참석 여부, 과거에 주고받은 금액과 나의 경제적 상황을 함께 고려해 줘.
2. 최근 급격한 외식 물가 및 예식장 식대 상승 트렌드를 검색하여, 동반 인원과 식사 여부에 따른 민폐 논란(식대보다 적은 축의금 등)이 발생하지 않도록 현실적인 하한선을 고려해 줘.
3. 가장 적합한 선택을 먼저 추천하고, 그 이유를 쉽게 설명해 줘.
4. 사회적 체면이나 주변의 시선만을 이유로 감당하기 어려운 금액을 권하지 마.
5. 행사장 식대나 선물 가격만을 유일한 잣대로 삼지 말고 관계와 개인 형편을 종합적으로 다뤄 줘.
6. 회사나 모임에 합의된 기준이 있다면 중요한 참고사항으로 활용하되 반드시 따라야 하는 규칙처럼 표현하지 마.
7. 과거에 받은 경조사비가 확인된다면 중요한 기준으로 활용하되, 물가 상승과 현재의 참석 조건 변화 등도 함께 살펴봐 줘.
8. 화환, 화분, 선물 등을 함께 준비한다면 전체 부담을 고려해 현금 금액을 조정해 줘.
9. 승진, 퇴직, 개업 등 현금보다 선물이 자연스러운 상황이라면 무조건 현금 액수를 제시하지 말고 더 적절한 방법을 알려 줘.
10. 금액 범위를 지나치게 넓게 제시하지 말고 다음 순서로 알려 줘.
   - 가장 추천하는 금액 또는 방식
   - 부담을 줄이고 싶을 때의 선택
   - 조금 더 마음을 표현하고 싶을 때의 선택
11. 각 선택에는 금액만 적지 말고 그 선택이 적합한 조건을 함께 설명해 줘.
12. 경조사비 액수를 제안할 때는 반드시 '한국민속대백과사전' 등을 검색하여 확인한 한국의 전통적인 부조 예절도 함께 고려해 줘.
    - 특히 조의금은 일반적으로 사용하는 3만 원, 5만 원, 7만 원이나 10만 원, 20만 원, 30만 원처럼 자연스럽게 구분되는 금액을 우선 제안해 줘.
    - 특별한 이유가 없다면 4만 원, 6만 원, 8만 원처럼 짝수로 끝나는 금액이나 아홉수를 연상할 수 있는 9만 원은 일반적인 추천에서 제외해 줘.
    - 다만 이는 반드시 따라야 하는 규칙이 아니라 전통적인 관행이므로, 과거에 주고받은 금액, 회사나 모임의 합의된 기준, 단체 전달, 개인의 경제적 형편과 법적 제한이 있다면 해당 조건을 우선 고려하고 그 이유를 함께 설명해 줘.

## 법적 제한 확인

사용자나 상대방이 공직자, 교직원, 언론기관 종사자 등 법 적용 대상일 가능성이 있거나 업무상 이해관계가 있다면 다음 원칙을 적용해 줘.

- 국민권익위원회, 국가법령정보센터 등 공식 자료에서 최신 기준을 검색해 줘.
- 청탁금지법(김영란법) 시행령의 '최신 개정된' 경조사비 가액 범위(현금 및 농수산물 화환 포함 시 한도 등)를 검색하여 정확히 적용해 줘.
- 일반적인 사회통념과 법적으로 허용되는 범위를 구분해 설명해 줘.
- 단순히 상대방의 직업만으로 법 적용 여부를 확정하지 말고 직무 관련성, 관계와 전달 목적을 함께 살펴봐 줘.
- 법 적용 여부가 불분명하면 임의로 법률 판단을 확정하지 말고 공식 기관에 확인해야 할 사항을 알려 줘.
- 법적 기준을 설명할 때는 확인한 날짜와 공식 출처를 표시해 줘.
```
