# 1회용 맞춤형 한국어 교정 프롬프트 (바로 써보기)

이 페이지는 시스템 설정에 등록할 필요 없이, **글을 다듬을 때마다 필요한 조건만 바로 골라서 복사해 사용하는 1회용 맞춤형 교정 프롬프트**입니다. 

문장 안의 **파란색 칩을 클릭**하여 글의 용도, 대상, 말투를 선택한 뒤 **[프롬프트 복사]** 버튼을 눌러 AI 채팅창에 바로 붙여넣기 해보세요.

```prompt
title: 맞춤형 한국어 교정 프롬프트
description: 본문 텍스트 내의 파란색 칩을 클릭해 원하는 조건(용도, 말투 등)을 고르고 마지막에 다듬을 글을 붙여넣으세요.
---
아래 글을 다음 기준에 맞게 자연스럽게 다듬어 줘.

- 글의 용도: [블로그 / 보고서 / 메일 / 후기 / 안내문 / 자기소개서 / 발표문 / SNS 글]
- 읽는 사람: [친구 / 가족 / 직장 동료 / 상사 / 고객 / 일반 독자 / 수강생]
- 원하는 말투: [담백하게 / 친근하게 / 정중하게 / 자연스럽게 / 전문적으로 / 개인 기록처럼]
- 수정 강도: [가볍게 다듬기 / 어색한 문장만 수정 / 전체 흐름까지 정리 / 짧고 간결하게 압축]

중요 원칙:
- 원래 의미는 바꾸지 마.
- 사실, 날짜, 장소명, 이름, 금액, 수치, 고유명사는 유지해 줘.
- 원문에 없는 정보는 새로 추가하지 마.
- AI가 쓴 것 같은 과장된 표현은 줄여 줘.
- 번역투와 어색한 표현은 자연스럽게 바꿔 줘.
- 영어식 완료·진행 표현은 최대한 줄여 줘.
- 너무 문학적이거나 과하게 꾸민 문장으로 바꾸지 마.
- 확인이 필요한 정보는 확정하지 말고 “확인 필요”로 남겨 줘.
- 필요한 부분만 고치고, 전체를 불필요하게 새로 쓰지 마.

특히 줄여야 할 표현:
- “결론적으로”
- “시사하는 바가 크다”
- “주목할 만하다”
- “~를 통해”
- “~에 있어서”
- “~할 수 있다”
- “매우 중요하다”
- “효율적이고 효과적인”
- “혁신적인”
- “완벽한”

영어식 시간 표현도 줄여 줘:

한국어 글에서는 영어처럼 완료시제와 진행형을 자주 드러내지 않아도 자연스럽습니다.
아래 표현이 나오면 가능한 한 더 담백한 한국어 표현으로 바꿔 줘.

“~해왔습니다” → “~했습니다”
“~하고 있습니다” → “~합니다” / “~하는 중입니다”
“~되어 왔습니다” → “~됐습니다”
“~해오고 있습니다” → “~했습니다” / “계속했습니다”
“~할 예정입니다” → “~하려고 합니다” / “~합니다”

출력 형식:
1. 다듬은 글
2. 고친 표현 예시 3개
3. 사람이 직접 확인해야 할 항목

다듬을 글: 
"[여기에 글 붙여넣기]"
```

## 💡 활용 팁 (권장 글자 수)

AI 모델은 한 번에 수만 자 이상의 긴 글도 읽을 수 있지만, **'문장 하나하나를 세밀하게 고치는 교정'** 작업에서는 원문이 너무 길면 세세한 부분을 건너뛰는 경향이 있습니다.

또한 AI가 한 번에 답변을 출력할 수 있는 길이에 제한이 있어, 글이 너무 길면 중간에 답변이 끊길 수 있습니다.

가장 꼼꼼하고 완벽한 교정 결과를 원하신다면, 긴 글은 **한 번에 A4 용지 1~2장 분량(약 1,000자 ~ 3,000자 내외)씩 나누어서** 붙여넣고 교정받는 것을 추천합니다!
