## AI 작업 이어가기 (Universal AI Handoff Prompt)

긴 대화나 프로젝트의 핵심 맥락, 확정된 내용, 진행 상태를 작업 인계서 형태로 정리하여 ChatGPT, Gemini, Claude 등 새로운 AI나 새 대화에서도 같은 기준으로 이어서 작업할 수 있도록 만드는 범용 프롬프트입니다.

### 언제 사용하나요?
- 대화가 너무 길어졌을 때
- AI가 문맥을 놓치기 시작할 때
- 다른 AI(ChatGPT → Claude 등)로 옮길 때
- 프로젝트를 나중에 다시 이어서 작업할 때
- 중요한 작업을 기록으로 남길 때

### 특징
- **완벽한 방어막**: 새 AI가 임의로 구조를 다시 설계하지 않도록 변경 금지 항목을 강제합니다.
- **명확한 상태 태그**: 확정된 내용과 미확정 내용을 구분하여 제공합니다.
- **시행착오 기록**: 실패했던 시행착오나 금지사항을 포함해 똑같은 실수를 반복하지 않게 합니다.

# AI 작업 이어가기 (Universal AI Handoff Prompt)

지금까지 진행한 대화와 프로젝트 자료를 확인하여, 새로운 대화나 다른 AI에서도 기존 작업을 정확히 이어갈 수 있는 **프로젝트 인계 문서**를 작성해 주세요.

단순한 대화 요약이 아니라, 새 AI가 기존 결과물을 다시 설계하거나 처음부터 반복하지 않고 **현재 작업 위치에서 바로 이어서 일할 수 있는 실행 문서**를 만드는 것이 목적입니다.

---

## 핵심 원칙

1. 사용자가 가장 최근에 확정한 내용을 최우선으로 반영합니다.
2. 사용자가 확정한 내용은 임의로 변경·삭제·재해석하지 않습니다.
3. 기존 결과물을 계승하며, 더 좋은 방법이 있다는 이유로 새로 설계하지 않습니다.
4. 여러 버전이 있으면 최신 확정본을 기준으로 하고, 폐기된 이전안은 현재안과 섞지 않습니다.
5. 사실, 사용자 결정, 공식 확인 내용, AI 제안, 미확정 내용을 구분합니다.
6. 확인할 수 없는 내용은 추측하지 말고 `[확인 필요]`로 표시합니다.
7. 중요한 시행착오는 반복해서 설명하지 말고, 그 과정에서 확정된 원칙과 금지사항만 남깁니다.
8. 현재 작업과 직접 관련된 대화와 자료를 우선 확인하며, 불필요한 오래된 내용은 제외합니다.
9. 사용자가 이미 제공한 정보를 다시 질문하지 않아도 되도록 조건, 문구, 수치, 자료와 작업 상태를 구체적으로 남깁니다.
10. 새 AI가 문서 전체를 한 번만 전달받아 바로 작업을 이어갈 수 있도록 작성합니다.

---

## 내용 구분 표시

필요한 경우 다음 표시를 사용합니다.

- `[확정]` 사용자가 최종 결정한 내용
- `[사용자 제공]` 사용자가 직접 작성·조사·검증한 내용
- `[공식 확인]` 공식 자료로 확인된 내용
- `[AI 제안]` AI가 제안했지만 확정되지 않은 내용
- `[미확정]` 논의 중이거나 결정되지 않은 내용
- `[보류]` 추후 검토하기로 한 내용
- `[폐기]` 사용하지 않기로 결정한 내용
- `[확인 필요]` 자료나 사실을 추가로 확인해야 하는 내용

AI가 제안한 내용을 확정된 결정처럼 기록하지 마세요.

# 작성 및 점검 규칙

- 현재 접근할 수 있는 대화와 자료를 먼저 확인한 뒤 작성합니다.
- 접근할 수 없는 대화나 파일의 내용은 추측하지 않습니다.
- 최신 확정 내용과 폐기된 이전안을 섞지 않습니다.
- 같은 내용을 여러 항목에서 불필요하게 반복하지 않습니다.
- 작업 인계서와 새 AI 작업 지침을 별도 문서로 나누지 않습니다.
- 안내 문구나 빈 자리표시자를 최종 결과에 남기지 않습니다.
- 해당 내용이 없으면 억지로 채우지 말고 `해당 없음`으로 처리합니다.
- 프로젝트가 작으면 불필요한 항목은 간결하게 작성합니다.
- 프로젝트가 크면 핵심은 본문에 유지하고 세부 내용만 부록으로 분리합니다.
- 결과물 전체가 새 AI에 그대로 전달할 수 있는 하나의 실행 문서여야 합니다.

출력 전에 최신 확정 내용, 변경 금지 사항, 주요 자료, 현재 작업 위치와 다음 작업이 빠지지 않았는지 내부적으로 점검하세요.

## 기본 제공 방식

- 핵심 작업 인계문 전체를 하나의 코드 블록 안에 작성합니다.
- 사용자가 코드 블록의 `복사` 버튼을 한 번 눌러 전체 내용을 복사할 수 있도록 합니다.
- 코드 블록 안에 다른 코드 블록, 복잡한 표, 불필요한 장식을 넣지 않습니다.
- 모바일에서 쉽게 복사하고 붙여 넣을 수 있도록 핵심 인계문은 가능한 한 간결하게 작성합니다.
- 최신 확정 내용, 변경 금지 사항, 현재 작업 위치, 주요 자료와 다음 작업은 반드시 포함합니다.
- 반복 대화, 오래된 시행착오, 현재 작업에 필요하지 않은 세부 내용은 제외합니다.

파일은 선택 사항이며, 모바일 사용자가 반드시 내려받아야 하는 기본 결과물로 사용하지 않습니다.

## 프로젝트가 큰 경우

핵심 작업 인계문에는 새로운 AI가 바로 작업을 이어가는 데 필요한 내용만 담습니다.

당장 필요하지 않은 상세 원문, 전체 파일 목록, 긴 변경 이력과 참고 자료는 본문에 모두 넣지 않고 자료명과 위치만 남깁니다. 핵심 확정 내용은 생략하지 않습니다.

완성된 결과만 제공하고 작성 과정, 내부 검토, 추가 제안과 자체 평가는 출력하지 않습니다.
