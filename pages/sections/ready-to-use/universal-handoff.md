## AI 작업 이어가기 (Universal AI Handoff Prompt)

긴 대화나 프로젝트의 핵심 맥락, 확정된 내용, 진행 상태를 작업 인계서 형태로 정리하여 ChatGPT, Gemini, Claude 등 새로운 AI나 새 대화에서도 같은 기준으로 이어서 작업할 수 있도록 만드는 범용 프롬프트입니다.

### 언제 사용하나요?
- 대화가 너무 길어졌을 때
- AI가 문맥을 놓치기 시작할 때
- 다른 AI(ChatGPT → Claude 등)로 옮길 때
- 프로젝트를 나중에 다시 이어서 작업할 때
- 중요한 작업을 기록으로 남길 때

### 특징
- **완벽한 방어막**: 새 AI가 임의로 구조를 다시 설계하지 않도록 변경 금지 항목을 강제합니다.
- **명확한 상태 태그**: 확정된 내용과 미확정 내용을 구분하여 제공합니다.
- **시행착오 기록**: 실패했던 시행착오나 금지사항을 포함해 똑같은 실수를 반복하지 않게 합니다.

---

### 프롬프트 복사하기

아래의 프롬프트 전문을 복사하여, 현재 작업 중이던 기존 대화창에 붙여넣어 결과물을 생성하세요. 
그리고 그 출력 결과를 복사해 **새로운 대화창(또는 다른 AI)**의 첫 질문으로 입력하시면 됩니다.

```text
# 새 대화에서 작업 이어가기 프롬프트
# Universal AI Handoff Prompt

지금까지 이 대화에서 진행한 작업을 새로운 대화창이나 다른 AI 서비스에서도 이어갈 수 있도록 정리해 주세요.

이 프롬프트는 ChatGPT, Gemini, Claude 등 여러 AI 서비스에서 사용할 예정입니다.

## 목적

이전 대화의 핵심 맥락, 확정된 내용, 작업 진행 상태를 빠짐없이 정리해  
새로운 대화에서도 같은 기준과 방향으로 작업을 이어가려는 것입니다.

## 정리 원칙

1. 지금까지 여러 번 수정된 내용이 있다면 가장 최근에 확정된 내용을 우선하세요.
2. 사용자가 명확하게 확정한 내용은 임의로 삭제하거나 바꾸지 마세요.
3. 단순한 대화 요약이 아니라, 다음 AI가 바로 작업을 이어갈 수 있는 작업 인계서 형태로 작성하세요.
4. 불필요한 인사, 감정 표현, 반복 대화, 시행착오는 제외하세요.
5. 다만 시행착오에서 확정된 중요한 원칙이나 금지사항은 반드시 포함하세요.
6. 확인된 사실과 사용자의 결정, AI의 제안을 구분하세요.
7. 불확실하거나 아직 결정되지 않은 내용은 추측하지 말고 “미확정” 또는 “확인 필요”로 표시하세요.
8. 기존 자료, 문서, 파일, 링크가 작업에 중요하다면 자료명과 용도를 함께 정리하세요.
9. 다음 대화에서 다시 묻지 않아도 되도록 중요한 조건, 수치, 이름, 용어, 형식, 문체를 구체적으로 남기세요.
10. 새 대화의 AI가 임의로 전체 구조를 다시 설계하지 않도록 확정 내용과 변경 금지 항목을 분명히 적으세요.
11. (코딩/개발의 경우) 현재 다루고 있는 핵심 파일의 전체 경로(Path)와 아키텍처 구조를 반드시 명시하세요.

## 반드시 포함할 내용

### 1. 작업 개요

- 작업명:
- 작업의 배경:
- 최종 목표:
- 주요 대상:
- 최종 결과물:

### 2. 현재까지 확정된 내용

사용자가 최종적으로 확정한 내용을 주제별로 정리하세요.

- 확정된 방향
- 확정된 구조
- 확정된 문구
- 확정된 조건
- 확정된 사례와 자료
- 확정된 출력 형식
- 확정된 디자인 또는 문체

각 항목은 가능하면 아래처럼 표시하세요.

- [확정] 사용자가 명확하게 결정한 내용
- [사용자 제공] 사용자가 직접 조사하거나 작성한 내용
- [공식 확인] 공식 자료로 확인된 내용
- [미확정] 아직 선택하거나 결정하지 않은 내용
- [확인 필요] 최신 정보나 추가 검증이 필요한 내용

### 3. 작업 진행 상태

#### 완료한 작업

- 완료 항목
- 완성된 결과물
- 이미 반영된 수정사항

#### 진행 중인 작업

- 현재 작업 위치
- 작성 또는 검토 중인 부분
- 아직 마무리되지 않은 내용

#### 아직 하지 않은 작업

- 다음에 진행할 항목
- 보류된 항목
- 추가 자료가 필요한 항목

### 4. 유지해야 할 핵심 원칙

다음 작업에서도 반드시 유지해야 할 기준을 정리하세요.

- 사용자의 의도와 교육 철학
- 내용 구성 원칙
- 문체와 말투
- 사실 검증 기준
- 자료 활용 기준
- 결과물 형식
- 대상 수준
- 수정 범위

### 5. 변경하거나 삭제하면 안 되는 내용

- 사용자가 이미 확정한 내용
- 반드시 유지해야 할 구조
- 바꾸면 안 되는 문구, 수치, 이름, 일정
- 제외하기로 결정한 내용
- 다시 제안하지 않아야 할 방향
- 이전 작업에서 문제가 되었던 변경 방식

### 6. 중요 의사결정과 변경 이력

중요한 변경만 아래 형식으로 정리하세요.

- 기존안:
- 변경안:
- 변경 이유:
- 최종 결정:

단순한 문장 수정이나 사소한 시행착오는 제외하세요.

### 7. 참고 자료와 우선순위

현재 작업과 관련된 자료를 정리하세요.

- 자료명:
- 자료 유형:
- 자료의 역할:
- 우선순위:
- 참고할 부분:
- 주의할 부분:

자료가 여러 개라면 다음 기준으로 우선순위를 표시하세요.

1. 사용자가 가장 최근에 확정한 자료
2. 현재 작업과 직접 관련된 자료
3. 최종본 또는 수정본
4. 참고용 자료

### 8. 용어와 표현 기준

- 반드시 통일해야 할 용어
- 사용자가 선호하는 표현
- 피해야 할 표현
- 고유명사 표기
- 제목과 부제 작성 방식
- 문장 길이와 말투
- 기술 용어 설명 수준

### 9. 현재 해결해야 할 문제

- 현재 남아 있는 핵심 문제
- 결정이 필요한 항목
- 추가 확인이 필요한 사실
- 작업을 막고 있는 조건
- 서로 충돌하는 내용

### 10. 다음 대화에서 이어서 할 작업

다음 대화에서 가장 먼저 해야 할 작업을 순서대로 정리하세요.

1.
2.
3.

각 항목에는 아래 내용을 포함하세요.

- 작업 목적
- 사용할 기존 자료
- 유지할 확정 내용
- 예상 결과물
- 주의사항

### 11. 새 대화의 AI가 지켜야 할 작업 지침

새로운 대화에서 아래 원칙을 따르도록 작성하세요.

- 먼저 인계 내용을 이해하고 현재 상태를 파악하세요.
- 사용자가 확정한 내용을 임의로 바꾸지 마세요.
- 기존안을 새로 설계하지 말고 필요한 부분만 이어서 작업하세요.
- 변경이 필요하다고 판단하면 바로 바꾸지 말고 변경 대상, 이유, 기존안과의 차이를 먼저 설명하세요.
- 현재 요청 범위 밖의 전체 재작성은 하지 마세요.
- 이미 제공된 정보를 다시 질문하지 마세요.
- 불확실한 내용은 추측하지 말고 확인 필요로 표시하세요.
- 새로운 제안은 확정 내용과 분리해서 제시하세요.
- 결과물은 바로 사용할 수 있는 형태로 작성하세요.
- 작업 전에는 현재 요청과 확정 내용을 내부적으로 다시 확인하세요.

## 최종 출력 형식

# Part 1. AI 작업 인계서 (Handoff Document)

사람이 검토하고 보관할 수 있는 프로젝트 인계 문서를 작성하세요.

다음 순서를 유지하세요.

# AI 작업 인계서

## 1. 작업 개요
## 2. 현재까지 확정된 내용

## 4. 유지해야 할 핵심 원칙
## 5. 변경하거나 삭제하면 안 되는 내용
## 6. 중요 의사결정 및 변경 이력
## 7. 참고 자료 및 우선순위
## 8. 용어와 표현 기준
## 9. 현재 해결해야 할 문제
## 10. 다음 작업

내용은 사람이 읽기 쉽도록 명확하게 정리하세요.

# Part 2. 새 AI에 바로 붙여 넣는 프롬프트 (Ready Prompt)

위에서 작성한 작업 인계서를 바탕으로 새로운 AI가 즉시 작업을 이어갈 수 있는 완성된 프롬프트를 작성하세요.

다음 조건을 반드시 포함하세요.

- 이전 프로젝트를 이어받는 AI의 역할
- 인계서를 최우선 기준으로 사용할 것
- 가장 최근에 확정된 내용을 우선할 것
- 확정된 내용을 임의로 변경하지 말 것
- 변경이 필요하면 먼저 변경 이유와 영향을 설명할 것
- 불확실한 내용은 추측하지 말고 "확인 필요"로 표시할 것
- 현재 요청 범위만 작업하고 불필요한 전체 재작성은 하지 말 것
- 기존 자료와 문체, 구조를 유지할 것
- 새로운 제안은 기존 확정 내용과 구분해서 제시할 것
- 작업을 시작하기 전에 현재 상태를 먼저 요약하고 이해한 내용을 확인한 뒤 실제 작업을 시작할 것

Ready Prompt는 사용자가 그대로 복사하여 ChatGPT, Gemini, Claude 등 새로운 AI 서비스에 붙여 넣을 수 있는 완성된 프롬프트 형태로 작성하세요.

---

## 최종 점검

출력하기 전에 다음 사항을 확인하세요.

- 최신 확정 내용이 모두 반영되었는가
- 확정 내용과 제안이 명확히 구분되었는가
- 중요한 조건과 자료가 누락되지 않았는가
- 새 AI가 추가 설명 없이 바로 작업을 이어갈 수 있는가
- Handoff Document와 Ready Prompt가 서로 일관성을 유지하는가

만약 이전 대화 내용이 짧거나 해당되는 항목이 없다면, 억지로 내용을 만들지 말고 해당 섹션을 과감히 생략하거나 '해당 없음'으로 간결하게 처리하세요.

최종 결과만 출력하고, 작성 과정이나 판단 과정은 설명하지 마세요.
```
