# 뚝딱 완성! 맞춤 레시피 가이드 (바로 써보기)

필요한 조건을 선택해 맞춤형 레시피 프롬프트를 만들어 보세요.

```prompt
title: 맞춤형 레시피 프롬프트
description: 본문 텍스트 내의 파란색 칩을 클릭해 원하는 요리 조건을 선택하세요.
---
아래 요리 조건과 원칙에 맞춰 레시피를 작성해 줘.

### 입력 조건
- 요리 이름: "[요리 이름 입력]"
- 인원: [1명 / 2명 / 3명 / 4명]
- 먹는 사람 또는 식사 목적: [일반 / 아이와 함께 / 어르신과 함께 / 다이어트 식사 / 손님 접대용]
- 원하는 조리 시간: [15분 이내 / 20분 이내 / 30분 이내 / 1시간 이내 / 여유롭게]
- 원하는 방식: [기본 / 간단 / 저염 / 저당 / 기본·저염·저당 비교]
- 빼고 싶은 재료: "[없음]"
- 알레르기 또는 못 먹는 재료: "[없음]"
- 사용할 수 있는 조리도구: [가스레인지 / 인덕션 / 에어프라이어 / 전자레인지 / 오븐 / 모두 가능]
- 칼로리 계산: [포함 / 제외]

### 출력 형식
- 모든 내용은 마크다운(Markdown) 형식으로 가독성 좋게 작성할 것 (표, 굵은 글씨, 구분선 등을 적극적으로 활용할 것).
아래 10가지 항목을 반드시 포함하여 작성할 것:

1. 필요한 재료와 인원에 맞는 분량
2. 재료별 대체 가능한 재료
3. 재료 손질 방법
4. 단계별 조리 순서
5. 불 세기와 단계별 시간
6. 전체 조리 시간표
7. 실패하기 쉬운 부분
8. 완성 여부 확인 방법
9. 예상 영양정보
10. 건강 및 식재료 안전 안내

칼로리 계산이 ‘포함’인 경우 다음 내용을 표시할 것:

- 전체 예상 열량
- 1인분 예상 열량
- 열량 비중이 큰 주요 재료
- 열량을 줄일 수 있는 대체 방법
- 계산에 사용한 주요 재료와 분량
- 정확한 계산을 위해 추가 확인이 필요한 제품 정보

모든 수치는 ‘예상값’ 또는 ‘추정값’임을 표시할 것.

레시피를 제공한 뒤에는 반드시 다음과 같이 안내해 줘.

“준비하기 어려운 재료가 있거나 다른 재료로 바꾸고 싶다면
재료 이름을 알려 주세요.
대체 재료와 분량, 달라지는 맛과 식감,
필요한 경우 조리 순서와 시간까지 다시 조정해 드리겠습니다.”

### 칼로리 계산 원칙
(칼로리 계산이 '포함'일 경우 아래 원칙을 엄격히 적용할 것)
- 2025 한국인 영양소 섭취기준과 식품의약품안전처의 나트륨·당류 저감 관련 공식 자료와 원칙을 참고할 것.
  다만 이를 영양사가 개인의 건강 상태를 확인해 작성한 맞춤 식단이나 질환 치료식이라고 표현하지 말 것.
- 레시피에 사용한 재료와 분량을 기준으로 전체 예상 열량과 1인분 예상 열량을 계산할 것.
- 전체 예상 열량, 1인분 예상 열량, 열량 비중이 큰 주요 재료, 열량을 줄일 수 있는 대체 방법을 함께 표시할 것.
- 정확한 제품명, 중량, 조리 후 실제 섭취량이 확인되지 않은 경우에는 반드시 ‘예상값’ 또는 ‘추정값’이라고 표시할 것.
- 간장, 소스, 햄, 치즈, 면, 가공식품처럼 제품별 영양성분 차이가 큰 재료는 제품 포장의 영양정보를 확인하도록 안내할 것.
- 튀기기, 기름 추가, 소스 증량처럼 조리 과정에서 열량이 달라지는 요소도 반영할 것.
- 사용자가 인원, 재료, 분량, 조리법을 변경하면 칼로리도 함께 다시 계산할 것.
- 계산 근거가 부족한 경우에는 정확한 숫자를 임의로 만들지 말고 ‘정확한 중량 또는 제품 정보 확인 필요’라고 표시할 것.

### 이후 수정 원칙

- 사용자가 인원, 재료, 맛, 조리 시간, 조리도구 또는 요리 방식을 바꾸면
  기존 조건 중 변경하지 않은 내용은 유지할 것.
- 재료가 바뀌면 분량뿐 아니라 양념 비율, 조리 순서,
  불의 세기, 조리 시간과 예상 칼로리도 함께 다시 계산할 것.
- 조리 시간을 줄여 달라는 요청에는 숫자만 줄이지 말고,
  생략하거나 간소화할 과정과 달라지는 맛·식감을 설명할 것.
- 사용자가 “최종본으로 정리해 줘”라고 요청하면
  지금까지 수정한 내용을 반영한 하나의 완성 레시피로 다시 정리할 것.

### 반드시 확인하세요

이 레시피와 영양정보는 일반적인 조리법과 공식 영양 기준을 참고한
예시이며, 영양사가 개인의 건강 상태를 확인해 작성한 맞춤 식단은 아닙니다.

고혈압, 당뇨병, 신장질환, 심혈관질환, 알레르기 등으로
특정 영양소를 제한해야 하는 경우에는
AI의 안내만 따르지 말고 의사 또는 영양사와 확인하세요.

예상 열량과 영양성분은 재료의 종류, 제품, 실제 사용량과
조리 방법에 따라 달라질 수 있습니다.

식재료의 소비기한, 보관 상태, 부패 여부와 안전성은
사용자가 직접 확인해야 합니다.
```
