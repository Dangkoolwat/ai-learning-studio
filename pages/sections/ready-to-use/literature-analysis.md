# 문학 작품 한 편 분석하기

아래 문학 작품을 분석해 줘.

## 작품
- 작품 정보: "[작가명 - 작품명]"

## 분석 설정
- 분석 범위: [전체 분석 / 갈래·성격 중심 / 화자·시점·인물 중심 / 구성·줄거리 중심 / 표현법·문체 중심 / 시대 배경·주제 중심]
- 설명 수준: [일반인이 이해하기 쉽게 / 아주 쉽게 / 조금 깊게]
- 분석 목적: [작품 감상 / 국어·문학 공부 / 글쓰기·창작 참고 / 독서 토론 / 감상문·수행평가]
- 결과 형식: [항목별 설명 + 핵심 요약 / 표 중심 / 핵심만 간단히]
- 추가 자료: [없음 / 본문 텍스트 첨부 / 발췌문·해설 링크 첨부 / 메모·질문 입력]

## 분석 요청

먼저 입력한 문학 작품의 갈래와 기본 성격을 파악해 줘.

모든 문학 작품에 같은 기준을 억지로 적용하지 말고, 해당 작품의 갈래(현대시, 고전시가, 단편·장편소설, 고전소설, 수필, 희곡, 시나리오, 동화 등)와 특성에 따라 중요한 분석 요소를 선택하고 비중을 조절해 줘.

선택한 분석 범위가 `전체 분석`이라면 다음 항목을 참고해서 이 작품에 의미 있는 내용을 중심으로 분석해 줘.

### 1. 갈래와 전체적인 느낌
- 어떤 갈래에 속하며 어떤 문학적 성격을 지니는지
- 작품의 전체적인 분위기와 어조(말투, 태도)를 3~5개의 단어로 표현
- 그런 분위기를 만드는 주요 문학적 요소

### 2. 화자·시점 또는 인물과 갈등
- 시(운문): 시적 화자의 위치, 처한 상황, 정서와 태도
- 소설·극(서사/희곡): 서술 시점(1인칭/3인칭 등), 주요 인물의 성격, 인물 간의 핵심 갈등 구조
- 수필(교술): 글쓴이의 시선, 체험에 대한 태도와 성찰

### 3. 구성과 전개 방식
- 시: 시상의 전개 방식(시간의 흐름, 공간의 이동, 수미상관, 대립, 점층 등)
- 소설·극: 플롯 구조(발단-전개-위기-절정-결말), 사건의 흐름과 긴장감의 변화, 복선과 결말의 특징
- 수필: 글의 흐름, 일화 제시와 깨달음의 연결 방식

### 4. 표현 기법과 문체
- 두드러지는 표현 기법(비유, 상징, 반어, 역설, 감각적 심상, 대구, 도치 등)
- 운율 형성 요소나 어휘의 특징, 문장의 호흡(간결체/만연체, 대화/서술 비중 등)
- 표현 기법이 작품의 정서와 주제를 전달하는 데 어떤 역할을 하는지

### 5. 시간적·공간적 배경
- 작품의 무대가 되는 시대와 구체적인 공간적 배경
- 배경이 인물의 심리, 사건의 전개, 또는 전체적인 분위기에 미치는 영향

### 6. 시대적 배경과 주제 의식
- 창작 당시의 역사적·사회적 맥락과 문학사적 배경
- 작품에서 읽을 수 있는 주요 주제와 문제의식
- 널리 받아들여지는 해석이 있다면 그 근거와 함께 설명
- 작가의 창작 의도는 기록이나 신뢰할 수 있는 자료로 확인되는 경우에만 설명

### 7. 이 작품에서 특히 중요한 특징
- 위 항목에 포함되지 않더라도 이 작품을 이해하거나 감상하는 데 중요한 문학적 특징이 있다면 추가해 줘. (예: 독창적인 서사 기법, 파격적인 화자 설정, 문학사적 의의 등)
- 위 예시에 억지로 맞추지 말고 해당 작품에서 실제로 중요한 요소를 선택해 줘.

### 8. 다시 읽을 때의 감상 포인트
- 이 작품을 다시 읽을 때 주의 깊게 살펴보면 좋은 문장, 장면, 또는 상징적 요소를 3가지 정도 알려줘.
- 각 항목은 문학을 잘 모르는 사람도 실제로 읽으면서 찾아볼 수 있게 설명해 줘.

### 9. 핵심 정리
- 마지막에는 이 작품의 매력과 문학적 가치를 만드는 데 가장 중요한 핵심 요소 3가지를 골라 짧게 정리해 줘.

## 분석 범위 적용
선택한 분석 범위가 `전체 분석`이 아니라면 선택한 영역을 중심으로 분석하고, 이해에 꼭 필요한 다른 요소만 간단히 덧붙여 줘.

- `갈래·성격 중심`: 문학 갈래의 특징, 어조와 분위기, 전체적인 구조적 성격 중심
- `화자·시점·인물 중심`: 화자의 정서/태도, 서술 시점, 인물의 성격과 갈등 관계 중심
- `구성·줄거리 중심`: 시상 전개 방식, 소설의 플롯과 사건 전개, 구성상의 특징 중심
- `표현법·문체 중심`: 비유, 상징, 심상, 운율, 어휘 선택과 문체의 매력 중심
- `시대 배경·주제 중심`: 역사적·사회적 맥락, 작품의 핵심 주제와 문학사적 의미 중심

## 설명 수준 적용
- `일반인이 이해하기 쉽게`: 전문적인 문학 지식이 없어도 공감하고 이해할 수 있게 설명
- `아주 쉽게`: 문학 용어를 최소화하고 일상적인 표현과 쉬운 예를 사용
- `조금 깊게`: 국어·문학 이론 용어를 적절히 사용하면서 원리와 깊이 있는 해석까지 설명

전문 용어를 사용할 때는 선택한 설명 수준에 맞게 뜻을 함께 풀어 줘.

## 분석 목적 적용
선택한 목적에 따라 설명의 초점을 조절해 줘.

- `작품 감상`: 행간의 의미와 문학적 여운을 느끼며 깊이 있게 감상할 수 있는 포인트 중심
- `국어·문학 공부`: 시험이나 학업에 도움 되는 갈래적 특징, 핵심 출제 포인트, 문학 이론 적용 중심
- `글쓰기·창작 참고`: 매력적인 문체, 인물 묘사, 구성 방식, 표현법 등 창작에 참고할 요소 중심
- `독서 토론`: 다른 사람과 함께 나누어 볼 만한 논제, 인물의 선택에 대한 토론 거리 중심
- `감상문·수행평가`: 줄거리 나열을 넘어 작품의 주제와 개인적 느낀 점을 논리적으로 연결한 글쓰기 중심

## 결과 형식 적용
- `항목별 설명 + 핵심 요약`: 분석 항목별로 설명한 뒤 마지막에 핵심 내용을 정리
- `표 중심`: 주요 분석 내용을 보기 쉬운 표로 정리하고 필요한 설명만 덧붙임
- `핵심만 간단히`: 중요한 특징과 감상 포인트만 짧게 정리

## 추가 자료 적용
- 사용자가 제공한 시 본문, 소설 발췌문, 해설 링크, 메모 등의 추가 자료가 있는 경우 해당 AI가 직접 접근하거나 분석할 수 있는 자료는 우선 참고해 줘.
- 자료에 접근할 수 없거나 내용을 직접 확인할 수 없는 경우에는 확인한 것처럼 말하지 말고, 확인할 수 없다고 알려 줘.
- 추가 자료가 없으면 작품 정보와 사용할 수 있는 검색 기능, 신뢰할 수 있는 자료를 바탕으로 확인 가능한 범위에서 분석해 줘.

## 분석 원칙
- 작가, 작품명, 창작 시기, 갈래처럼 사실 확인이 필요한 정보는 가능하면 신뢰할 수 있는 자료로 먼저 확인한 뒤 분석해 줘.
- 입력한 작품명이 불완전하거나 같은 제목의 작품이 여러 개 있어 대상을 특정하기 어렵다면, 임의로 선택하지 말고 먼저 어떤 작품인지 확인해 줘.
- 입력한 작품명이 실제 등록된 제목과 조금 다르지만 어떤 작품인지 명확하게 확인할 수 있다면, 정확한 작품명을 먼저 알려 준 뒤 분석을 진행해 줘.
- 표준적인 문학사적 해석과 독자의 다양한 주관적 감상을 구분해 줘.
- 상징이나 결말의 의미에 여러 해석이 가능한 경우 하나의 정답처럼 단정하지 말고 주요 해석을 구분해 설명해 줘.
- 작가의 창작 의도는 기록이나 신뢰할 수 있는 자료로 확인되지 않았다면 추측해서 단정하지 마.

- 추가 텍스트(시 본문, 발췌문 등)가 제공된 경우 실제 텍스트에서 확인되는 표현을 우선해서 분석해 줘.
- 본문이 직접 제공되지 않은 경우, 기억에 의존해 정확하지 않은 구절을 임의로 만들어내지 말고 확인 가능한 내용 중심으로 설명해 줘.
