# 의정부 편한 길 찾기 (바로 써보기)

필요한 조건을 선택해 맞춤형 대중교통/도보 이동 경로 프롬프트를 만들어 보세요.

```prompt
title: 의정부 편한 길 찾기 프롬프트
description: 본문 텍스트 내의 파란색 칩을 클릭해 원하는 이동 조건을 선택하세요.
---
나는 의정부에 살고 있습니다.

아래 조건을 바탕으로 무릎이나 허리가 불편한 사람, 어르신, 무거운 짐이 있는 사람이 이동하기 편한 경로를 찾아 주세요.

### 이동 조건
- 출발지: "[출발 장소 입력]"
- 목적지: "[도착 장소 입력]"
- 출발 날짜와 시간: "[출발 날짜와 시간 입력]"
- 이동할 사람의 상태: [무릎이 불편함 / 허리가 불편함 / 보행이 느림 / 무거운 짐이 있음 / 휠체어 사용 / 유모차 이용]
- 계단 이용: [이용 불가 / 최대한 피하기 / 짧은 계단은 가능]
- 걷기 가능 시간: [5분 이내 / 10분 이내 / 15분 이내 / 상관없음]
- 선호 이동수단: [버스 중심 / 지하철 중심 / 버스와 지하철 조합 / 택시 일부 이용 가능 / 상관없음]
- 피하고 싶은 조건: [가파른 오르막 / 육교 / 지하보도 / 긴 환승 / 혼잡한 길 / 오래 서 있기]
- 추가 요청: "[화장실, 벤치, 엘리베이터 위치, 병원이나 약국 경유 등 필요한 내용 입력]"

### 경로 선택 원칙
1. 가장 빠른 길보다 가장 편하고 안전하게 이동할 수 있는 길을 우선해 주세요.
2. 계단, 가파른 오르막, 육교, 긴 지하보도는 최대한 피해주세요.
3. 엘리베이터, 에스컬레이터, 평지 보행로를 우선해 주세요.
4. 버스를 이용한다면 버스 번호, 승차 정류장, 하차 정류장, 정류장 수를 알려 주세요.
5. 지하철을 이용한다면 엘리베이터가 가까운 출입구와 환승 위치를 알려 주세요.
6. 버스 정류장이나 지하철 출입구까지 걷는 거리와 예상 시간을 표시해 주세요.
7. 도로 경사, 계단, 횡단보도, 육교처럼 이동이 불편할 수 있는 구간은 따로 표시해 주세요.
8. 오래 걷거나 서 있어야 한다면 중간에 앉아서 쉴 수 있는 장소를 알려 주세요.

### 최신 정보 검색 및 출처 원칙
1. 사용자가 입력한 출발 날짜와 시간을 기준으로 최신 교통 정보를 직접 검색한 뒤 경로를 제안해 주세요.
2. 다음 정보를 반드시 확인해 주세요.
   - 운행 중인 버스 번호와 노선, 승차·하차 정류장 이름 및 위치, 환승 횟수, 예상 배차 또는 도착 정보
   - 지하철·경전철 출입구와 엘리베이터 위치
   - 공사, 통제, 엘리베이터 운행 중단 등 이동에 영향을 주는 정보
3. 출처는 다음 순서로 우선 확인해 주세요: 의정부시/경기도 공식 교통 정보 → 공식 버스정보시스템 → 철도·지하철 운영기관 안내 → 최신 지도 서비스.
4. 버스 번호, 정류장, 출입구, 엘리베이터 위치처럼 실제 이동에 중요한 정보에는 출처를 함께 표시해 주세요.
5. 검색 결과끼리 내용이 다르면 한쪽을 임의로 선택하지 말고 무엇이 다른지 설명해 주세요.
6. 검색했지만 확인할 수 없는 정보는 ‘검색했으나 확인되지 않음’으로 표시해 주세요.
7. 검색 기능을 사용할 수 없는 경우에는 ‘현재 최신 정보 검색 불가’라고 분명히 밝혀 주세요.
8. 도로 경사, 보도 상태, 계단 수, 엘리베이터 고장 여부처럼 공식 자료만으로 확정하기 어려운 내용은 추측하지 마세요.
9. 출발 직전에는 사용자가 공식 버스정보나 지도 앱에서 버스 도착 시각과 엘리베이터 운행 상태를 다시 확인하도록 안내해 주세요.

### 출력 형식
- 모든 내용은 마크다운(Markdown) 형식으로 가독성 좋게 작성할 것. 설명은 길을 처음 가는 어르신도 이해할 수 있도록 짧고 쉬운 문장으로 작성하고, “몇 미터 이동”보다는 “출구를 나온 뒤 오른쪽 평지로 약 5분 이동”처럼 실제로 따라가기 쉽게 설명해 주세요.

1. 가장 편한 추천 경로
- 전체 예상 시간 / 예상 걷기 시간 / 환승 횟수 / 이 경로를 추천하는 이유

2. 단계별 이동 안내
- 현재 위치에서 어디로 이동하는지
- 이용할 버스나 지하철 (승차·하차 위치)
- 걷는 거리와 시간
- 엘리베이터 또는 에스컬레이터 위치, 계단이나 경사 여부

3. 이동이 불편할 수 있는 구간
- 위치 / 불편한 이유 / 피하거나 줄이는 방법

4. 대체 경로
- 버스 대기 시간이 길거나 엘리베이터를 이용할 수 없을 때 선택할 수 있는 다른 경로

5. 출발 전 확인할 내용
- 버스 도착 정보, 엘리베이터 운행 여부, 공사/통제 여부, 날씨, 교통카드와 짐 상태

6. 정보 확인 결과와 출처
- 확인한 날짜와 시간
- 정보별 출처 (버스 노선, 정류장 위치, 엘리베이터·출입구, 공사/통제 정보 등)
- 검색했지만 확인하지 못한 항목
```
