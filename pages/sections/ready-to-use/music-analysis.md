# 누구나 쉽게 이해하는 음악 분석 도우미 (바로 써보기)

좋아하는 대중가요, 클래식, 재즈, 록, 힙합, 국악, 영화 OST 등 **어떤 곡이든 아티스트와 곡 정보만 입력하면 AI가 장르, 리듬, 선율, 화성, 악기 구성, 감상 포인트까지 맞춤 분석**해 주는 완성형 프롬프트입니다. 유튜브 링크나 음원·영상·악보 등의 추가 자료를 함께 제공하면 더욱 정밀한 분석이 가능합니다.

원하는 분석 조건(범위, 수준, 목적, 형식, 추가 자료)을 선택하고 아티스트와 곡명을 입력한 뒤, **[프롬프트 복사]** 버튼을 눌러 AI에게 질문해 보세요.

```prompt
# 음악 한 곡 분석하기

아래 음악을 분석해 줘.

## 음악
- 곡 정보: "[아티스트 - 곡명]"

## 분석 설정
- 분석 범위: [전체 분석 / 분위기·장르 중심 / 리듬·그루브 중심 / 악기·음색 중심 / 선율·화성 중심 / 구성·전개 중심]
- 설명 수준: [일반인이 이해하기 쉽게 / 아주 쉽게 / 조금 깊게]
- 분석 목적: [음악 감상 / 음악 공부 / 연주 참고 / 작곡·편곡 참고 / 감상문·수행평가]
- 결과 형식: [항목별 설명 + 핵심 요약 / 표 중심 / 핵심만 간단히]
- 추가 자료: [없음 / 유튜브 링크 첨부 / 악보 업로드 / 음원·영상 업로드 / 가사·메모 입력]

## 분석 요청

먼저 입력한 음악의 장르와 음악적 성격을 파악해 줘.

모든 음악에 같은 기준을 억지로 적용하지 말고, 해당 곡의 장르와 특징에 따라 중요한 분석 요소를 선택하고 비중을 조절해 줘.

클래식, 재즈, 록, 팝, 발라드, 힙합, R&B, EDM, 국악, 영화음악, 연주곡 등 장르에 따라 중요한 요소가 다르다면 그 특징을 우선해서 분석해 줘.

선택한 분석 범위가 `전체 분석`이라면 다음 항목을 참고해서 이 음악에 의미 있는 내용을 중심으로 분석해 줘.

### 1. 장르와 전체적인 느낌
- 어떤 장르나 스타일의 특징이 나타나는지
- 한 가지 장르로 나누기 어렵다면 어떤 음악적 특징이 섞여 있는지
- 전체적인 분위기를 3~5개의 단어로 표현
- 그런 분위기를 만드는 주요 음악적 요소

### 2. 빠르기와 리듬
- 전체적으로 느린지, 보통인지, 빠른지
- 확인할 수 있다면 대략적인 BPM
- 박자, 리듬, 그루브, 장단 등에서 두드러지는 특징
- 리듬이 곡의 느낌에 어떤 영향을 주는지

### 3. 선율
- 멜로디의 전체적인 특징
- 반복되거나 귀에 잘 들어오는 선율적 요소
- 선율의 움직임이나 표현 방식
- 선율이 곡의 분위기에 어떤 영향을 주는지

### 4. 조성과 화성
- 조성과 화성이 중요한 음악이라면 그 특징
- 확인할 수 있다면 Key 또는 중심음
- 장조·단조의 느낌이나 특징
- 코드 진행이나 화음에서 눈에 띄는 부분
- 전문적인 화성 용어가 필요하다면 쉽게 풀어서 설명

### 5. 악기·보컬·음색
- 주요 악기 또는 소리의 구성
- 특히 두드러지는 악기와 음색
- 보컬이 있다면 음색, 창법, 표현 방식
- 전자음, 샘플링, 사운드 디자인 등이 중요하다면 함께 설명
- 각각의 소리가 전체 분위기에 어떤 역할을 하는지

### 6. 구성과 전개
- 음악이 어떤 흐름으로 진행되는지
- 반복, 변화, 대비가 나타나는 부분
- 절, 후렴, 브리지, 드롭, 악장 등 해당 장르에 맞는 구조
- 곡이 진행되면서 분위기나 에너지가 어떻게 달라지는지

### 7. 이 음악에서 특히 중요한 특징
- 위 항목에 포함되지 않더라도 이 곡을 이해하거나 감상하는 데 중요한 음악적 특징이 있다면 추가해 줘. (예: 다이내믹, 텍스처, 오케스트레이션, 즉흥연주, 플로우, 장단, 샘플링, 사운드 디자인, 연주 기법, 음악 형식)
- 위 예시에 억지로 맞추지 말고 해당 음악에서 실제로 중요한 요소를 선택해 줘.

### 8. 다시 들을 때의 감상 포인트
- 이 음악을 다시 들을 때 주의 깊게 들어보면 좋은 부분을 3가지 정도 알려줘.
- 각 항목은 음악을 잘 모르는 사람도 실제로 들으면서 찾아볼 수 있게 설명해 줘.

### 9. 핵심 정리
- 마지막에는 이 음악의 느낌과 개성을 만드는 데 가장 중요한 음악적 요소 3가지를 골라 짧게 정리해 줘.

## 분석 범위 적용
선택한 분석 범위가 `전체 분석`이 아니라면 선택한 영역을 중심으로 분석하고, 이해에 꼭 필요한 다른 요소만 간단히 덧붙여 줘.

- `분위기·장르 중심`: 장르, 스타일, 분위기와 이를 만드는 음악적 요소 중심
- `리듬·그루브 중심`: 빠르기, 박자, 리듬, 그루브, 장단 중심
- `악기·음색 중심`: 악기 구성, 보컬, 음색, 사운드 디자인 중심
- `선율·화성 중심`: 멜로디, 조성, 코드, 화성적 특징 중심
- `구성·전개 중심`: 곡의 구조, 반복, 변화, 대비, 전개 방식 중심

## 설명 수준 적용
- `일반인이 이해하기 쉽게`: 음악 지식이 없어도 이해할 수 있게 설명
- `아주 쉽게`: 전문 용어를 최소화하고 일상적인 표현과 쉬운 예를 사용
- `조금 깊게`: 음악 용어를 적절히 사용하면서 원리와 특징까지 설명

전문 용어를 사용할 때는 선택한 설명 수준에 맞게 뜻을 함께 풀어 줘.

## 분석 목적 적용
선택한 목적에 따라 설명의 초점을 조절해 줘.

- `음악 감상`: 다시 들을 때 발견할 수 있는 특징과 감상 포인트 중심
- `음악 공부`: 음악적 개념과 해당 곡에서의 실제 사용 사례 중심
- `연주 참고`: 연주 표현, 리듬, 다이내믹, 프레이징 등 연주에 참고할 요소 중심
- `작곡·편곡 참고`: 구조, 리듬, 화성, 악기 구성, 사운드와 전개 방식 중심
- `감상문·수행평가`: 곡의 특징과 느낀 점을 논리적이고 깔끔한 문장으로 정리할 수 있는 핵심 내용 중심

## 결과 형식 적용
- `항목별 설명 + 핵심 요약`: 분석 항목별로 설명한 뒤 마지막에 핵심 내용을 정리
- `표 중심`: 주요 분석 내용을 보기 쉬운 표로 정리하고 필요한 설명만 덧붙임
- `핵심만 간단히`: 중요한 특징과 감상 포인트만 짧게 정리

## 추가 자료 적용
- 유튜브 링크, 악보, 음원, 영상 파일, 가사·메모 등의 추가 자료가 제공된 경우, 해당 AI가 직접 접근하거나 분석할 수 있는 자료는 우선 참고해 줘.
- 자료에 접근할 수 없거나 내용을 직접 확인할 수 없는 경우에는 확인한 것처럼 말하지 말고, 확인할 수 없다고 알려 줘.
- 추가 자료가 없으면 곡 정보와 사용할 수 있는 검색 기능, 신뢰할 수 있는 자료를 바탕으로 확인 가능한 범위에서 분석해 줘.

## 분석 원칙
- 가능하다면 웹 검색이나 신뢰할 수 있는 자료로 곡 정보를 먼저 확인한 뒤 분석해 줘.
- 입력한 곡명이 불완전하거나 같은 제목의 곡이 여러 개 있어 대상을 특정하기 어렵다면, 임의로 선택하지 말고 먼저 어떤 곡인지 확인해 줘.
- 입력한 곡명이 실제 등록된 제목과 조금 다르지만 어떤 곡인지 명확하게 확인할 수 있다면, 정확한 곡명을 먼저 알려 준 뒤 분석을 진행해 줘.
- 해당 음악에 적용되지 않는 항목은 억지로 설명하지 마.
- 장르 특성상 더 중요한 요소가 있다면 정해진 항목보다 우선해서 설명해 줘.
- 보컬이 없는 음악에 보컬 분석을 넣는 식으로 해당하지 않는 내용을 만들지 마.
- BPM, Key, 코드, 악기 구성, 작곡·편곡 정보처럼 정확한 확인이 필요한 내용은 추측해서 사실처럼 말하지 마.
- 확인할 수 있는 정보와 음악적 해석 또는 추정을 구분해 줘.
- 확실하게 확인하기 어려운 정보는 '확인 필요'라고 표시해 줘.
- 같은 곡에 여러 버전, 편곡, 라이브 녹음 등이 있어 분석 결과가 달라질 수 있다면 그 점을 알려 줘.
- 음악적 특징에 대한 설명과 감상자의 주관적인 느낌을 구분해 줘.
```

## 💡 실전 200% 활용 팁

1. **곡명만 입력해도 충분하며, 추가 자료로 정확도를 높일 수 있습니다**
   - 유명한 대중가요나 클래식은 곡명과 아티스트명만 적어도 충분히 분석됩니다.
   - 인디 음원, 최신곡, 라이브 무대, 악보(PDF/이미지), 유튜브 링크가 있다면 AI 채팅창에 함께 첨부하고 `추가 자료` 옵션을 선택해 보세요. AI가 해당 자료를 우선 분석합니다.

2. **분석 범위와 결과 형식을 조합해 보세요**
   - **빠른 핵심 파악**: `분석 범위: 전체 분석` + `결과 형식: 핵심만 간단히`
   - **한눈에 보는 비교 정리**: `분석 범위: 전체 분석` + `결과 형식: 표 중심`
   - **악기 연주·보컬 분석**: `분석 범위: 악기·음색 중심` 또는 `리듬·그루브 중심` + `분석 목적: 연주 참고`

3. **💬 더 깊은 분석을 위한 '이어서 질문하기' 예시**
   - 기본 분석을 받은 뒤, 아래 문장을 그대로 복사해서 AI에게 추가 질문해 보세요.

   **🎸 악기 연주 & 보컬 연습**
   - 후렴구(싸비) 부분의 코드 진행을 초보자가 연주하기 쉬운 피아노/기타 코드로 풀어서 알려줘.
   - 이 곡에서 가장 두드러진 기타/베이스 리프의 주법과 리듬 타는 팁을 알려줘.
   - 보컬의 가성 전환 구간, 호흡, 발성 등 창법의 특징을 집중적으로 분석해 줘.

   **🎹 작곡·편곡 & 음악 공부**
   - 이 곡에서 긴장감을 주는 화성(텐션 코드, 전조 등)이 쓰인 구간을 쉽게 설명해 줘.
   - 드럼 비트와 베이스 라인이 어떻게 그루브를 만드는지 리듬 편곡을 분석해 줘.
   - 도입부에서 후렴으로 넘어갈 때 에너지를 끌어올리는 편곡 빌드업 기법을 알려줘.

   **📝 감상문 & 수행평가**
   - 학교 음악 수행평가 감상문으로 제출할 수 있게 500자 분량의 완성된 글로 요약해 줘.
   - 음악을 잘 모르는 사람에게 이 곡의 매력을 1분 동안 구두로 소개하는 대본을 짜줘.

   **🎧 심층 감상 & 추천**
   - 이 곡과 비슷한 화성 진행이나 분위기를 가진 국내외 추천 곡 3곡을 알려줘.
   - 원곡과 다른 매력을 느낄 수 있는 대표적인 편곡/라이브 버전의 차이점을 설명해 줘.
