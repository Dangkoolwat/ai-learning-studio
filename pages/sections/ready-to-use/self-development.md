# 자기 개발 학습 계획 프롬프트

새로운 분야를 공부하고 싶지만 어디서부터 어떻게 시작해야 할지 막막할 때 활용하기 좋은 프롬프트입니다.
본인의 직업, 목표, 현재 수준, 투자할 수 있는 시간을 선택하거나 직접 입력해 보세요.

## 문장 속에서 바로 고르기

- 프롬프트 본문 문장 안에서 바로 옵션을 고르거나 `"[공부하고 싶은 분야]"`를 눌러 직접 텍스트를 입력할 수 있습니다.
- 옵션 선택이 끝나면 하단의 **[프롬프트 복사]**를 눌러 완성된 내용을 복사하세요.

```prompt
title: 맞춤형 자기 개발 학습 계획 세우기
description: 본문 텍스트 내의 파란색 태그 칩을 클릭해 옵션을 선택하거나 목표를 직접 타이핑해 보세요.
---
나는 [직장인 / 학생 / 프리랜서]이고,
[퇴근 후 / 주말 / 아침 시간]을 활용해
"[공부하고 싶은 분야]"를 배우고 싶습니다.

목표는 [4주 안에 기초 익히기 / 자격증 준비 / 포트폴리오 만들기]입니다.
현재 수준은 [초보 / 기초 있음 / 실무 경험 있음]이고,
하루에 사용할 수 있는 시간은 [30분 / 1시간 / 주말 2시간]입니다.

아래 형식으로 정리해 주세요.
1. 4주 학습 계획표
2. 주차별 목표
3. 하루 실천 루틴
4. 필요한 준비물
5. 중간 점검 방법
6. 무리하지 않기 위한 조정 방법

조건:
- 계획은 현실적으로 작성해 줘.
- 너무 많은 분량을 한 번에 넣지 마.
- 실천이 어려운 부분은 줄일 방법도 함께 제안해 줘.
```
