# 업무 이메일 작성 프롬프트 (UX 체감 및 비교)

상황에 맞는 정중하고 또렷한 업무 이메일 초안을 다듬기 위한 **A안(라이브 태그 칩 인라인)** 및 **B안(실시간 폼 조립)** UX 비교 체감 페이지입니다.

---

## A안: 라이브 태그 하이라이트 방식 (추천 UX)

- 프롬프트 본문 문장 안의 **파란색 하이라이트 태그 칩**을 클릭하여 옵션을 고르거나 전달 내용을 직접 타이핑하세요.
- 글자 흐름을 깨지 않고 문맥 안에서 바로 적용되며, 하단의 **[프롬프트 복사]** 클릭 시 그대로 완벽하게 복사됩니다.

```prompt
title: [A안] 라이브 태그 인라인 프롬프트 (다중 선택 칩 포함)
description: 본문 텍스트 내의 파란색 태그 칩을 클릭해 단일/다중 옵션을 선택하거나 타이핑해 보세요.
---
당신은 베테랑 커뮤니케이션 전문가입니다.
아래 조건에 맞춰 상대방에게 정중하고 또렷하게 전달되는 업무 이메일 초안을 작성해 주세요.

[이메일 정보]
- 수신자: [팀장님 / 클라이언트 담당자 / 협력사 담당자]
- 목적: [일정 변경 안내 / 프로젝트 진행 상황 보고 / 자료 요청]
- 필요 첨부 서류: [+ 사업자등록증 / 견적서 / 통장사본 / 대표자 신분증]
- 주요 전달 항목:
  1. [첫 번째 핵심 내용]
  2. [두 번째 핵심 내용]
- 톤앤매너: [정중하고 매끄러운 톤 / 간결하고 또렷한 톤]

[작성 지침]
- 제목은 한눈에 목적을 알아볼 수 있도록 간결하게 작성하세요.
- 인사말, 본문 핵심 내용, 요청 사항, 마감 인사 순으로 정리하세요.
```

---

## B안: 상단 폼 선택 + 실시간 자동 조립 방식

- 상단 양식에서 조건과 전달 내용을 선택/입력하면, 하단 완성 카드가 실시간으로 즉시 조립되어 출력됩니다.

```prompt-field
id: recipient
label: 수신자
type: select
options: 팀장님 / 클라이언트 담당자 / 협력사 담당자
default: 팀장님
description: 이메일을 받는 상대방을 선택하세요.
```

```prompt-field
id: purpose
label: 이메일 목적
type: select
options: 일정 변경 안내 / 프로젝트 진행 상황 보고 / 자료 요청
default: 일정 변경 안내
description: 이메일의 핵심 작성 목적을 선택하세요.
```

```prompt-field
id: attachments
label: 필요 첨부 서류 (다중 선택 예시)
type: select
options: 사업자등록증 / 견적서 / 통장사본 / 대표자 신분증
default: 사업자등록증, 견적서
description: 함께 요청하거나 첨부할 서류를 선택하세요.
```

```prompt-field
id: key-points
label: 주요 전달 항목
type: text
placeholder: 예: 1. 금요일 스터디 일정 변경, 2. 장소 안내
description: 본문에 들어갈 핵심 전달 내용을 작성하세요.
```

```prompt-field
id: tone
label: 톤앤매너
type: select
options: 정중하고 매끄러운 톤 / 간결하고 또렷한 톤
default: 정중하고 매끄러운 톤
description: 이메일의 어조를 선택하세요.
```
