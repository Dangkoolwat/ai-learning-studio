```prompt
# 영화·드라마 한 편 분석하기

아래 영화·드라마 작품을 분석해 줘.

## 작품
- 작품 정보: "[감독·연출 - 작품명]"

## 분석 설정
- 분석 범위: [전체 분석 / 장르·분위기 중심 / 서사·인물 갈등 중심 / 연출·미장센 중심 / 촬영·음악 중심 / 주제·시대 배경 중심]
- 설명 수준: [일반인이 이해하기 쉽게 / 아주 쉽게 / 조금 깊게]
- 분석 목적: [작품 감상 / 영화·영상 공부 / 시나리오·연출 참고 / 영화 모임 토론 / 감상문·비평문]
- 결과 형식: [항목별 설명 + 핵심 요약 / 표 중심 / 핵심만 간단히]
- 추가 자료: [없음 / 특정 장면·구간 설명 / 예고편·영상 링크 첨부 / 메모·질문 입력]

## 분석 요청

먼저 입력한 작품의 형식(장편영화, 단편영화, 드라마 시리즈, OTT 오리지널, 애니메이션, 다큐멘터리 등)과 기본 장르를 파악해 줘.

모든 영상 작품에 같은 기준을 억지로 적용하지 말고, 해당 작품의 형식과 장르적 특성에 따라 중요한 분석 요소를 선택하고 비중을 조절해 줘.

선택한 분석 범위가 `전체 분석`이라면 다음 항목을 참고해서 이 작품에 의미 있는 내용을 중심으로 분석해 줘.

### 1. 장르와 전체적인 톤앤매너
- 어떤 장르적 문법과 스타일을 따르고 있는지 (복합 장르라면 어떻게 결합되었는지)
- 작품의 전체적인 분위기와 톤(어둡고 묵직함, 경쾌하고 유머러스함 등)을 3~5개의 단어로 표현
- 그런 분위기를 만드는 주요 시각적·청각적 요소

### 2. 서사 구조와 플롯 전개
- 서사의 전개 방식(3막 구조, 비선형적 시간 구성, 옴니버스, 에피소드 구조 등)
- 긴장감(서스펜스)의 완급 조절과 사건의 인과관계
- 복선과 반전, 결말의 연출적 특징 (결정적인 반전은 '스포일러 주의' 표시 후 설명)

### 3. 주요 인물과 갈등 관계
- 주인공의 핵심 동기(욕망)와 결핍
- 대립 인물(안타고니스트) 또는 환경과의 핵심 갈등 구조
- 인물의 내적 성장이나 입체적인 심리 변화

### 4. 연출과 미장센
- 공간 연출(로케이션, 세트 디자인)과 시대적 질감
- 의상, 분장, 주요 소품에 담긴 상징적 의미
- 작품의 시그니처가 되는 색감(컬러 팔레트)과 톤앤매너

### 5. 촬영과 조명
- 카메라 앵글, 화면 구도, 화각과 심도의 특징
- 렌즈나 촬영 장비가 신뢰할 수 있는 자료로 확인되는 경우 그 특징도 설명
- 카메라 워킹(롱테이크, 핸드헬드, 클로즈업, 트래킹 등)이 인물의 감정이나 장면의 분위기에 미치는 영향
- 조명 설계(빛과 어둠의 명암 대비, 자연광/인공광 활용 등)

### 6. 음악과 사운드 디자인
- 오리지널 스코어(OST)와 삽입곡이 장면에 미치는 감정적 효과
- 음향 효과(사운드 디자인) 및 무음(침묵)의 연출적 활용
- 소리와 침묵이 긴장감 형성에 기여하는 방식

### 7. 주제 의식과 시대적 맥락
- 제작 당시의 사회적 현실이나 인간 본성에 대한 핵심 질문
- 작품에서 읽을 수 있는 주요 주제와 문제의식
- 감독이나 작가의 의도가 공식 인터뷰나 신뢰할 수 있는 자료로 확인되는 경우 그 내용을 구분해서 설명
- 널리 받아들여지는 비평적 해석이 있다면 그 근거와 함께 설명

### 8. 다시 볼 때의 감상 포인트 (N차 관람)
- 이 작품을 다시 볼 때 눈여겨보면 좋은 숨은 디테일, 복선, 또는 연출적 명장면 3가지를 알려줘.
- 각 항목은 영화를 잘 모르는 사람도 보면서 쉽게 찾아볼 수 있게 설명해 줘.

### 9. 핵심 정리
- 마지막에는 이 작품의 완성도와 매력을 만드는 데 가장 중요한 핵심 요소 3가지를 골라 짧게 정리해 줘.

## 분석 범위 적용
선택한 분석 범위가 `전체 분석`이 아니라면 선택한 영역을 중심으로 분석하고, 이해에 꼭 필요한 다른 요소만 간단히 덧붙여 줘.

- `장르·분위기 중심`: 장르적 관습과 파격, 전체적인 톤앤매너, 작품의 첫인상 중심
- `서사·인물 갈등 중심`: 플롯의 전개, 주인공의 동기, 인물 간의 갈등과 관계 변화 중심
- `연출·미장센 중심`: 공간 미술, 의상, 소품, 컬러 톤, 시각적 상징 요소 중심
- `촬영·음악 중심`: 카메라 워킹, 조명 설계, OST와 사운드 디자인의 연출 효과 중심
- `주제·시대 배경 중심`: 사회적 맥락, 작품의 철학적 주제, 문학적·영화사적 의미 중심

## 설명 수준 적용
- `일반인이 이해하기 쉽게`: 전문적인 영화 용어가 없어도 재미있게 공감할 수 있게 설명
- `아주 쉽게`: 영화 용어를 최소화하고 일상적인 표현과 쉬운 비유를 사용
- `조금 깊게`: 영화 이론 및 연출 기법 용어를 적절히 사용하면서 원리와 미학적 특징까지 설명

전문 용어를 사용할 때는 선택한 설명 수준에 맞게 뜻을 함께 풀어 줘.

## 분석 목적 적용
선택한 목적에 따라 설명의 초점을 조절해 줘.

- `작품 감상`: 다시 볼 때 새로운 재미를 느낄 수 있는 감상 포인트와 연출의 묘미 중심
- `영화·영상 공부`: 연출 기법, 촬영 문법, 사운드 디자인 등 미학적 분석 중심
- `시나리오·연출 참고`: 로그라인, 캐릭터 설정, 갈등 유발, 복선 배치 등 창작 참고 요소 중심
- `영화 모임 토론`: 함께 본 사람들과 깊이 있게 이야기 나눌 만한 논제와 생각할 거리 중심
- `감상문·비평문`: 단순 줄거리 소개를 넘어 주제와 연출을 논리적으로 짚어내는 완성도 높은 글쓰기 중심

## 결과 형식 적용
- `항목별 설명 + 핵심 요약`: 분석 항목별로 설명한 뒤 마지막에 핵심 내용을 정리
- `표 중심`: 주요 분석 내용을 보기 쉬운 표로 정리하고 필요한 설명만 덧붙임
- `핵심만 간단히`: 중요한 특징과 감상 포인트만 짧게 정리

## 추가 자료 적용
- 사용자가 제공한 특정 장면 설명, 대사 발췌, 예고편 링크, 메모 등의 추가 자료가 있는 경우 해당 AI가 직접 접근하거나 분석할 수 있는 자료는 우선 참고해 줘.
- 자료에 접근할 수 없거나 내용을 직접 확인할 수 없는 경우에는 확인한 것처럼 말하지 말고, 확인할 수 없다고 알려 줘.
- 추가 자료가 없으면 작품 정보와 사용할 수 있는 검색 기능, 신뢰할 수 있는 자료를 바탕으로 확인 가능한 범위에서 분석해 줘.

## 분석 원칙
- 감독, 배우, 개봉/방영 연도, 수상 내역, 원작 유무처럼 사실 확인이 필요한 정보는 가능하면 신뢰할 수 있는 자료로 먼저 확인한 뒤 분석해 줘.
- 입력한 작품명이 불완전하거나 같은 제목의 작품(리메이크, 동명 영화 등)이 여러 개 있어 대상을 특정하기 어렵다면, 임의로 선택하지 말고 먼저 어떤 작품인지 확인해 줘.
- 입력한 작품명이 실제 등록된 제목과 조금 다르지만 어떤 작품인지 명확하게 확인할 수 있다면, 정확한 작품명을 먼저 알려 준 뒤 분석을 진행해 줘.
- 영화와 드라마 시리즈(회차별 호흡)의 구조적 차이를 반영해 분석해 줘.
- 드라마나 시리즈의 경우 전체 작품, 특정 시즌, 특정 회차 중 분석 대상이 명확하지 않다면 임의로 판단하지 말고 먼저 확인해 줘. 사용자가 시즌이나 회차를 지정했다면 해당 범위만 분석해 줘.
- 결말이나 핵심 반전을 언급해야 할 경우, '스포일러 주의' 문구를 명시하고 필요 이상으로 과도하게 노출하지 마.
- 감독이나 작가의 연출 의도는 인터뷰나 공식 기록으로 확인되는 경우에만 설명하고, 확인되지 않은 내용은 추측해서 단정하지 마.
- 주요 비평적 해석과 일반 관객의 다양한 주관적 해석을 구분해 줘.
- 해당 작품에 적용되지 않는 요소는 억지로 끼워 맞춰 설명하지 마.
```
