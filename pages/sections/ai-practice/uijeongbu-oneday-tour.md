# 의정부 숨은 명소 찾기

같은 주제를 여러 프롬프트 방식으로 바꾸어 봅니다.

**중요 포인트:** ‘의정부 숨은 명소로 하루 여행 코스 만들기’이라는 같은 주제를 가지고 프롬프트를 하나씩 개선해 봅니다.

이번 기본 실습에서는 아래 조건을 끝까지 유지합니다.

- 혼자 이동
- 역사·문화·예술과 관련된 장소와 도서관을 선호
- 조금 걷는 것은 괜찮음
- 가능역에서 오전 10시 출발
- 오후 6시 전까지 가능역으로 복귀
- 걷기와 대중교통 이용
- 혼자 편하게 먹을 수 있는 점심 포함
- 카페에서 쉴 시간 포함
- 전체 예산 5만 원 이내
- 유명 관광지만 나열하지 않고 의정부의 지역 분위기를 느낄 수 있는 장소 우선
- 장소의 존재 여부, 운영시간, 휴무일, 비용, 교통편은 직접 확인

## 실습 순서

1. Zero-shot Prompting: 바로 요청
2. Ask-before-answer Prompting: 먼저 질문
3. Context Prompting: 상황 추가
4. Constraint Prompting: 조건 설정
5. Output Format Prompting: 형식 지정
6. Step-by-step Prompting: 단계별 검토
7. Self-Reflection / Critique Prompting: 답변 검토
8. Prompt Chaining: 작업을 이어서 완성

---

## 1단계. 바로 요청하기

### Zero-shot Prompting

별도의 예시나 조건 없이 AI에게 원하는 일을 바로 요청하는 방식입니다.

가장 빠르게 시작할 수 있지만, 사용자의 상황과 기준이 부족하면 답변이 넓고 일반적으로 나올 수 있습니다.

```prompt
title: 1단계 예제 - 기본 제로샷 요청
description: 별도의 조건 없이 의정부의 숨은 명소를 추천해 달라고 요청합니다.
---
의정부의 숨은 명소를 추천해 줘.
```

```prompt
title: 1단계 실습 - 1일 코스 요청
description: 하루 동안 둘러볼 수 있는 코스를 만들어 달라는 조건만 추가합니다.
---
의정부의 숨은 명소를 둘러보는 1일 코스를 만들어 줘.
```

### 이번 단계에서 확인할 점

조건이 부족해서 답변이 넓고 일반적으로 나오는지 확인합니다.

AI가 유명한 장소만 나열하거나, 출발지와 이동수단을 고려하지 않은 코스를 만들 수 있습니다.

### 이번 단계 체크

- [ ] 출발 장소와 이동수단이 빠져 있다는 점을 확인했나요?
- [ ] 누구와 가는지, 무엇을 좋아하는지 반영되지 않았나요?
- [ ] 식사와 휴식 시간이 빠져 있지는 않았나요?
- [ ] 다음 단계에서 어떤 정보를 더 알려주면 좋을지 생각해 봤나요?

---

## 2단계. 답하기 전에 먼저 질문받기

### Ask-before-answer Prompting

AI가 바로 답을 만들지 않고, 더 나은 결과에 필요한 정보를 먼저 질문하게 하는 방식입니다.

처음부터 모든 조건을 완벽하게 정리하기 어려울 때 유용합니다.

```prompt
title: 2단계 예제 - 바로 코스 요청
description: 필요한 정보가 부족한 상태에서 바로 코스를 요청합니다.
---
의정부의 숨은 명소를 둘러보는 1일 코스를 만들어 줘.
```

```prompt
title: 2단계 실습 - 확인 질문 3개 요청
description: 코스를 만들기 전에 AI가 필요한 정보를 먼저 질문하게 합니다.
---
나에게 맞는 의정부 숨은 명소 1일 코스를 만들고 싶어.

바로 코스를 만들지 말고, 더 나은 계획을 위해 나에게 먼저 확인해야 할 질문을 3개만 해 줘.
```

### 이번 단계에서 확인할 점

AI가 사용자가 빠뜨린 정보를 먼저 찾아 질문하는지 확인합니다.

AI의 질문에 답하면서 동행자, 관심사, 걷기 정도 같은 조건을 자연스럽게 정리할 수 있습니다.

### 이번 단계 체크

- [ ] AI가 코스를 바로 만들지 않고 질문부터 했나요?
- [ ] 질문이 여행 계획에 필요한 내용이었나요?
- [ ] 질문에 답하면서 내 상황이 더 분명해졌나요?
- [ ] 불필요한 질문은 건너뛰거나 바꿔 달라고 요청할 수 있나요?

---

## 3단계. AI의 질문에 답하며 내 상황 알려주기

### Context Prompting

AI에게 나의 상황과 배경을 알려주는 방식입니다.

앞 단계에서 AI가 한 질문은 ChatGPT와 Gemini, 대화 내용에 따라 달라질 수 있습니다.  
정해진 답을 그대로 복사하기보다, AI가 묻는 내용에 맞춰 내 상황을 알려주는 것이 중요합니다.

AI는 내 상황을 미리 알지 못합니다. 알려 준 만큼 답변이 내 상황에 가까워집니다.

```prompt
title: 3단계 예제 - AI 질문에 짧게 답하기
description: 앞 단계에서 AI가 한 질문 가운데 하나에 내 상황을 간단히 답합니다.
---
혼자 갈 거야.
```

```prompt
title: 3단계 실습 - AI 질문에 맞춰 상황 답하기
description: AI의 질문은 달라질 수 있으므로, 질문에 맞춰 동행자와 관심사, 걷기 정도를 알려 줍니다.
---
앞에서 네가 한 질문에 차례로 답할게.

- 동행자: 혼자
- 관심사: 역사, 문화, 예술과 관련된 장소와 도서관
- 걷기 정도: 조금 걷는 것은 괜찮음

내 답변을 반영해서 의정부 숨은 명소 1일 코스를 다시 제안해 줘.
```

### 이번 단계에서 확인할 점

AI가 한 질문은 서비스와 대화에 따라 달라질 수 있습니다.

중요한 것은 질문의 문장을 똑같이 맞추는 것이 아니라, AI가 코스를 만드는 데 필요한 나의 상황을 빠뜨리지 않고 알려주는 것입니다.

같은 의정부 1일 코스라도 누구와 가는지, 무엇을 좋아하는지에 따라 추천 장소가 달라질 수 있습니다.

### 이번 단계 체크

- [ ] AI가 앞에서 한 질문에 맞춰 답했나요?
- [ ] 질문이 달라도 동행자, 관심사와 걷기 정도를 알려줬나요?
- [ ] 혼자 이동한다는 상황이 반영됐나요?
- [ ] 역사·문화·예술과 도서관이라는 관심사가 반영됐나요?
- [ ] 조금 걷는 것이 가능하다는 점이 동선에 반영됐나요?
- [ ] 알려 주지 않은 상황은 답변에 반영되기 어렵다는 점을 확인했나요?

---

## 4단계. 조건과 제한 정하기

### Constraint Prompting

반드시 지켜야 할 조건과 제한을 알려주는 방식입니다.

조건이 많다고 무조건 좋은 것은 아닙니다. 이번 결과에 꼭 필요한 조건부터 알려주는 것이 중요합니다.

```prompt
title: 4단계 예제 - 기본 상황을 조건으로 요청
description: 동행자, 관심사와 걷기 정도를 조건으로 전달합니다.
---
혼자 가고,
역사·문화·예술과 관련된 장소를 좋아하며 도서관도 좋아해.
조금 걷는 것도 괜찮아.

이 조건에 맞는 코스를 만들어 줘.
```

```prompt
title: 4단계 실습 - 시간·이동·식사·예산 조건 추가
description: 출발과 복귀 시간, 이동수단, 식사, 휴식과 예산을 추가합니다.
---
위 조건에 다음 내용도 반영해 줘.

- 가능역에서 오전 10시에 출발
- 오후 6시 전까지 가능역으로 복귀
- 걷기와 대중교통을 함께 이용
- 중간에 혼자 편하게 먹을 수 있는 점심 포함
- 카페에서 쉴 시간 포함
- 전체 예산은 5만 원 이내

이 조건을 지키면서 의정부 숨은 명소 1일 코스를 다시 만들어 줘.
```

### 이번 단계에서 확인할 점

시간, 이동수단, 식사, 휴식과 예산을 알려주었을 때 일정이 더 현실적으로 바뀌는지 확인합니다.

### 이번 단계 체크

- [ ] 가능역 출발과 복귀 시간이 반영됐나요?
- [ ] 걷기와 대중교통을 함께 이용하도록 구성됐나요?
- [ ] 혼자 먹기 편한 점심과 카페 휴식이 포함됐나요?
- [ ] 전체 예산 5만 원 이내로 정리됐나요?
- [ ] 일정이 지나치게 빡빡하지 않은지 살펴봤나요?

## 5단계. 원하는 결과 형식 정하기

### Output Format Prompting

AI의 답변을 어떤 형태로 받을지 지정하는 방식입니다.

표, 목록, 체크리스트처럼 결과 형식을 알려주면 답변을 읽고 활용하기 쉬워집니다.

```prompt
title: 5단계 예제 - 보기 좋은 일정 요청
description: 원하는 형식을 구체적으로 정하지 않고 보기 좋게 정리해 달라고 요청합니다.
---
일정을 보기 좋게 정리해 줘.
```

```prompt
title: 5단계 실습 - 시간대별 일정표 요청
description: 최종 프롬프트와 같은 항목으로 1일 코스를 표로 정리하게 합니다.
---
지금까지 정리한 조건을 반영해 의정부 숨은 명소 1일 코스를 표로 정리해 줘.

표의 항목은 다음과 같이 해 줘.

- 시간
- 장소
- 이동 방법
- 예상 이동 시간
- 머무는 시간
- 추천 이유
- 예상 비용
- 직접 확인할 정보
```

### 이번 단계에서 확인할 점

긴 설명이 읽기 쉬운 일정표로 바뀌는지 확인합니다.

요청한 항목이 빠짐없이 들어갔는지도 함께 살펴봅니다.

### 이번 단계 체크

- [ ] 코스가 시간대별 표로 정리됐나요?
- [ ] 이동 방법과 예상 이동 시간이 포함됐나요?
- [ ] 머무는 시간과 추천 이유가 표시됐나요?
- [ ] 예상 비용과 직접 확인할 정보가 구분됐나요?
- [ ] 바로 저장하거나 공유하기 쉬운 결과물이 됐나요?

## 6단계. 기준을 나누어 검토하기

### Step-by-step Prompting

복잡한 작업을 바로 확정하지 않고, 어떤 순서로 검토할지 알려주는 방식입니다.

한 번의 답변 안에서 조건 정리, 후보 선정, 동선 검토와 일정표 작성을 순서대로 진행합니다.

```prompt
title: 6단계 예제 - 최종 코스 바로 요청
description: 중간 검토 없이 내 조건에 맞는 최종 코스를 바로 요청합니다.
---
내 조건에 맞는 의정부 숨은 명소 1일 코스를 최종 추천해 줘.
```

```prompt
title: 6단계 실습 - 6단계 검토 순서 지정
description: 조건 정리부터 일정표와 최신 확인 정보까지 순서를 나누어 검토합니다.
---
바로 최종 코스를 확정하지 말고, 다음 순서로 단계별로 검토해 줘.

1단계: 내 조건 정리
2단계: 조건에 맞는 숨은 명소 후보 5곳 선정
3단계: 각 장소의 추천 이유와 주의할 점 정리
4단계: 이동 동선이 자연스러운 장소 선택
5단계: 선택한 장소로 1일 일정표 작성
6단계: 최신 확인이 필요한 정보 표시

각 단계에는 짧은 제목을 붙여 줘.
```

### 이번 단계에서 확인할 점

복잡한 작업은 결과만 요청하는 것보다 검토 순서를 알려주면 중간 결과를 확인하기 쉽습니다.

Step-by-step Prompting은 한 번의 답변 안에서 작업 순서를 나누는 방식입니다.

### 이번 단계 체크

- [ ] 내 조건이 먼저 정리됐나요?
- [ ] 후보 장소가 5곳으로 제시됐나요?
- [ ] 각 장소의 추천 이유와 주의할 점이 구분됐나요?
- [ ] 이동 동선이 자연스러운 장소를 골랐나요?
- [ ] 최종 일정과 최신 확인 정보가 구분됐나요?

---

## 7단계. AI 답변 다시 검토하기

### Self-Reflection / Critique Prompting

AI가 만든 답변을 다시 검토하고 문제점과 누락을 찾게 하는 방식입니다.

AI가 만든 일정은 완성본이 아니라 초안입니다. 실제 정보는 사람이 다시 확인해야 합니다.

```prompt
title: 7단계 예제 - 간단한 일정 검토 요청
description: 구체적인 기준 없이 일정이 괜찮은지 확인합니다.
---
이 일정이 괜찮은지 봐 줘.
```

```prompt
title: 7단계 실습 - 현실성 및 최신 정보 검토
description: 이동 동선, 혼자 방문, 복귀 시간, 예산과 최신 정보를 기준으로 다시 검토합니다.
---
지금 만든 의정부 숨은 명소 1일 코스를 다시 검토해 줘.

다음 기준으로 확인해 줘.

- 이동 동선이 무리한 부분
- 혼자 방문하기 불편한 장소
- 머무는 시간이 너무 짧거나 긴 곳
- 오후 6시 전까지 복귀하기 어려운 부분
- 전체 예산 5만 원을 넘을 가능성
- 실제 존재 여부가 불확실한 장소
- 운영시간, 휴무일, 비용, 교통편처럼 최신 확인이 필요한 정보

문제가 있다면 ‘문제점 → 이유 → 수정안’ 순서로 정리해 줘.
```

### 이번 단계에서 확인할 점

AI의 답변을 그대로 확정하지 않고, 실제로 이용할 수 있는지 다시 검토합니다.

특히 운영시간, 휴무일, 비용, 교통편처럼 바뀔 수 있는 정보는 지도 서비스나 공식 안내에서 직접 확인해야 합니다.

### 이번 단계 체크

- [ ] 이동 동선이 무리한 부분을 찾았나요?
- [ ] 혼자 방문하기 불편한 장소가 표시됐나요?
- [ ] 복귀 시간과 예산을 다시 점검했나요?
- [ ] 실제 존재 여부가 불확실한 장소가 구분됐나요?
- [ ] 문제점, 이유와 수정안이 순서대로 정리됐나요?

---

## 8단계. 여러 번 이어서 완성하기

### Prompt Chaining

하나의 큰 요청을 한 번에 처리하지 않고, 앞 단계의 결과를 다음 단계의 재료로 이어 가는 방식입니다.

각 단계의 결과를 확인하고 수정한 뒤 다음 단계로 넘어갑니다.

```prompt
title: 8단계 예제 - 한 번에 모두 요청
description: 일정, 식당, 카페, 예산과 준비물을 한 번에 만들어 달라고 요청합니다.
---
의정부 숨은 명소 일정과 식당, 카페, 예산, 준비물을 모두 만들어 줘.
```

```prompt
title: 8단계 실습 - 6단계 프롬프트 체이닝
description: 조건 정리부터 최종 점검까지 하나씩 진행하고, 각 단계에서 사용자 확인을 받습니다.
---
의정부 숨은 명소 1일 코스를 한 번에 모두 완성하지 말고, 다음 순서로 하나씩 진행해 줘.

1단계: 지금까지 말한 여행 조건 정리
2단계: 숨은 명소 후보 5곳 비교
3단계: 내가 선택한 장소를 기준으로 1일 일정표 작성
4단계: 일정 동선에 맞는 점심 식당과 카페 후보 추가
5단계: 예상 예산과 준비물 체크리스트 작성
6단계: 무리한 일정과 최신 확인이 필요한 정보 최종 점검

각 단계가 끝나면 결과를 보여주고, 내가 확인하거나 수정한 다음 다음 단계로 넘어가 줘.

지금은 1단계만 먼저 진행해 줘.
```

### 이번 단계에서 확인할 점

Step-by-step Prompting은 한 번의 답변 안에서 순서를 나누는 방식입니다.

Prompt Chaining은 여러 번의 질문을 이어 가며 결과물을 점점 완성하는 방식입니다.

### 이번 단계 체크

- [ ] 한 번에 전체 결과를 만들지 않고 1단계부터 시작했나요?
- [ ] 각 단계가 끝날 때 결과를 확인할 수 있었나요?
- [ ] 내가 수정한 내용이 다음 단계에 반영됐나요?
- [ ] 앞 단계의 결과가 다음 단계의 재료로 사용됐나요?
- [ ] 여러 번의 대화를 거치며 코스가 점점 완성됐나요?

---

# 최종 프롬프트로 정리하기

AI와 대화하며 쌓은 상황, 조건과 수정 요청을 하나로 정리하면 새 대화나 다른 AI에서도 다시 사용할 수 있습니다.

```prompt
title: 최종 프롬프트 정리 요청
description: 지금까지 확정한 조건과 검토 요청을 빠뜨리지 않고 하나의 재사용 가능한 프롬프트로 정리합니다.

지금까지 내가 알려 준 상황, 관심사, 이동 조건, 시간, 예산, 출력 형식과 검토 요청을 빠뜨리지 말고 정리해 줘.

새 대화창이나 다른 AI에서도 다시 사용할 수 있도록 앞의 대화를 보지 않아도 이해할 수 있는 하나의 완성된 프롬프트로 만들어 줘.

사용자가 확정한 조건은 바꾸지 말고, 직접 확인해야 할 정보도 프롬프트에 포함해 줘.
```

# 확장형 최종 프롬프트

기본 실습에서는 모든 수강생이 같은 조건으로 프롬프트가 달라지는 과정을 확인했습니다.

아래 확장형 프롬프트는 기본 실습에서 배운 요소를 한데 모아, 각자의 상황에 맞게 바꾸어 다시 사용할 수 있도록 만든 완성형입니다.

기본 실습과 조건이 일부 다른 것은 오류가 아닙니다.  
기본 실습은 프롬프트 기법을 비교하는 과정이고, 확장형 최종 프롬프트는 실제 활용과 재사용을 위한 결과물입니다.

## 초보자용 빈칸 채우기 버전

아래 프롬프트의 대괄호 안 내용을 내 상황에 맞게 바꿔 넣으세요.

```prompt
title: 최종 프롬프트 - 초보자용 빈칸 채우기
description: 출발지, 시간, 동행자, 관심사와 예산을 바꾸어 의정부 1일 코스를 만드는 프롬프트입니다.
---
너는 의정부의 문화 공간, 산책길, 시장과 골목을 연결해 현실적인 1일 코스를 만드는 지역 여행 플래너야.

나는 [의정부에 오래 산 토박이 / 의정부에 이사 온 시민 / 의정부를 처음 방문하는 사람]이야.

이번에는 의정부의 익숙한 장소를 여행자의 시선으로 다시 둘러보고, 지역의 생활과 분위기를 느낄 수 있는 장소를 찾아보고 싶어.

[가능역 / 의정부역 / 회룡역 / 망월사역]에서 오전 [9시 / 10시]에 출발하고, 오후 [5시/ 6시]까지 돌아오는 1일 코스를 만들려고 해.

함께 가는 사람은 [혼자 / 짝궁 /  연인 / 서방님  / 마눌님 /가족 / 부모님 /아이들 ]이야.

관심 있는 분야는 [산책 / 문화 공간 / 시장과 골목 / 사진 촬영 / 카페와 음식]이야.

이동은 [걷기와 경전철 / 걷기와 시내버스 / 대중교통 /   자동자] 중심으로 하고 싶어.

걷는 정도는 [천천히 걷기 / 보통 / 많이 걷기]로 해 줘.

예산은 1인 [3만 원 / 5만 원 / 10만 원] 이하야.

방문 장소는 [2~3 /3~5곳 / 4~8 ] 곳 정도로 하고, 점심 식사와 카페에서 쉬는 시간을 포함해 줘.

필수로 넣고 싶은 장소는 [없음 / 의정부음악도서관 ]이야.

[산길 / 계단이 많은 장소 / 이동 거리가 긴 장소 ]은 제외해 줘.

유명한 관광지만 나열하지 말고, 의정부의 생활과 지역 분위기를 느낄 수 있는 문화 공간, 산책 장소, 시장과 골목도 함께 검토해 줘.

근거 없이 어떤 장소를 ‘숨은 명소’라고 단정하지 마.

바로 코스를 만들지 말고, 더 정확한 추천을 위해 나에게 먼저 확인해야 할 질문 5개를 한 번에 하나씩 해 줘.

내가 질문에 답하면 장소 후보 5~6곳을 먼저 비교해 줘.

장소 후보를 접근성, 지역 분위기, 관심 분야, 휴식, 비용 기준으로 비교해 줘.

내가 방문할 장소를 선택하거나 제외할 때까지 기다린 뒤 시간대별 1일 코스를 작성해 줘.

일정표의 항목은 다음과 같이 해 줘.

- 시간
- 장소
- 추천 이유
- 주요 활동
- 이동 방법
- 예상 이동 시간
- 예상 체류 시간
- 예상 비용
- 최신 확인 필요 항목

일정표 아래에는 다음 내용을 따로 정리해 줘.

- 전체 이동 순서
- 점심 식사 후보
- 카페 또는 휴식 장소
- 예상 총비용
- 비가 올 때의 대체 코스
- 이동이 무리한 부분
- 여행 전에 직접 확인할 정보

마지막에는 일정이 너무 빡빡하지 않은지, 나의 조건이 빠지지 않았는지 다시 검토해 줘.

운영시간, 휴관일, 입장료, 교통편, 행사 일정처럼 바뀔 수 있는 정보는 확정된 사실처럼 말하지 마.

확인하지 못한 내용은 ‘최신 확인 필요’ 또는 ‘직접 확인 필요’로 표시해 줘.
```

## 구조화된 마크다운 버전

같은 요청도 역할, 상황, 조건, 작업 순서와 출력 형식을 나누면 더 쉽게 수정하고 재사용할 수 있습니다.

```prompt
title: 최종 프롬프트 - 구조화된 마크다운 버전
description: 역할, 상황, 조건, 진행 방식, 출력 형식과 검토 기준을 구분한 의정부 1일 코스 프롬프트입니다.
---
### 역할

너는 의정부의 문화 공간, 산책길, 시장과 골목을 연결해 현실적인 1일 코스를 만드는 지역 여행 플래너야.

장소를 많이 나열하기보다 이동 동선, 체류 시간, 식사와 휴식을 함께 고려해 줘.

확실하지 않은 장소나 정보는 아는 것처럼 말하지 마.

### 여행 배경

나는 [의정부에 오래 산 시민 / 의정부에 이사 온 시민 / 의정부를 처음 방문하는 사람]이야.

이번 여행에서는 익숙한 의정부를 새로운 시선으로 바라보고, 지역의 생활과 분위기를 느낄 수 있는 장소를 둘러보고 싶어.

### 기본 조건

- 출발 장소: [가능역 / 의정부역 / 회룡역  ]
- 출발 시간: [09:00 / 10:00]
- 종료 시간: [17:00 / 18:00]
- 동행자: [혼자 / 짝궁 /  연인 / 서방님  / 마눌님 /가족 / 부모님 /아이들과 ]
- 관심 분야: [산책 / 문화 공간 / 시장과 골목 / 사진 / 카페와 음식]
- 이동수단: [걷기와 경전철 / 걷기와 버스 / 대중교통 / 자동차]
- 걷기 정도: [천천히 / 보통 / 많이 걷기]
- 예산: 1인 [3만 원 / 5만 원 / 10만 원] 이하
- 방문 장소: [2~3 /3~5 / 4~8 ]곳
- 필수 포함 장소: [없음 / 의정부음악도서관 ]
- 제외할 장소나 조건: [없음 / 산길 / 계단이 많은 장소 / 이동 거리가 긴 장소]

### 코스 작성 원칙

- 유명 관광지만 나열하지 마.
- 의정부의 지역 분위기를 느낄 수 있는 문화 공간, 산책 장소, 시장과 골목을 함께 검토해 줘.
- 근거 없이 어떤 장소를 ‘숨은 명소’라고 단정하지 마.
- 점심 식사와 카페 휴식을 일정에 포함해 줘.
- 이동 시간과 체류 시간을 현실적으로 반영해 줘.
- 너무 빡빡하거나 같은 지역을 반복해서 오가는 동선은 피해서 구성해 줘.
- 내가 말하지 않은 취향이나 조건은 임의로 만들지 마.

### 작업 진행 방식

바로 최종 코스를 만들지 말고 아래 순서로 진행해 줘.

1. 지금까지 입력한 나의 여행 조건을 정리해 줘.
2. 부족한 정보가 있으면 확인 질문 5개를 한 번에 하나씩 해 줘.
3. 내가 답변하면 조건에 맞는 장소 후보 5~6곳을 정리해 줘.
4. 장소 후보를 접근성, 지역 분위기, 관심 분야, 휴식, 비용 기준으로 비교해 줘.
5. 내가 방문할 장소를 선택하거나 제외할 수 있도록 기다려 줘.
6. 선택한 장소를 바탕으로 시간대별 1일 코스를 작성해 줘.
7. 예상 비용과 비가 올 때의 대체 코스를 작성해 줘.
8. 마지막으로 코스의 현실성과 최신 정보를 점검해 줘.

각 단계가 끝나면 아래 내용을 짧게 정리해 줘.

- 이번 단계에서 정리한 내용
- 아직 확인할 내용
- 다음 단계에서 할 일

내가 동의하기 전에는 다음 단계로 넘어가지 마.

### 출력 형식

최종 일정은 표로 정리해 줘.

표의 항목:

- 시간
- 장소
- 추천 이유
- 주요 활동
- 이동 방법
- 예상 이동 시간
- 예상 체류 시간
- 예상 비용
- 최신 확인 필요 항목

표 아래에는 다음 내용을 따로 정리해 줘.

1. 전체 이동 순서
2. 점심 식사 후보
3. 카페 또는 휴식 장소
4. 예상 총비용
5. 비가 올 때의 대체 코스
6. 여행 전에 직접 확인할 정보

### 검토 요청

최종 코스를 아래 기준으로 다시 검토해 줘.

- 이동 거리가 무리하지 않은가
- 같은 지역을 불필요하게 반복해서 오가지 않는가
- 한 장소에 머무는 시간이 너무 짧지 않은가
- 식사와 휴식 시간이 충분한가
- 예산을 초과할 가능성이 있는가
- 내가 말한 조건이 빠지지 않았는가
- 실제 존재 여부나 최신 정보가 불분명한 장소가 있는가

문제가 발견되면 기존 코스 전체를 새로 만들지 말고 필요한 부분만 수정해 줘.

### 확인 필요 항목

운영시간, 휴관일, 입장료, 교통편, 행사 일정, 점포 영업시간, 예약 여부처럼 바뀔 수 있는 정보는 확정된 사실처럼 말하지 마.

확인한 정보와 확인하지 못한 정보를 구분해 줘.

불분명한 내용은 ‘최신 확인 필요’ 또는 ‘직접 확인 필요’로 표시해 줘.

지금은 최종 일정을 만들지 말고, 나의 여행 조건을 정리한 뒤 첫 번째 확인 질문부터 시작해 줘.
```

# 마지막으로 기억할 점

좋은 프롬프트는 처음부터 한 번에 완성되지 않습니다.

같은 ‘의정부 숨은 명소 1일 코스’라는 주제를 가지고 먼저 질문받기, 상황 추가, 조건 설정, 형식 지정, 단계별 검토, 답변 검토와 작업 연결을 하나씩 더하면 실제로 활용할 수 있는 프롬프트가 됩니다.

AI가 만든 여행 계획은 완성본이 아니라 초안입니다.

특히 다음 정보는 지도 서비스나 공식 안내에서 직접 확인해야 합니다.

- 장소가 실제로 운영 중인지
- 운영시간과 휴무일
- 비용과 예약 여부
- 실제 이동 시간과 교통편
- 식당과 카페의 영업시간

AI가 코스의 초안을 만들고, 사람은 실제 정보를 확인한 뒤 최종 코스를 결정합니다.
