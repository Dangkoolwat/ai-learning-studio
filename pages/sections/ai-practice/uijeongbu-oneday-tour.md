# 의정부 숨은 명소 1일 코스 만들기 (프롬프트 기초편)

같은 주제를 여러 프롬프트 방식으로 바꾸어 봅니다.

**중요 포인트:** ‘의정부 숨은 명소 1일 코스 완성’이라는 같은 주제를 가지고 프롬프트를 하나씩 개선해 봅니다.

처음에는 짧고 단순한 요청으로 시작합니다.  
그다음 AI에게 먼저 질문하게 하고, 나의 상황과 조건을 추가합니다.

이후 원하는 결과 형식을 정하고, 코스를 단계별로 검토한 뒤, 여러 번의 대화를 이어 가며 실제로 활용할 수 있는 1일 코스를 완성합니다.

## 실습 순서

1. Zero-shot Prompting: 바로 요청
2. Ask-before-answer Prompting: 먼저 질문
3. Context Prompting: 상황 추가
4. Constraint Prompting: 조건 설정
5. Output Format Prompting: 형식 지정
6. Step-by-step Prompting: 단계별 검토
7. Self-Reflection / Critique Prompting: 답변 검토
8. Prompt Chaining: 작업을 이어서 완성

---

## 1단계. 바로 요청하기

### Zero-shot Prompting

별도의 예시나 조건 없이 AI에게 원하는 일을 바로 요청하는 방식입니다.

가장 빠르게 시작할 수 있지만, 사용자의 상황과 기준이 부족하면 답변이 넓고 일반적으로 나올 수 있습니다.

```prompt
title: 1단계 예제 - 기본 제로샷 요청
description: 별도의 조건 없이 의정부의 숨은 명소를 추천해 달라고 요청합니다.
---
의정부의 숨은 명소를 추천해 줘.
```

```prompt
title: 1단계 실습 - 1일 코스 요청
description: 하루 동안 둘러볼 수 있는 코스를 만들어 달라는 조건만 추가합니다.
---
의정부의 숨은 명소를 하루 동안 둘러보는 1일 코스를 만들어 줘.
```

### 이번 단계에서 확인할 점

여행 시간이 하루라는 것 외에는 구체적인 조건이 거의 없습니다.

AI가 유명한 장소를 나열하거나, 출발지와 이동수단을 고려하지 않은 코스를 만들 수 있습니다. 식사와 휴식 시간도 빠질 수 있습니다.

또한 AI가 실제로 확인하지 않은 장소를 ‘숨은 명소’라고 표현할 수도 있습니다.

### 이번 단계 체크

- [ ] 출발 장소와 이동수단이 빠져 있다는 점을 확인했나요?
- [ ] 누구와 가는지, 무엇을 좋아하는지 반영되지 않았나요?
- [ ] 식사와 휴식 시간이 빠져 있지는 않았나요?
- [ ] AI의 답변이 넓고 일반적으로 나오는지 살펴봤나요?
- [ ] 다음 단계에서 어떤 정보를 더 알려주면 좋을지 생각해 봤나요?

---

## 2단계. 답하기 전에 먼저 질문받기

### Ask-before-answer Prompting

AI가 바로 답을 만들지 않고, 더 정확한 결과를 만드는 데 필요한 정보를 먼저 질문하게 하는 방식입니다.

내가 무엇을 빠뜨렸는지 잘 모를 때 유용합니다.

```prompt
title: 2단계 예제 - 먼저 질문 3개 받기
description: 1일 코스를 만들기 전에 AI가 필요한 정보를 먼저 질문하게 합니다.
---
나에게 맞는 의정부 숨은 명소 1일 코스를 만들고 싶어.

바로 코스를 만들지 말고, 먼저 나에게 확인해야 할 질문 3개를 해 줘.
```

```prompt
title: 2단계 실습 - 질문 이유까지 확인하기
description: AI가 확인 질문을 한 번에 하나씩 하고, 질문이 필요한 이유도 설명하게 합니다.
---
지금 바로 의정부 1일 코스를 만들지 말고, 더 정확한 코스를 만들기 위해 나에게 먼저 확인해야 할 질문 5개를 해 줘.

출발 장소, 이용 시간, 동행자, 관심 있는 장소, 걷기 가능한 정도, 예산 등을 확인해 줘.

질문은 한 번에 하나씩 해 줘.

각 질문을 할 때는 왜 필요한 질문인지도 한 줄로 설명해 줘.
```

### 이번 단계에서 확인할 점

AI가 사용자가 빠뜨린 정보를 먼저 찾아 질문하는지 확인합니다.

한꺼번에 많은 질문을 받는 것보다 한 번에 하나씩 질문받으면 대화하듯 편하게 답할 수 있습니다.

AI의 질문이 모두 필요한 것은 아닙니다. 불필요하거나 답하기 어려운 질문은 건너뛰거나 다른 질문으로 바꿔 달라고 요청할 수 있습니다.

### 이번 단계 체크

- [ ] AI가 코스를 바로 만들지 않고 질문부터 했나요?
- [ ] 출발지, 시간, 관심사, 동행자 등을 확인했나요?
- [ ] 각 질문이 필요한 이유를 설명했나요?
- [ ] 질문을 한 번에 하나씩 했나요?
- [ ] 질문에 답한 뒤 결과가 더 구체적으로 달라졌나요?

---

## 3단계. 내 상황과 배경 알려주기

### Context Prompting

AI에게 나의 상황과 여행 배경을 알려주는 방식입니다.

AI는 사용자가 의정부에 얼마나 오래 살았는지, 어디에서 출발하는지, 어떤 여행을 원하는지 미리 알지 못합니다.

알려 준 상황이 구체적일수록 답변이 내 여행에 가까워집니다.

```prompt
title: 3단계 예제 - 여행 배경 알려주기
description: 의정부 거주 여부, 여행 목적과 출발 시간을 알려 줍니다.
---
나는 의정부에 오래 살았지만 익숙한 장소만 다녀서, 이번에는 평소 지나쳤던 곳을 여행자의 시선으로 다시 둘러보고 싶어.

[가능역 / 의정부역 / 회룡역]에서 오전 [9시 / 10시]에 출발해 하루 동안 혼자 다닐 수 있는 코스를 추천해 줘.
```

```prompt
title: 3단계 실습 - 관심사와 여행 방식 추가하기
description: 관심 있는 장소와 원하는 여행 속도를 추가해 답변을 다시 작성하게 합니다.
---
나는 [의정부에 오래 산 시민 / 의정부에 이사 온 시민 / 의정부를 처음 방문하는 사람]이야.

이번에는 의정부의 익숙한 장소를 여행자의 시선으로 다시 둘러보고 싶어.

[가능역 / 의정부역 / 회룡역]에서 오전 [9시 / 10시]에 출발하고, 오후 [5시 / 6시]까지 돌아오는 1일 코스를 만들려고 해.

나는 [산책 / 문화 공간 / 시장과 골목 / 사진 촬영 / 카페와 음식]에 관심이 있어.

여러 장소를 빠르게 돌아보기보다 한 장소를 천천히 둘러보고 쉬는 시간을 갖는 편이야.

이 상황을 반영해서 앞에서 추천한 코스를 다시 정리해 줘.
```

### 이번 단계에서 확인할 점

같은 의정부 1일 코스라도 사용자의 여행 배경과 관심사에 따라 추천 장소가 달라질 수 있습니다.

단순히 유명한 장소를 찾는 여행인지, 익숙한 동네를 새롭게 바라보는 여행인지에 따라서도 코스의 방향이 달라집니다.

### 이번 단계 체크

- [ ] 의정부 거주 여부와 여행 목적이 반영됐나요?
- [ ] 출발 장소와 여행 시간이 일정에 반영됐나요?
- [ ] 내가 관심 있는 장소 유형이 추천에 반영됐나요?
- [ ] 여행 속도와 휴식 선호가 반영됐나요?
- [ ] 알려 주지 않은 정보는 결과에 반영되기 어렵다는 점을 확인했나요?

---

## 4단계. 조건과 제한 정하기

### Constraint Prompting

반드시 지켜야 할 조건과 피하고 싶은 조건을 알려주는 방식입니다.

조건이 구체적일수록 추천 범위가 줄어들고, 실제로 이용할 수 있는 코스에 가까워집니다.

```prompt
title: 4단계 예제 - 시간·예산·이동수단 설정
description: 여행 시간, 예산, 이동수단과 방문 장소 수를 제한합니다.
---
아래 조건을 반영해서 의정부 1일 코스를 다시 만들어 줘.

- 여행 시간: 오전 [9시 / 10시]부터 오후 [5시 / 6시]까지
- 예산: 1인 [3만 원 / 5만 원 / 10만 원] 이하
- 이동수단: [걷기와 경전철 / 걷기와 시내버스 / 대중교통]
- 방문 장소: [3곳 / 4곳 / 5곳]
- 점심 식사와 카페 휴식 포함
- 너무 빡빡한 일정은 제외
```

```prompt
title: 4단계 실습 - 필수 조건과 제외 조건 추가하기
description: 관심 분야, 걷기 정도, 필수 장소와 최신 확인 항목을 함께 지정합니다.
---
앞에서 정리한 나의 상황과 아래 조건을 모두 반영해서 코스를 다시 만들어 줘.

- 출발 장소: [가능역 / 의정부역 / 회룡역 / 직접 입력]
- 여행 시간: [09:00~18:00 / 10:00~17:00]
- 이동수단: [걷기와 경전철 / 걷기와 버스 / 대중교통]
- 예상 예산: 1인 [3만 원 / 5만 원 / 10만 원] 이하
- 관심 분야: [산책 / 문화 공간 / 시장과 골목 / 사진 / 카페와 음식]
- 걷기 정도: [천천히 걷기 / 보통 / 많이 걷기]
- 방문 장소: 3~5곳
- 필수 포함 장소: [없음 / 의정부음악도서관 / 직접 입력]
- 제외할 장소나 조건: [없음 / 산길 / 계단이 많은 장소 / 직접 입력]
- 점심 식사와 카페 휴식 포함
- 같은 지역을 여러 번 오가는 동선은 제외
- 유명 관광지만 나열하지 말고 지역의 생활과 분위기를 느낄 수 있는 장소도 검토

운영시간, 휴관일, 입장료, 교통편처럼 바뀔 수 있는 정보는 ‘최신 확인 필요’로 표시해 줘.

확실하지 않은 장소를 근거 없이 ‘숨은 명소’라고 단정하지 마.
```

### 이번 단계에서 확인할 점

시간, 예산, 이동수단과 제외 조건이 코스의 성격을 어떻게 바꾸는지 확인합니다.

‘숨은 명소’라는 표현만으로는 기준이 분명하지 않습니다. 지역 분위기, 접근성, 휴식, 관심 분야처럼 구체적인 기준이 함께 필요합니다.

### 이번 단계 체크

- [ ] 여행 시간과 예산이 일정에 반영됐나요?
- [ ] 이동수단에 맞게 동선이 달라졌나요?
- [ ] 방문 장소가 너무 많지 않게 조정됐나요?
- [ ] 필수 장소와 제외 조건이 반영됐나요?
- [ ] 점심과 휴식 시간이 포함됐나요?
- [ ] 최신 확인이 필요한 정보가 따로 표시됐나요?

## 5단계. 원하는 결과 형식 정하기

### Output Format Prompting

AI의 답변을 어떤 형태로 받을지 지정하는 방식입니다.

일정표, 비교표, 체크리스트처럼 실제로 활용할 결과물의 형식을 알려주면 답변을 읽고 사용하기 쉬워집니다.

```prompt
title: 5단계 예제 - 시간대별 일정표 요청
description: 앞에서 추천한 장소를 시간대별 일정표로 정리하도록 요청합니다.
---
앞에서 추천한 장소를 바탕으로 오전 [9시 / 10시]부터 오후 [5시 / 6시]까지의 의정부 1일 코스를 표로 정리해 줘.

표의 항목은 시간, 장소, 할 일, 이동 방법, 예상 체류 시간으로 해 줘.
```

```prompt
title: 5단계 실습 - 일정표와 확인 목록 지정
description: 장소 선정 이유, 이동 시간, 비용과 최신 확인 항목까지 포함한 결과물을 요청합니다.
---
앞에서 정리한 나의 상황과 조건을 반영해 의정부 1일 코스를 시간대별 일정표로 작성해 줘.

표의 항목은 다음과 같이 해 줘.

- 시간
- 장소
- 이 장소를 넣은 이유
- 주요 활동
- 이동 방법
- 예상 이동 시간
- 예상 체류 시간
- 예상 비용
- 최신 확인 필요 항목

표 아래에는 다음 내용을 따로 정리해 줘.

1. 전체 이동 순서
2. 점심 식사 후보
3. 카페 또는 휴식 장소
4. 예상 총비용
5. 비가 올 때 바꿀 수 있는 장소
6. 여행 전에 직접 확인할 정보

확인하지 못한 운영시간과 가격은 임의로 작성하지 마.
```

### 이번 단계에서 확인할 점

긴 설명이 시간대별 일정표와 확인 목록으로 바뀌었는지 확인합니다.

결과 형식을 지정할 때는 표에 들어갈 항목뿐 아니라, 표 아래에 따로 정리할 내용도 함께 알려줄 수 있습니다.

### 이번 단계 체크

- [ ] 코스가 시간대별 일정표로 정리됐나요?
- [ ] 요청한 항목이 빠짐없이 들어갔나요?
- [ ] 장소를 선택한 이유가 함께 표시됐나요?
- [ ] 식사와 휴식 장소가 구분됐나요?
- [ ] 예상 비용과 최신 확인 항목이 따로 표시됐나요?
- [ ] 바로 저장하거나 공유할 수 있는 형태가 됐나요?

---

## 6단계. 기준을 나누어 검토하기

### Step-by-step Prompting

복잡한 작업을 바로 완성하게 하지 않고, 확인할 순서를 나누어 정리하게 하는 방식입니다.

AI의 내부 생각을 모두 보여 달라고 요청하는 것이 아니라, 어떤 기준으로 검토했는지 결과와 짧은 이유를 단계별로 정리하게 합니다.

```prompt
3단계: 접근성, 지역 분위기, 휴식, 비용 기준으로 후보 비교
4단계: 이동 동선이 자연스러운 장소 3~5곳 선택
5단계: 선택한 장소로 시간대별 1일 코스 작성
```

## 7단계. AI 답변 다시 검토하기

## 8단계. 여러 번 이어서 완성하기

### Prompt Chaining

하나의 큰 작업을 한 번에 처리하지 않고, 앞 단계의 결과를 다음 단계의 재료로 이어 가는 방식입니다.

의정부 1일 코스는 조건 정리, 확인 질문, 장소 후보 비교, 장소 선택, 일정 작성, 최종 검토로 나누어 진행할 수 있습니다.

```prompt
title: 8단계 예제 - 프롬프트 체이닝 진행 순서
description: 전체 코스를 한 번에 만들지 않고 첫 번째 단계부터 진행합니다.
---
아래 순서로 의정부 숨은 명소 1일 코스를 하나씩 만들어 줘.

1단계: 나의 여행 조건 정리
2단계: 부족한 조건 질문
3단계: 조건에 맞는 장소 후보 5~6곳 제안
4단계: 장소 후보 비교
5단계: 내가 방문할 장소 선택
6단계: 시간대별 1일 코스 작성
7단계: 예상 비용과 우천 시 대체 코스 작성
8단계: 현실성과 최신 정보 최종 점검

각 단계가 끝나면 결과를 짧게 정리하고, 다음 단계로 넘어갈지 나에게 물어봐 줘.

지금은 1단계 여행 조건 정리만 진행해 줘.
```

```prompt
title: 8단계 실습 - 단계별 대화로 최종 코스 만들기
description: 앞 단계 결과를 확인하고 수정한 뒤 다음 단계로 이어 가도록 요청합니다.

4단계: 장소 후보를 접근성, 지역 분위기, 관심 분야, 휴식, 비용 기준으로 비교해 줘.
5단계: 내가 방문할 장소를 선택하거나 제외할 때까지 기다려 줘.

7단계: 점심, 카페, 예상 비용과 비가 올 때의 대체 코스를 정리해 줘.
8단계: 이동 시간, 일정의 무리함과 최신 확인이 필요한 정보를 검토해 줘.
9단계: 내가 수정할 내용을 말하면 필요한 부분만 반영해 최종 코스를 작성해 줘.

- 아직 확인할 내용
- 다음 단계에서 할 일
```

### 이번 단계에서 확인할 점

- [ ] 잘못된 조건을 중간에 수정할 수 있었나요?

## 구조화된 마크다운 버전

같은 요청도 역할, 상황, 조건, 작업 순서와 출력 형식을 나누면 더 쉽게 수정하고 재사용할 수 있습니다.

```prompt
title: 최종 프롬프트 - 구조화된 마크다운 버전

---
### 역할

너는 의정부의 문화 공간, 산책길, 시장과 골목을 연결해 현실적인 1일 코스를 만드는 지역 여행 플래너야.

장소를 많이 나열하기보다 이동 동선, 체류 시간, 식사와 휴식을 함께 고려해 줘.

확실하지 않은 장소나 정보는 아는 것처럼 말하지 마.

### 여행 배경

나는 [의정부에 오래 산 시민 / 의정부에 이사 온 시민 / 의정부를 처음 방문하는 사람]이야.

이번 여행에서는 익숙한 의정부를 새로운 시선으로 바라보고, 지역의 생활과 분위기를 느낄 수 있는 장소를 둘러보고 싶어.

### 기본 조건

- 출발 장소: [가능역 / 의정부역 / 회룡역 / 직접 입력]
- 출발 시간: [09:00 / 10:00]
- 종료 시간: [17:00 / 18:00]
- 동행자: [혼자 / 친구 / 가족 / 부모님]
- 관심 분야: [산책 / 문화 공간 / 시장과 골목 / 사진 / 카페와 음식]

- 방문 장소: 3~5곳
- 필수 포함 장소: [없음 / 의정부음악도서관 / 직접 입력]
- 제외할 장소나 조건: [없음 / 산길 / 계단이 많은 장소 / 이동 거리가 긴 장소 / 직접 입력]

### 코스 작성 원칙

- 유명 관광지만 나열하지 마.
- 의정부의 지역 분위기를 느낄 수 있는 문화 공간, 산책 장소, 시장과 골목을 함께 검토해 줘.
- 근거 없이 어떤 장소를 ‘숨은 명소’라고 단정하지 마.
- 점심 식사와 카페 휴식을 일정에 포함해 줘.
- 이동 시간과 체류 시간을 현실적으로 반영해 줘.
- 너무 빡빡하거나 같은 지역을 반복해서 오가는 동선은 피해서 구성해 줘.
- 내가 말하지 않은 취향이나 조건은 임의로 만들지 마.

### 작업 진행 방식

바로 최종 코스를 만들지 말고 아래 순서로 진행해 줘.

1. 지금까지 입력한 나의 여행 조건을 정리해 줘.
2. 부족한 정보가 있으면 확인 질문 5개를 한 번에 하나씩 해 줘.
3. 내가 답변하면 조건에 맞는 장소 후보 5~6곳을 정리해 줘.
4. 장소 후보를 접근성, 지역 분위기, 관심 분야, 휴식, 비용 기준으로 비교해 줘.
5. 내가 방문할 장소를 선택하거나 제외할 수 있도록 기다려 줘.
6. 선택한 장소를 바탕으로 시간대별 1일 코스를 작성해 줘.
7. 예상 비용과 비가 올 때의 대체 코스를 작성해 줘.
8. 마지막으로 코스의 현실성과 최신 정보를 점검해 줘.

각 단계가 끝나면 아래 내용을 짧게 정리해 줘.

- 이번 단계에서 정리한 내용
- 아직 확인할 내용
- 다음 단계에서 할 일

내가 동의하기 전에는 다음 단계로 넘어가지 마.

3. 카페 또는 휴식 장소

### 검토 요청

최종 코스를 아래 기준으로 다시 검토해 줘.

- 이동 거리가 무리하지 않은가
- 같은 지역을 불필요하게 반복해서 오가지 않는가
- 한 장소에 머무는 시간이 너무 짧지 않은가
- 식사와 휴식 시간이 충분한가
- 예산을 초과할 가능성이 있는가
- 내가 말한 조건이 빠지지 않았는가
- 실제 존재 여부나 최신 정보가 불분명한 장소가 있는가

문제가 발견되면 기존 코스 전체를 새로 만들지 말고 필요한 부분만 수정해 줘.
```

# 마지막으로 기억할 점

좋은 프롬프트는 처음부터 한 번에 완성되지 않습니다.

같은 ‘의정부 숨은 명소 1일 코스’라는 주제를 가지고 먼저 질문받기, 상황 추가, 조건 설정, 출력 형식 지정, 단계별 검토, 답변 검토와 작업 연결을 하나씩 더하면 실제로 활용할 수 있는 프롬프트가 됩니다.

‘숨은 명소’는 사람마다 기준이 다릅니다.

유명하지 않다는 이유만으로 좋은 장소가 되는 것은 아니며, AI가 어떤 장소를 근거 없이 숨은 명소라고 표현할 수도 있습니다.

AI에게는 장소 후보와 동선을 정리하게 하고, 사람은 지도 서비스나 공식 안내에서 다음 내용을 직접 확인해야 합니다.

- 장소가 실제로 운영 중인지
- 운영시간과 휴관일
- 입장료와 예약 여부
- 실제 이동 시간과 교통편
- 식당과 카페의 영업시간
- 행사 일정
- 날씨와 우천 시 이용 가능 여부

AI가 코스의 초안을 만들고, 사람은 실제 정보를 확인한 뒤 최종 코스를 결정합니다.
