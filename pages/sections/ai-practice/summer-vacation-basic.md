# 여름휴가 계획 세우기 (기초편)

같은 주제를 여러 프롬프트 방식으로 바꾸어 봅니다.

**중요 포인트:** ‘여름휴가 계획’이라는 같은 주제를 가지고 프롬프트를 하나씩 개선해 봅니다.

## 실습 순서

1. Zero-shot Prompting: 바로 요청
2. Role Prompting: 역할 부여
3. Context Prompting: 상황 추가
4. Constraint Prompting: 조건 설정
5. One-shot / Few-shot Prompting: 예시 제공
6. Output Format Prompting: 형식 지정
7. Step-by-step Prompting: 단계별 검토
8. Ask-before-answer Prompting: 먼저 질문
9. Self-Reflection / Critique Prompting: 답변 검토
10. Prompt Chaining: 작업을 이어서 완성

---

## 1단계. 바로 요청하기

### Zero-shot Prompting

가장 빠르게 AI에게 일을 맡기는 방식입니다.

```prompt
title: 1단계 예제 - 기본 제로샷 요청
description: 아무런 부가 조건 없이 기본 질문을 전달합니다.
---
여름휴가 계획을 세워 줘.
```

```prompt
title: 1단계 실습 - 기간 지정 요청
description: 간단한 여행 기간 조건만 추가하여 결과를 관찰합니다.
---
[2박 3일 / 3박 4일 / 1박 2일] 여름휴가 계획을 세워 줘.
```

### 이번 단계에서 확인할 점

조건이 부족해서 답변이 넓고 일반적으로 나오는지 확인합니다.

### 이번 단계 체크

- [ ] 여행 기간 외에 구체적인 조건이 거의 없다는 점을 확인했나요?
- [ ] AI의 답변이 넓고 일반적으로 나오는지 살펴봤나요?
- [ ] 다음 단계에서 어떤 정보를 더 알려주면 좋을지 생각해 봤나요?

---

## 2단계. AI의 역할 정하기

### Role Prompting

AI에게 역할을 주는 방식입니다.

```prompt
title: 2단계 예제 - 여행 플래너 역할 부여
description: AI에게 특정 페르소나와 관점을 지정합니다.
---
너는 [직장인을 위한 / 가족 여행 전문 / 알뜰 여행] 플래너야.

퇴근 후 준비 시간이 많지 않은 사람을 위한 [2박 3일 / 3박 4일 / 1박 2일] 여름휴가 계획을 세워 줘.
```

```prompt
title: 2단계 실습 - 고려 사항이 포함된 역할 재정리
description: 이동 피로, 예산, 휴식 시간을 고려하도록 역할을 재지정합니다.
---
위 답변을 [직장인을 위한 / 커플을 위한 / 부모님 동반] 현실적인 여행 플래너 관점에서 다시 정리해 줘.

이동 피로, 예산 부담, 휴식 시간을 고려해 줘.
```

### 이번 단계에서 확인할 점

AI의 관점과 추천 기준이 달라지는지 확인합니다.

### 이번 단계 체크

- [ ] 역할을 추가한 뒤 추천 기준이 달라졌나요?
- [ ] 이동 피로, 예산 부담, 휴식 시간이 답변에 반영됐나요?
- [ ] 역할이 결과에 어떤 영향을 주는지 설명할 수 있나요?

---

## 3단계. 내 상황과 배경 알려주기

### Context Prompting

AI에게 내 상황과 배경을 알려주는 방식입니다.

```prompt
title: 3단계 예제 - 출발지와 상황 배경 전달
description: 거주지, 준비 가능 시간, 여행 시기 등 상황을 전달합니다.
---
나는 [의정부 / 서울 / 부산]에 사는 직장인이고, 퇴근 후 준비 시간이 많지 않아.

[7월 말 / 8월 초]에 [2박 3일 / 3박 4일 / 1박 2일]로 다녀올 수 있는 여름휴가 여행지를 추천해 줘.
```

```prompt
title: 3단계 실습 - 이동 부담 반영 요청
description: 이동 부담을 줄이고 내 상황에 맞춘 재추천을 유도합니다.
---
나는 [의정부 / 서울 / 대구]에 사는 직장인이고, [7월 말 / 8월 중순]에 [2박 3일 / 3박 4일 / 1박 2일]로 여름휴가를 가려고 해.

퇴근 후 준비 시간이 많지 않고, 너무 먼 곳보다는 이동 부담이 적은 여행지를 선호해.

이 상황을 반영해서 위 답변을 다시 추천해 줘.
```

### 이번 단계에서 확인할 점

AI는 내 상황을 모릅니다. 알려 준 만큼 답변이 내 상황에 가까워집니다.

### 이번 단계 체크

- [ ] 출발지, 직업, 여행 시기와 기간이 반영됐나요?
- [ ] 이동 부담이 적은 여행지 중심으로 추천이 달라졌나요?
- [ ] AI에게 알려 주지 않은 정보는 답변에 제대로 반영되기 어렵다는 점을 확인했나요?

---

## 4단계. 조건과 제한 정하기

### Constraint Prompting

조건과 제한을 주는 방식입니다.

```prompt
title: 4단계 예제 - 예산 및 이동수단 제약
description: 1인 예산 한도와 이동수단, 이동시간 제한을 설정합니다.
---
예산은 1인 [60만 원 / 40만 원 / 80만 원] 이하로 해 줘.

[대중교통 / 자차]으로 이동 가능한 곳만 추천해 줘.

하루 이동 시간은 [3시간 / 2시간]을 넘지 않게 해 줘.

너무 유명한 관광지는 제외해 줘.
```

```prompt
title: 4단계 실습 - 세부 제한 및 검토 항목 지정
description: 일정의 빡빡함 제외 및 확인 필요 항목 구분을 추가합니다.
---
예산은 1인 [60만 원 / 50만 원] 이하로 해 줘.

[대중교통 / 렌터카] 중심으로 이동할 수 있는 곳을 추천해 줘.

하루 총 이동 시간은 [3시간 이내 / 4시간 이내]로 해 줘.

너무 빡빡한 일정은 제외해 줘.

가격, 운영시간, 예약 여부는 확인 필요로 표시해 줘.
```

### 이번 단계에서 확인할 점

추천 범위가 줄어들고 기준이 선명해지는지 확인합니다.

### 이번 단계 체크

- [ ] 예산과 이동수단이 추천 범위를 좁혔나요?
- [ ] 제외 조건이 일정의 성격을 바꿨나요?
- [ ] 최신 확인이 필요한 항목이 따로 표시됐나요?

---

## 5단계. 예시를 보여주기

### One-shot / Few-shot Prompting

예시를 보여주고 그 형식이나 톤을 따라 하게 하는 방식입니다.

```prompt
title: 5단계 예제 - 원샷(One-shot) 표준 출력 템플릿 전달
description: 1개의 원하는 예시 양식을 제시해 출력 형태를 고정합니다.
---
아래 예시와 같은 형식으로 작성해 줘.

여행지: 강릉
추천 이유: 바다, 카페, 기차 이동이 편리함
일정 특징: 무리하지 않는 산책과 휴식 중심
확인 필요: 숙소 가격, 기차표, 카페 운영시간

위 형식을 참고해서 여행지 후보 3곳을 다시 정리해 줘.
```

```prompt
title: 5단계 실습 - 퓨샷(Few-shot) 패턴 맞춤 적용
description: 예시 양식을 바탕으로 후보별 일관된 패턴 작성을 요구합니다.
---
위 답변의 여행지 후보를 아래 예시와 같은 형식으로 다시 정리해 줘.

예시

여행지: [강릉 / 속초 / 여수]
추천 이유: 바다, 카페, 기차 이동이 편리함
일정 특징: 무리하지 않는 산책과 휴식 중심
확인 필요: 숙소 가격, 기차표, 카페 운영시간

후보별로 같은 형식을 반복해서 정리해 줘.
```

### 이번 단계에서 확인할 점

말로 길게 설명하는 것보다 예시를 보여주는 것이 더 효과적일 수 있습니다.

### 이번 단계 체크

- [ ] AI가 예시의 항목과 순서를 따라 작성했나요?
- [ ] 후보마다 같은 형식이 반복됐나요?
- [ ] 형식을 설명하는 것과 예시를 보여주는 것의 차이를 확인했나요?

---

## 6단계. 원하는 결과 형식 정하기

### Output Format Prompting

결과 형식을 지정하는 방식입니다.

```prompt
title: 6단계 예제 - 일정표 및 체크리스트 형식 지정
description: 날짜별 일정표와 준비물 체크리스트 생성을 지정합니다.
---
[2박 3일 / 3박 4일 / 1박 2일] 여름휴가 계획을 날짜별 일정표로 정리해 줘.

마지막에는 준비물 체크리스트도 함께 만들어 줘.
```

```prompt
title: 6단계 실습 - 비교표 및 요약문 지정
description: 항목별 비교 표 작성과 요약 1순위 추천을 요구합니다.
---
위 답변을 여행지 후보 3곳 비교표로 정리해 줘.

항목은 여행지, 추천 이유, 이동 방법, 예상 이동 시간, 예상 비용, 장점, 단점, 확인 필요 항목으로 해 줘.

표 아래에는 1순위 추천과 이유를 2줄로 정리해 줘.

마지막에는 준비물 체크리스트도 함께 만들어 줘.
```

### 이번 단계에서 확인할 점

답변이 읽기 쉬운 결과물로 바뀌는지 확인합니다.

### 이번 단계 체크

- [ ] 여행지 후보가 비교표로 정리됐나요?
- [ ] 요청한 항목이 빠짐없이 들어갔나요?
- [ ] 바로 활용할 수 있는 준비물 체크리스트가 만들어졌나요?

---

## 7단계. 기준을 나누어 검토하기

### Step-by-step / CoT Prompting

단계별로 검토하게 하는 방식입니다.

```prompt
title: 7단계 예제 - 멀티 기준 비교 및 단계별 분석
description: 이동시간, 예산, 맛집 등 기준별 단계 분석을 유도합니다.
---
[강릉 / 속초 / 부산]과 [여수 / 경주 / 제주]를 비교해 줘.

이동 시간, 예산, 휴식, 맛집, 혼잡도 기준으로 단계별로 검토해 줘.

마지막에는 더 적합한 여행지 1곳과 이유 3가지를 정리해 줘.
```

```prompt
title: 7단계 실습 - 5단계 검토 순서 정의
description: 1~5단계별로 판단 과정을 쪼개어 단계별 제목과 함께 답변받습니다.
---
위 여행 계획을 바로 확정하지 말고, 아래 순서로 단계별로 정리해 줘.

1단계: 여행 조건 정리
2단계: 여행지 후보 선정 기준
3단계: 후보 3곳 비교
4단계: 최종 추천
5단계: 확인 필요 항목

각 단계마다 짧은 제목을 붙여서 정리해 줘.
```

### 이번 단계에서 확인할 점

복잡한 판단은 바로 결론을 요청하는 것보다 기준을 나누어 단계별로 검토하게 하면 답변이 더 안정적입니다.

### 이번 단계 체크

- [ ] 바로 결론을 내리지 않고 기준부터 정리했나요?
- [ ] 후보를 같은 기준으로 비교했나요?
- [ ] 최종 추천과 확인 필요 항목이 구분됐나요?

---

## 8단계. 답하기 전에 먼저 질문받기

### Ask-before-answer Prompting

답하기 전에 필요한 정보를 먼저 묻게 하는 방식입니다.

```prompt
title: 8단계 예제 - 역질문 3개 요청
description: 답변 생성 전 AI가 필요 질문을 던지도록 유도합니다.
---
나에게 맞는 [2박 3일 / 3박 4일 / 1박 2일] 여름휴가 계획을 세우고 싶어.

바로 계획을 만들지 말고, 먼저 나에게 확인해야 할 질문 3개를 해 줘.
```

```prompt
title: 8단계 실습 - 질문 근거 포함 역질문 요청
description: 역질문 3개와 함께 질문 사유를 설명하도록 지시합니다.
---
지금 바로 여행 계획을 확정하지 말고, 더 정확한 추천을 위해 나에게 먼저 확인해야 할 질문 3개를 해 줘.

각 질문 옆에는 왜 필요한 질문인지도 한 줄로 적어 줘.
```

### 이번 단계에서 확인할 점

AI가 내가 빠뜨린 조건을 먼저 찾아주는지 확인합니다.

좋은 프롬프트는 답을 바로 받는 것이 아니라, 필요한 질문을 먼저 받는 방식도 포함합니다.

### 이번 단계 체크

- [ ] AI가 빠진 정보를 찾기 위한 질문을 했나요?
- [ ] 각 질문이 왜 필요한지 설명했나요?
- [ ] 질문에 답한 뒤 결과가 더 구체적으로 달라졌나요?

---

## 9단계. AI 답변 다시 검토하기

### Self-Reflection / Critique Prompting

AI 답변을 다시 검토하게 하는 방식입니다.

```prompt
title: 9단계 예제 - 검토 및 허점 점검 요청
description: 무리한 일정, 초과 예산, 사실 확인 필요 항목을 점검합니다.
---
위 여행 계획을 다시 검토해 줘.

현실성이 낮은 부분, 이동 시간이 무리한 부분, 예산이 초과될 수 있는 부분, 사실 확인이 필요한 항목을 따로 표시해 줘.
```

```prompt
title: 9단계 실습 - 5가지 검토 항목 분류 작성
description: 무리한 일정, 예산, 개선점 3가지 등을 체계적으로 도출합니다.
---
지금까지 나온 여행 계획을 검토해 줘.

아래 항목으로 나누어 정리해 줘.

- 무리한 일정
- 예산 초과 가능성
- 빠진 조건
- 최신 확인이 필요한 항목
- 수정하면 더 좋아질 점 3가지
```

### 이번 단계에서 확인할 점

AI 답변을 완성본이 아니라 초안으로 점검할 수 있는지 확인합니다.

특히 운영시간, 가격, 교통편, 예약 여부처럼 실제 정보는 반드시 다시 검토해야 합니다.

### 이번 단계 체크

- [ ] 무리한 일정과 예산 초과 가능성이 표시됐나요?
- [ ] 빠진 조건과 최신 확인 항목이 구분됐나요?
- [ ] AI의 답을 그대로 확정하지 않고 초안으로 검토했나요?

## 10단계. 여러 번 이어서 완성하기

### Prompt Chaining

하나의 큰 요청을 한 번에 처리하지 않고, 앞 단계의 결과를 다음 단계의 재료로 이어 가는 방식입니다.

```prompt
title: 10단계 예제 - 6단계 프롬프트 체이닝 구조 정의
description: 1~6단계 흐름을 설계하고 첫 번째 단계만 먼저 시작시킵니다.
---
아래 순서로 하나씩 진행해 줘.

1단계: 내 여행 조건을 정리해 줘.
2단계: 조건에 맞는 여행지 후보 3곳을 비교해 줘.
3단계: 내가 선택한 여행지를 기준으로 2박 3일 일정표를 만들어 줘.
4단계: 일정표를 바탕으로 예산표를 만들어 줘.
5단계: 준비물 체크리스트를 만들어 줘.
6단계: 마지막으로 현실성이 낮은 부분과 사실 확인이 필요한 항목을 표시해 줘.

지금은 1단계만 먼저 진행해 줘.
```

```prompt
title: 10단계 실습 - 체이닝 1단계 시작 지시
description: 한 번에 전체를 출력하지 않고 1단계 여행 조건 정리부터 진행합니다.
---
이번 여행 계획을 한 번에 완성하지 말고, 아래 순서로 하나씩 진행해 줘.

1단계: 여행 조건 정리
2단계: 여행지 후보 3곳 비교
3단계: 선택한 여행지의 2박 3일 일정표 작성
4단계: 예산표 작성
5단계: 준비물 체크리스트 작성
6단계: 최종 점검

먼저 1단계 여행 조건 정리부터 시작해 줘.
```

### 이번 단계에서 확인할 점

Step-by-step은 한 번의 답변 안에서 순서를 나누는 방식이고, Prompt Chaining은 여러 번의 질문을 이어 가며 결과물을 점점 완성하는 방식입니다.

### 이번 단계 체크

- [ ] 한 번에 전체 결과를 만들지 않고 1단계부터 시작했나요?
- [ ] 앞 단계의 결과가 다음 단계의 재료로 사용됐나요?
- [ ] 여러 번의 대화를 거치며 결과물이 점점 완성됐나요?

# 최종 프롬프트 만들기

## 초보자용 빈칸 채우기 버전

아래 프롬프트의 대괄호 안 내용을 내 상황에 맞게 바꿔 넣으세요.

```prompt
title: 최종 프롬프트 (초보자용 대괄호 조합 템플릿)
description: 괄호 안의 선택지나 자유 입력값을 내 상황에 맞게 바꿔 완성하는 최종 프롬프트입니다.
---
너는 직장인을 위한 여행 플래너야.

나는 [출발지]에 사는 직장인이고, 퇴근 후 준비 시간이 많지 않아.
[7월 말 / 8월 초 / 8월 중순]에 [2박 3일 / 3박 4일] 동안 여름휴가를 가려고 해.

예산은 1인 [60만 원 / 40만 원 / 80만 원] 이하이고, [대중교통 / 자차 / 렌터카] 중심으로 이동하고 싶어.
너무 빡빡한 일정은 피하고, 휴식과 맛집 방문을 적절히 섞어 줘.

바로 계획을 만들기 전에, 나에게 먼저 확인해야 할 질문 5개를 해 줘.

내가 답변하면 그 내용을 바탕으로 날짜별 일정표와 준비물 체크리스트를 만들어 줘.

마지막에는 이동 시간, 예산, 운영시간, 입장료, 교통편, 예약 필요 여부처럼 사실 확인이 필요한 항목을 따로 표시해 줘.
확실한 정보와 확인이 필요한 정보를 구분해서 정리해 줘.
```

## 구조화된 마크다운 버전

같은 요청도 입력 방식을 나누면 더 쉽게 수정하고 재사용할 수 있습니다.

```prompt
title: 최종 프롬프트 (구조화된 마크다운 섹션 템플릿)
description: 역할, 상황, 조건, 작업 방식, 출력 형식, 검토 요청을 명확히 구분한 고급 프롬프트입니다.
---
### 역할
너는 직장인을 위한 여행 플래너야.

### 상황
나는 [출발지]에 사는 직장인이고, 퇴근 후 준비 시간이 많지 않아.
[7월 말 / 8월 초 / 8월 중순]에 [2박 3일 / 3박 4일 / 1박 2일] 동안 여름휴가를 가려고 해.

### 조건
예산은 1인 [60만 원 / 50만 원] 이하야.
[대중교통 / 자차] 중심으로 이동하고 싶어.
너무 빡빡한 일정은 피하고, 휴식과 맛집 방문을 적절히 섞어 줘.

### 작업 방식
바로 계획을 만들기 전에, 나에게 먼저 확인해야 할 질문 5개를 해 줘.
내가 답변하면 그 내용을 바탕으로 여행 계획을 작성해 줘.

### 출력 형식
날짜별 일정표로 정리해 줘.
마지막에는 준비물 체크리스트를 함께 만들어 줘.

### 검토 요청
이동 시간이 무리한 부분, 예산이 초과될 수 있는 부분, 일정이 너무 빡빡한 부분을 알려 줘.

### 확인 필요 항목
운영시간, 입장료, 교통편, 예약 필요 여부처럼 사실 확인이 필요한 항목은 따로 표시해 줘.
확실한 정보와 확인이 필요한 정보를 구분해서 정리해 줘.
```

# 마지막으로 기억할 점

좋은 프롬프트는 처음부터 한 번에 완성되지 않습니다.

같은 주제를 두고 역할, 상황, 조건, 예시, 출력 형식, 단계별 검토, 먼저 질문하기, 답변 검토, 작업 연결을 하나씩 더하면 최종 프롬프트가 완성됩니다.

AI가 만든 여행 계획은 완성본이 아니라 초안입니다. 특히 운영시간, 가격, 교통편, 예약 여부처럼 실제 여행에 영향을 주는 정보는 반드시 다시 확인해야 합니다.
