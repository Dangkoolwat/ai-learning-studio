# 먼저 진단받기 ⭐

## 언제 사용하나요?

**⭐ 문제 진단을 위한 대표 프롬프트 (마스터 프롬프트)**

AI에게 무작정 "새로 써줘"라고 요청하기 전에, 내 글이나 아이디어에 어떤 문제가 있는지 객관적으로 파악하고 싶을 때 사용합니다. 
AI를 단순한 작성 도구가 아닌 **'문제 진단 파트너'** 로 활용하는 가장 좋은 방법입니다.

## 대표 프롬프트 ⭐

내 글, 계획, 아이디어 등을 붙여 넣고 전반적인 진단을 받아보세요.

```prompt
title: 마스터 진단 프롬프트
description: 여러 관점에서 문제점을 파악하고 우선순위를 알려줍니다.
---
아래 내용을 바로 수정하거나 새로 작성하지 말고, 먼저 문제점과 놓친 부분부터 찾아줘.

"[여기에 글, 계획, 아이디어 등을 붙여넣기]"

다음 6가지 관점에서 객관적으로 확인해줘.

1. 빠진 내용은 없는지
2. 앞뒤가 맞지 않는 부분은 없는지
3. 상대방 입장에서 이해하기 어려운 부분은 없는지
4. 내가 당연하다고 생각해서 설명하지 않은 부분은 없는지
5. 불필요하거나 중요도가 낮은 내용은 없는지
6. 추가로 확인해야 할 사실이나 정보는 없는지

발견된 문제를 중요도 순으로 정리하고, 각 문제마다 왜 문제가 되는지 짧게 설명해줘.
바로 전체를 다시 작성하지 말고, '먼저 무엇을 고치면 좋을지' 방향을 알려줘.

마지막에는 「가장 먼저 고칠 것 [ 3가지 / 5가지 ]」를 우선순위로 정리해줘.
```

## 💡 AI 활용 TIP

- 프롬프트 엔지니어링의 핵심은 AI를 검색 엔진이 아닌 **'실무 담당자'** 로 대하는 것입니다. 
- 막막할 때는 무조건 **"이 작업을 네가 완벽하게 수행하려면 나에게 어떤 정보를 더 물어봐야 해?"** 라고 역질문을 유도해 보세요.
- 초안을 완벽하게 쓰려고 스트레스 받지 마세요. 생각나는 대로 대충 적어 넣은 뒤, 이 마스터 프롬프트로 진단을 받는 것이 훨씬 효율적입니다.
