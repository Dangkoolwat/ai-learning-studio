# 이어서 작업하기

## 언제 사용하나요?

AI가 답변을 하다가 길이나 토큰 제한 때문에 중간에 뚝 끊겼을 때, 혹은 지금 나온 답변의 방향성이 좋아서 더 깊이 파고들고 싶을 때 사용합니다.

처음부터 다시 지시할 필요 없이, 문맥을 완벽히 유지한 채 자연스럽게 작업을 이어갈 수 있습니다.

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 끊긴 곳부터 이어서
description: 중단된 문장 복구
---
답변이 중간에 끊겼습니다. 마지막으로 쓰다 만 문장부터 정확히 이어서 끝까지 작성해 줘.
```

## 추가 프롬프트

```prompt
title: 다음 단계 제안 받기
description: 흐름을 타는 연속 작업
---
지금까지의 결과물이 아주 마음에 듭니다. 이 내용을 바탕으로 내가 다음 단계로 진행하면 좋을 후속 액션 3가지를 제안해 줘.
```

```prompt
title: 특정 부분 심화
description: 원하는 부분만 줌인(Zoom-in)
---
네가 말한 내용 중에 '2번 항목'이 제일 흥미로워. 다른 건 제외하고 2번 항목에 대해서만 3배 더 자세하게 파고들어 줘.
```
