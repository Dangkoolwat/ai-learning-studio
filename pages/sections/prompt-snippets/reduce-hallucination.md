# 할루시네이션 줄이기 ⭐

## 언제 사용하나요?

AI가 사실과 다르게 지어낸 내용(환각 현상, Hallucination)을 말하는 것을 방지하고 싶을 때 꼭 사용해야 하는 필수 조미료입니다.

법률, 의료, 최신 뉴스, 통계 등 정확한 사실이 매우 중요한 영역에서 정보를 탐색할 때 사용하면, AI가 모르는 것을 억지로 꾸며내는 확률을 크게 줄일 수 있습니다.

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 모르면 모른다고 하기
description: 환각을 방지하는 가장 확실한 방어막
---
이 질문에 대해 명확하고 검증된 사실만 대답해 줘. 만약 정확히 모르거나 확신할 수 없는 내용이라면, 절대로 지어내지 말고 '모른다'고 대답해 줘.
```

## 추가 프롬프트

```prompt
title: 공식 출처 명시
description: 정보의 신뢰성 검증
---
위 답변을 작성할 때 참고한 공식적인 출처나 문헌 근거를 링크와 함께 명시해 줘. 근거가 없는 내용은 제외해 줘.
```

```prompt
title: 팩트와 의견 분리
description: 주관적 판단과 객관적 사실 분리
---
위의 내용 중에서 '객관적으로 증명된 사실(Fact)'과 '너의 추정이나 주관적 의견(Opinion)'을 명확하게 분리해서 정리해 줘.
```

## 💡 AI 활용 TIP

- 중요한 내용은 반드시 검증하세요.
- 최신 정보는 교차 검증(구글 검색 등)을 통해 다시 확인하세요.
- AI는 추정 내용을 사실처럼 말할 수도 있으므로 맹신은 금물입니다.
