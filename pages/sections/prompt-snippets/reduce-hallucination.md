# 할루시네이션 줄이기 ⭐

## 언제 사용하나요?

AI가 모르는 것을 마치 사실처럼 그럴듯하게 지어내는 현상을 **'할루시네이션(환각)'**이라고 합니다.

단순한 글쓰기나 아이디어 발상에서는 큰 문제가 없지만, 정확한 사실 확인이 필요한 업무나 학습에서는 치명적인 결과를 초래할 수 있습니다. 따라서 AI의 답변을 맹신하지 않고, **비판적으로 검토하고 출처를 검증하도록 유도할 때** 이 조미료가 필요합니다.

**🚨 AI가 특히 틀리기 쉬운 경우 (주의 구간)**

아래와 같은 주제를 질문할 때는 AI가 거짓말을 하거나 존재하지 않는 출처를 지어낼 확률이 매우 높으므로, 반드시 아래의 검증 프롬프트를 함께 사용해야 합니다.
- **최신 정보**
- **법률**
- **의료**
- **통계**
- **논문**
- **회사 정책**
- **서비스 기능**
- **요금제**
- **AI가 존재하지 않는 사실이나 가짜 출처(링크)를 생성하는 경우**

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 완벽한 사실 검증 콤보
description: 할루시네이션 의심 구간을 원천 차단하고 출처를 꼼꼼히 확인합니다.
---
네가 작성한 답변에 대해 다음 5가지를 엄격하게 검증하고 다시 정리해 줘.
1. 객관적으로 확인된 '사실(Fact)'과 너의 '추정(Opinion)'을 명확히 구분할 것.
2. 100% 확신할 수 없거나 추가 확인이 필요한 내용은 [확인 필요] 태그를 붙일 것.
3. 이 정보가 언제를 기준으로 한 최신 정보인지 명시할 것.
4. 주요 주장에 대해 공식 자료나 신뢰할 수 있는 출처(링크 등)를 제공할 것.
5. AI로서 지어냈을(할루시네이션) 가능성이 조금이라도 의심되는 문장이 있다면 스스로 짚어내고 정정할 것.
```

## 추가 프롬프트

```prompt
title: 최신 정보 확인
description: 현재 시점 기준의 유효성 검증
---
이 정보의 기준 시점은 언제야? 가장 최근에 업데이트된 최신 정보인지 교차 검증해서 알려줘.
```

```prompt
title: 공식 출처 요청
description: 신뢰할 수 있는 레퍼런스 확보
---
위 답변에 대한 공식 문서나 신뢰할 수 있는 레퍼런스(논문, 통계청 자료, 공식 웹사이트 등)의 정확한 출처와 링크를 명시해 줘.
```

```prompt
title: 사실과 의견 구분
description: 주관과 객관의 분리
---
답변 내용 중 명백한 사실(Fact)과 너의 주관적 추정이나 의견(Opinion)을 분리해서 표로 정리해 줘.
```

```prompt
title: 논리 검토
description: 스스로 비판적 검토
---
네가 작성한 논리에 모순이 없는지 스스로 비판적인 시각에서 검토하고, 오류나 비약이 있다면 수정해 줘.
```

```prompt
title: 빠진 내용 찾기
description: 편향성 및 누락 방지
---
이 주제와 관련하여 꼭 다루어야 하지만, 현재 답변에서 누락된 중요한 사실이나 반대 의견이 있다면 3가지 추가해 줘.
```

```prompt
title: 신뢰도 평가
description: 정보의 확실성 자가 진단
---
네가 방금 제공한 답변의 정보 신뢰도를 1~100점으로 평가한다면 몇 점인지 말해주고, 그 이유를 설명해 줘.
```

## 💡 AI 활용 TIP

- AI는 그럴듯한 거짓말을 확신 있게 할 수도 있습니다.
- 중요한 결정에 필요한 내용은 AI의 답변을 믿지 말고, 반드시 교차 검증하세요.
- 최신 정보나 법률/요금제는 시간이 지나면서 수시로 변경될 수 있습니다.
- AI가 제시한 출처(링크나 논문 이름)가 있다고 해서 항상 정확한 것은 아니며, 가짜 출처일 수도 있습니다.

---
**📌 참고**
AI 모델마다 이해 방식과 지원 기능이 다르므로 같은 프롬프트라도 결과가 달라질 수 있습니다. 필요하면 조건을 추가하거나 여러 번 수정하며 원하는 결과를 만들어 보세요.
