# 설명 수준 바꾸기

## 언제 사용하나요?

AI가 너무 전문적인 용어를 써서 이해하기 어렵거나, 반대로 너무 유치하게 설명해서 비즈니스에 쓰기 부적절할 때 사용합니다.

같은 내용이라도 '누구에게' 말하느냐에 따라 찰떡같은 비유와 어휘로 내용을 완벽하게 번역해 줍니다.

## 이렇게 요청해 보세요.

```prompt
title: 초등학생 눈높이
description: 가장 쉽고 직관적인 비유
---
이 복잡한 개념을 이 분야에 대해 전혀 모르는 초등학교 5학년 학생도 단번에 이해할 수 있게, 일상생활의 쉬운 비유를 들어서 설명해 줘.
```

## 추가 프롬프트

```prompt
title: 비즈니스 전문가 톤
description: 보고서 및 실무용 톤
---
위 내용을 우리 회사 임원진에게 보고할 목적으로, 감정적인 표현은 배제하고 데이터와 논리 중심의 객관적이고 격식 있는 톤으로 다시 써 줘.
```

```prompt
title: 동네 친구 톤
description: 친근하고 편안한 톤
---
딱딱하게 설명하지 말고, 친한 동네 친구한테 카페에서 수다 떨면서 알려주듯이 아주 친근하고 편안한 말투로 바꿔서 말해 줘.
```

## 함께 사용하면 좋은 프롬프트

글 다듬기 ➔ 설명 수준 바꾸기 ➔ 보기 쉽게 정리하기

## 💡 TIP

- 대상을 구체적으로 지정할수록 좋습니다. '쉽게 설명해 줘'보다 '코딩을 처음 배우는 문과생에게 설명해 줘'가 훨씬 강력합니다.
