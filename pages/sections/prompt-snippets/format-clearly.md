## 언제 사용하나요?

AI의 답변이 너무 길고 줄글로만 되어 있어서, 내용을 한눈에 파악하기 어렵거나 실무(보고서, 이메일, 코드 등)에 바로 붙여넣기 불편할 때 사용합니다.

단순 텍스트를 다음과 같이 시각적으로 정돈되거나 바로 활용할 수 있는 다양한 포맷으로 순식간에 바꿔줍니다.

**💡 변환 가능한 유용한 포맷 예시**
- 표 (Table)
- 엑셀 (Excel)
- 워드 (Word)
- 타임테이블 (일정표)
- 체크리스트
- 마크다운 (Markdown)
- PPT (슬라이드 개요)
- 보고서 (기획서 형태)
- 비즈니스 이메일
- JSON / CSV (데이터 포맷)

---

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 다양한 포맷으로 깔끔하게 정리
description: 정보 비교와 가독성 극대화
---
위에서 설명한 내용들을 한눈에 비교하고 파악할 수 있도록 "[보기 좋은 표(Table) / 엑셀 (Excel) / 워드 (Word) / 타임테이블 (일정표) / 체크리스트 / 마크다운 (Markdown) / PPT (슬라이드 개요) / 보고서 (기획서 형태) / 비즈니스 이메일 / JSON / CSV (데이터 포맷)]" 형식으로 정리해 줘.
```

---

## 추가 프롬프트

```prompt
title: 마크다운 헤더 정리
description: 블로그/문서용 포맷 변환
---
이 내용을 블로그 포스팅에 바로 쓸 수 있게 적절한 제목(H2)과 소제목(H3), 그리고 불릿 포인트를 활용한 마크다운 형식으로 재구성해 줘.
```

```prompt
title: 마인드맵 구조화
description: 계층형 트리 구조로 파악
---
위 내용을 최상위 주제부터 하위 세부 내용까지 마인드맵이나 계층형 트리(Tree) 구조로 보기 쉽게 나열해 줘.
```

## 💡 AI 활용 TIP

- 표로 만들어달라고 할 때 '항목, 장점, 단점, 비용으로 열(Column)을 구성해 줘'처럼 열 이름을 직접 지정해주면 훨씬 원하는 표를 얻을 수 있습니다.
