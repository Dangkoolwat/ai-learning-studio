# 요약과 핵심 정리

## 언제 사용하나요?

긴 뉴스 기사, 방대한 보고서, 혹은 AI의 지나치게 긴 답변을 끝까지 읽을 시간이 없을 때 유용합니다.

빠르게 전체 맥락을 파악하거나, 가장 중요한 결론 3가지만 도출하고 싶을 때 한 줄 조미료로 시간을 절약하세요.

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 핵심 3줄 요약
description: 가장 빠르고 간결한 요약
---
아무리 바빠도 이 글의 전체 맥락을 바로 이해할 수 있도록, 가장 중요한 핵심 내용만 딱 3줄(3문장)로 요약해 줘.
```

## 추가 프롬프트

```prompt
title: 결론 먼저 (TL;DR)
description: 두괄식 결론 도출
---
긴 설명은 다 빼고, 그래서 내가 구체적으로 무엇을 해야 하는지(Action Item) 결론만 먼저 3가지 불릿 포인트로 제시해 줘.
```

```prompt
title: 5세 요약 (ELI5)
description: 쉽고 짧은 요약 결합
---
이 긴 글의 핵심 주제가 무엇인지, 유치원생도 이해할 수 있게 딱 한 문장으로 압축해서 말해 줘.
```
