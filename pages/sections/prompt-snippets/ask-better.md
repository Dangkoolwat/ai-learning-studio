## 언제 사용하나요?

단순한 '질문'이 아니라, 명확한 '작업 요청'을 하고 싶은데 내 상황을 어떻게 프롬프트로 표현해야 할지 막막할 때 사용하는 마법의 한 스푼입니다.

내가 프롬프트를 고민하는 대신, AI가 이 작업을 수행하기 위해 필요한 정보를 나에게 먼저 캐묻게 하여 완벽한 작업 요청서를 함께 완성해 나갑니다.

---

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 완벽한 작업을 위한 역질문
description: AI가 작업 컨설턴트가 되게 하기
---
내가 이 작업을 완벽하게 달성하고 싶은데 프롬프트를 어떻게 써야 할지 잘 모르겠어. 네가 이 작업을 훌륭하게 수행하기 위해 내가 더 알려줘야 할 정보가 있다면 나에게 "[3가지/ 5가지]" 질문을 먼저 던져 줘.
```

---

## 추가 프롬프트

```prompt
title: 부족한 정보 질문 유도
description: 최적의 결과를 위한 역질문
---
현재 요청만으로는 최적의 결과를 만들기 어렵다면, 바로 작업하지 말고 먼저 필요한 정보를 나에게 질문해 주세요.
```

```prompt
title: 역할 및 형식 제안받기
description: 전문가의 시각에서 역제안
---
최고의 결과를 얻기 위해 적합한 역할(Role), 출력 형식, 추가 조건이 있다면 먼저 제안하고 반영해 주세요.
```

```prompt
title: 목적만 던지고 맡기기
description: 작업 방향성 컨설팅 받기
---
나의 최종 목표는 "[목표]"야. 이 목표를 달성하기 위해 내가 지금 너에게 어떤 형태로 작업 요청을 하는 것이 가장 똑똑한 방법일까?
```

```prompt
title: 요청서 개선 받기
description: AI에게 내 프롬프트 피드백 받기
---
내가 방금 쓴 작업 요청(프롬프트)을 평가해 줘. 네가 더 완벽한 결과물을 만들기 위해 내 프롬프트의 어느 부분을 어떻게 고치면 좋을지 조언해 줘.
```

## 💡 AI 활용 TIP

- 프롬프트 엔지니어링의 핵심은 AI를 검색 엔진이 아닌 '실무 담당자'로 대하는 것입니다.
- 막막할 때는 무조건 '네가 이 작업을 하려면 나한테 뭘 물어봐야 해?'라고 역질문을 유도해 보세요.
