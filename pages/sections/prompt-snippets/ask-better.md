# AI에게 질문 잘하기

## 언제 사용하나요?

무언가 질문하고 싶은데 내 상황을 어떻게 프롬프트로 표현해야 할지 막막할 때 가장 유용한 마법의 조미료입니다.

내가 프롬프트를 고민하는 대신, AI가 나에게 필요한 정보를 먼저 캐묻게 하여 완벽한 프롬프트를 함께 완성해 나갑니다.

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 완벽한 결과를 위한 역질문
description: AI가 인터뷰어가 되게 하기
---
내가 이 작업을 완벽하게 달성하고 싶은데 프롬프트를 어떻게 써야 할지 잘 모르겠어. 나에게 최고의 결과를 주기 위해 내가 더 알려줘야 할 정보가 있다면 나에게 3가지 질문을 먼저 던져 줘.
```

## 추가 프롬프트

```prompt
title: 목적만 던지고 맡기기
description: 방향성 컨설팅 받기
---
나의 최종 목표는 [목표]야. 이 목표를 달성하기 위해 내가 지금 너에게 어떤 질문이나 요청을 하는 것이 가장 똑똑한 방법일까?
```

```prompt
title: 프롬프트 개선 요청
description: AI에게 내 프롬프트 피드백 받기
---
내가 방금 쓴 질문(프롬프트)을 평가해 줘. 네가 더 정확한 답변을 하기 위해 내 프롬프트의 어느 부분을 어떻게 고치면 좋을지 조언해 줘.
```
