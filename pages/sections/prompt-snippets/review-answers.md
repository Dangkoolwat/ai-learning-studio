# AI 답변 검토하기

## 언제 사용하나요?

AI가 작성해 준 보고서나 코드가 완벽해 보이지만, 놓친 부분이 없는지 확신이 서지 않을 때 사용합니다.

AI를 나만의 '크로스 체커(교차 검증자)'로 활용하여 스스로 작성한 결과물에서 논리적 비약이나 치명적인 오류를 찾아내게 합니다.

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 셀프 리뷰 요청
description: 자신의 답변을 비판적으로 재검토합니다.
---
네가 방금 작성한 내용에서 논리적으로 빈약한 부분이나, 현실적으로 적용하기 어려운 치명적인 단점이 있다면 가감 없이 짚어줘.
```

## 추가 프롬프트

```prompt
title: 빠진 내용 찾기
description: 누락된 핵심 정보를 찾아 보완
---
이 주제를 다룰 때 반드시 들어가야 하지만, 현재 답변에서 누락되었거나 부족하게 다뤄진 핵심 정보가 있다면 알려줘.
```

```prompt
title: 실행 가능성 검토
description: 현실적인 문제점 진단
---
이 계획을 당장 내일부터 현실에 적용한다고 했을 때, 가장 먼저 부딪힐 3가지 예상 문제점과 해결책을 검토해 줘.
```

## 💡 AI 활용 TIP

- 검토 요청 프롬프트를 사용할 때는 AI에게 '비판자' 역할을 명확히 부여하면 결과가 훨씬 날카로워집니다.
- 오류가 발견되면 '지적한 내용을 반영해서 본문을 다시 수정해 줘'라고 이어서 요청해 보세요.

---
> **📌 참고**
> AI 모델마다 이해 방식과 지원 기능이 다르므로 같은 프롬프트라도 결과가 달라질 수 있습니다. 필요하면 조건을 추가하거나 여러 번 수정하며 원하는 결과를 만들어 보세요.
