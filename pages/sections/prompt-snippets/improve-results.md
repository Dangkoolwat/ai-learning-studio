# 결과를 더 좋게 만들기

## 언제 사용하나요?

**⭐ 가장 많이 사용하는 프롬프트 (한 스푼)**

AI가 준 첫 번째 답변이 어딘가 부족하거나 평범하게 느껴질 때 사용합니다.

새로운 프롬프트를 처음부터 다시 고민할 필요 없이, 기존 답변을 바탕으로 AI 스스로 내용을 보강하고 깊이를 더하도록 유도할 수 있습니다.

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 더 구체적으로 만들기
description: 현재 답변에 디테일을 더해 풍성하게 만듭니다.
---
지금 답변 내용이 너무 포괄적입니다. 구체적인 실제 사례나 예시를 3가지 이상 추가해서 더 상세하게 설명해 줘.
```

## 추가 프롬프트

```prompt
title: 한 줄로 쉽게 설명하기 (ELI15)
description: 15세 눈높이로 전문 용어는 보존하고 쉬운 예시를 곁들여 설명
---
/ELI15 위 내용을 처음 배우는 15살도 이해할 수 있게 쉽게 설명해 줘. 전문 용어가 필요하다면 빼지 말고, 쉬운 말이나 예시를 함께 덧붙여 줘.
```

```prompt
title: 초단축형 ELI15
description: 가장 짧게 바로 입력하는 한 줄 프롬프트
---
/ELI15 위 내용을 쉽게 설명해 줘.
```

```prompt
title: 비판적 시각 추가
description: 답변의 신뢰도를 높이기 위한 다각도 분석
---
네가 방금 한 주장에 대해, 스스로 반대되는 논거나 예상되는 비판점을 3가지 제시하고 방어해 줘.
```

```prompt
title: 전문가 톤 적용
description: 업무에 바로 쓸 수 있는 형태로 변환
---
위 내용을 이 분야의 10년 차 전문가가 신입 사원에게 조언해 주는 듯한 논리적이고 전문적인 톤으로 다시 작성해 줘.
```

```prompt
title: 범용 제약 조건(Constraint) 템플릿
description: 원하는 포맷과 규칙으로 엄격하게 통제
---
앞선 답변의 핵심 내용은 유지하면서 다음 조건을 반영하여 다시 작성해 주세요.

- [500자 이내 / 표로 작성 / 전문 용어 사용 금지 / 초보자 수준 등 자유롭게 입력]
```

## 💡 AI 활용 TIP

- **AI의 첫 번째 답변은 초안입니다**: 만족스러운 결과가 나올 때까지 이 한 스푼들을 번갈아 사용하며 답변을 조각해 나가는 것이 프롬프트 활용의 핵심입니다.
- **이건 진짜 프로그래밍 명령어인가요?**: `ELI15`는 **Explain Like I'm 15(15살에게 설명하듯)**의 줄임말입니다. `/ELI15`, `/ELI5`, `/TLDR` 같은 슬래시(`/`) 표현은 숨겨진 시스템 명령어가 아니라, 약어의 의미를 읽은 AI가 '쉬운 눈높이로 설명해 달라'는 요청으로 해석하는 것입니다. **ChatGPT는 물론 Gemini, Claude 등 주요 AI 모델에서 모두 동일하게 잘 작동**하며, 코드를 외우는 것보다 내가 원하는 설명 수준을 AI에게 명확히 전달하는 것이 더 중요합니다.
- **왜 5살(ELI5)이 아니라 15살(ELI15)인가요?**: 5살 아이 눈높이(`ELI5`)는 지나친 비유로 핵심 정보나 인과관계가 생략되기 쉽습니다. 15세 눈높이는 어려운 전문 용어는 쉬운 예시로 풀되, 동작 원리와 논리 구조를 온전히 유지할 수 있는 가장 실용적인 기준입니다.

**📌 참고**
AI 모델마다 이해 방식과 지원 기능이 다르므로 같은 프롬프트라도 결과가 달라질 수 있습니다. 필요하면 조건을 추가하거나 여러 번 수정하며 원하는 결과를 만들어 보세요.
