# 글 다듬기

## 언제 사용하나요?

내가 쓴 초안이 어딘가 어색하거나, 번역기 말투처럼 부자연스러울 때 문맥을 윤문(다듬기)하기 위해 사용합니다.

오탈자 수정은 물론, 글의 리듬감을 살리고 중복된 표현을 제거하여 사람이 직접 공들여 쓴 것 같은 세련된 글로 만들어줍니다.

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 자연스러운 윤문
description: 어색함 제거 및 리듬감 부여
---
내가 작성한 이 글의 원본 의미는 100% 유지하면서, 문법적 오류를 고치고 문맥이 훨씬 자연스럽게 물 흐르듯 읽히도록 다듬어 줘.
```

## 추가 프롬프트

```prompt
title: AI 티 없애기
description: 기계적인 말투 제거
---
글에서 흔히 보이는 뻔한 AI 말투(예: 결론적으로, 요약하자면 등)를 모두 없애고, 실제 사람이 브런치나 블로그에 감성적으로 쓴 글처럼 고쳐 줘.
```

```prompt
title: 강력하고 간결하게
description: 힘 있는 문장으로 교정
---
불필요한 수식어나 중복된 단어를 모두 제거하고, 문장을 짧고 힘 있는 단문 위주로 강력하게 재작성해 줘.
```

## 💡 AI 활용 TIP

- 글을 다듬을 때는 '원본의 길이를 유지해 줘' 혹은 '원본보다 20% 짧게 쳐내 줘'처럼 길이에 대한 지침을 주면 의도와 다르게 글이 너무 축소되는 것을 막을 수 있습니다.
