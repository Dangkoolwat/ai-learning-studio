# 비교와 분석

## 언제 사용하나요?

A와 B 중 무엇을 선택해야 할지 고민될 때, 혹은 여러 개념의 차이점을 명확히 알고 싶을 때 사용합니다.

사람이 직접 하기 번거로운 장단점 분석, 비용 비교, 상황별 추천 등을 AI가 한순간에 입체적으로 분석해 줍니다.

## 대표 프롬프트 ⭐

> **가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 장단점 극과 극 비교
description: 결정을 돕는 명확한 대조
---
A안과 B안의 장점과 단점을 극명하게 대비되도록 비교해 주고, 각각 어떤 상황에 처한 사람에게 추천하는지 분석해 줘.
```

## 추가 프롬프트

```prompt
title: 기준표 바탕 비교
description: 객관적 지표 비교
---
이 두 가지 기술(또는 제품)을 가격, 성능, 학습 난이도, 유지보수 측면의 4가지 기준으로 엄격하게 비교 평가해 줘.
```

```prompt
title: 유사점과 차이점
description: 본질적인 이해 돕기
---
이 두 개념이 표면적으로는 어떻게 유사한지 공통점을 설명하고, 본질적으로는 어떻게 다른지 핵심 차이점을 짚어 줘.
```

## 💡 AI 활용 TIP

- 비교 기준을 명확하게 함께 작성하면 결과가 훨씬 좋아집니다.
- 비교 분석을 요청한 직후에 '이 분석 결과를 표로 만들어 줘'라는 조미료를 연달아 사용하면 최고의 결과물을 얻을 수 있습니다.
