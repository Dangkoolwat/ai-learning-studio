# 다양한 아이디어 얻기

## 언제 사용하나요?

새로운 프로젝트 기획, 블로그 글감 찾기, 행사 이름 정하기 등 무언가 톡톡 튀는 아이디어가 필요할 때 사용합니다.

우리가 흔히 생각하는 뻔한 대답을 넘어, 다각도에서 바라본 창의적이고 참신한 아이디어 풀(Pool)을 AI에게 끌어내게 합니다.

## 대표 프롬프트 ⭐

**가장 많이 사용하는 대표 프롬프트입니다.** 초보자라면 고민 없이 이것부터 복사해서 바로 사용해 보세요!

```prompt
title: 극단적 브레인스토밍
description: 평범함을 거부하는 아이디어 도출
---
아주 평범하고 뻔한 아이디어는 제외하고, 약간 미쳤다 싶을 정도로 창의적이고 독특한 아이디어 5가지를 구체적으로 제안해 줘.
```

## 추가 프롬프트

```prompt
title: 타겟 변경 기법
description: 다른 시각에서 바라보기
---
만약 이 서비스를 Z세대 대학생이 아니라, 60대 은퇴자가 사용한다고 가정한다면 어떤 새로운 기능 아이디어가 필요할까?
```

```prompt
title: 스캠퍼(SCAMPER) 기법
description: 기존 아이디어 확장
---
내가 제시한 이 아이디어에 스캠퍼(SCAMPER) 기법을 적용해서, 결합(Combine)하거나 용도를 변경(Put to another use)한 새로운 버전을 만들어 줘.
```

## 💡 AI 활용 TIP

- 아이디어를 요청할 때는 '5가지', '10가지' 등 구체적인 숫자를 제시하면 좋습니다.
- 마음에 드는 아이디어가 하나 있다면, '3번 아이디어가 좋은데, 이 방향으로 5개 더 구체화해 줘'라고 이어서 좁혀나가 보세요.
