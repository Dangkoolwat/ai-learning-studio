# 결과물 다양하게 재활용하기

## 언제 사용하나요?

이미 잘 만들어진 원본을 완전히 다른 용도나 형식으로 바꿉니다.

**이런 때 사용해 보세요:**
- 블로그 글을 인스타 피드로 바꿀 때
- 보고서를 발표 대본으로 바꿀 때
- 일기를 에세이로 바꿀 때

## 짧은 프롬프트

간단하게 바로 복사해서 사용할 수 있는 짧은 프롬프트입니다.

```prompt
title: 짧은 프롬프트
description: 하나의 소스를 여러 포맷으로 변환합니다.
---
이 내용을 바탕으로 핵심만 뽑아서 [ 이메일 공지사항 / 인스타그램 피드 / 요약 보고서 / 발표 대본 ]에 맞게 완전히 새롭게 다시 써줘. 이때 전체적인 말투는 [ 정중하고 전문적으로 / 친근하고 가볍게 / 트렌디하고 위트있게 ] 작성해 주고, 비교해서 고를 수 있게 [ 3가지 / 5가지 ] 다른 버전으로 제안해줘.
```

## 범용 프롬프트

내용을 직접 붙여 넣고 더 자세하게 진단받을 수 있는 범용 프롬프트입니다.

```prompt
title: 상세 진단용 프롬프트
description: 특정 내용을 붙여 넣고 구체적인 피드백을 받습니다.
---
아래 제공하는 내용을 바탕으로, 완전히 새로운 형식의 결과물들을 만들어줘.

"[여기에 원본 내용 붙여넣기]"

이 내용을 활용해서 다음 3가지를 작성해줘.
1. 요점을 3줄로 정리한 짧은 요약본
2. 사람들의 흥미를 끌 수 있는 제목 후보 [ 3개 / 5개 / 10개 ]
3. [ 이메일 공지사항 / 인스타그램 게시글 / 블로그 포스팅 / 슬랙 메시지 ] 1개

원본의 핵심은 유지하되, 새로운 형식과 [ 정중하고 전문적인 / 친근하고 가벼운 / 트렌디하고 위트있는 ] 말투에 맞춰 분량을 조절해줘.
```
