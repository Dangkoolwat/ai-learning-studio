# 글자 조각 콜라주 프롬프트

입력한 문장을 바탕으로, 각 글자나 음절을 서로 다른 색과 질감의 찢어진 종이에 인쇄하여 손으로 하나씩 이어 붙인 듯한 자연스러운 콜라주 이미지를 생성합니다.

```prompt
title: 글자 조각 콜라주 이미지 생성
description: 문장과 배경을 선택해 아날로그 감성의 텍스트 콜라주를 만들어 보세요.
---
글자 조각을 이어 붙인 종이 콜라주 느낌으로 만들어줘.
문장: "[표현할 문장]"
각 글자나 음절은 서로 다른 색과 질감의 찢어진 종이에 인쇄된 것처럼 표현하고, 손으로 하나씩 붙인 듯 자연스럽게 배치해줘.
배경은 [따뜻한 아이보리색 종이 질감 / 화이트 종이 / 크림 베이지 / 연한 파스텔톤 / 짙은 배경 / 투명] 바탕으로 설정해줘. 
전체적으로 아날로그 수작업 콜라주 분위기를 살려줘.
한글 문장은 오탈자 없이 정확하게 표현해줘.
```
