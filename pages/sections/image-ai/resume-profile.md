인물의 표정은 [입을 다문 자연스러운 미소 / 밝고 친근한 미소 / 전문적이고 신뢰감 있는 표정 / 차분하고 단정한 표정 / 자신감 있고 활기찬 표정]으로 표현해 주세요.

시선은 [카메라를 자연스럽게 바라보기 / 카메라를 바라보며 부드럽게 미소 짓기 / 약간 측면을 바라보는 자연스러운 시선]으로 설정해 주세요.

표정이 과장되거나 입이 부자연스럽게 벌어지지 않도록 해 주세요.

눈동자의 방향과 크기를 자연스럽게 표현하고, 양쪽 눈이 서로 다른 방향을 바라보지 않도록 해 주세요.

치아가 보이는 경우에는 치아의 개수, 크기와 배열이 자연스럽게 보이도록 표현해 주세요.

11. 자세
━━━━━━━━━━━━━━━━━━━━

상반신 자세는 [어깨를 펴고 정면으로 앉거나 서 있는 자세 / 몸을 약간 돌리고 얼굴은 카메라를 바라보는 자세 / 두 손을 보이지 않게 하고 단정하게 서 있는 자세 / 팔짱을 자연스럽게 낀 전문가 자세]로 표현해 주세요.

전신 자세는 [팔을 양옆에 자연스럽게 내린 자세 / 두 손을 앞에서 단정하게 모은 자세 / 한 손을 자연스럽게 앞으로 둔 자세 / 한 손을 주머니에 가볍게 넣은 자세 / 팔짱을 낀 자신감 있는 자세]로 표현해 주세요.

어깨, 팔, 손, 다리와 발의 방향이 자연스럽게 연결되도록 해 주세요.

과도하게 모델 같은 자세, 비현실적으로 몸을 비튼 자세와 한쪽으로 지나치게 기울어진 자세는 사용하지 말아 주세요.

전신 자세에서는 양발이 바닥에 자연스럽게 닿고, 인물의 무게중심이 안정적으로 보이도록 해 주세요.

12. 체형 표현
━━━━━━━━━━━━━━━━━━━━

전신 참고 사진이 함께 첨부된 경우에는 해당 사진에서 확인되는 키, 어깨, 체형과 신체 비율을 자연스럽게 반영해 주세요.

얼굴 사진만 첨부된 경우에는 사진에서 확인할 수 없는 실제 신체 특징을 임의로 단정하지 말고, 자연스럽고 균형 잡힌 성인 체형으로 표현해 주세요.

전신 사진의 체형은 [첨부된 전신 사진을 최대한 반영 / 자연스럽고 평균적인 성인 비율 / 단정하고 균형 잡힌 체형]으로 표현해 주세요.

키, 어깨, 허리, 다리 길이와 신체 볼륨을 과도하게 늘이거나 줄이지 말아 주세요.

신체를 지나치게 마르거나 근육질로 만들지 말고, 성별을 이유로 특정 신체 부위를 과장하지 말아 주세요.

머리 크기와 신체 비율이 실제 성인 인물 사진처럼 자연스럽게 보이도록 해 주세요.

━━━━━━━━━━━━━━━━━━━━
13. 손과 발 표현
━━━━━━━━━━━━━━━━━━━━

손과 손가락의 개수와 형태를 정확하고 자연스럽게 표현해 주세요.

각 손에는 정상적인 개수의 손가락만 표현해 주세요.

손가락이 서로 붙거나 뒤틀리지 않게 하고, 추가된 손이나 사라진 손이 나타나지 않도록 해 주세요.

팔, 다리, 무릎과 발목 관절이 부자연스럽게 꺾이지 않도록 해 주세요.

두 손을 모으거나 팔짱을 낀 자세에서는 손과 팔이 서로 비정상적으로 겹치지 않도록 해 주세요.

전신 사진에서는 신발과 발끝까지 완전하게 표현하고 화면 밖으로 잘리지 않게 해 주세요.

신발의 좌우 방향과 형태가 자연스럽고, 양발이 바닥에 안정적으로 놓이도록 해 주세요.

━━━━━━━━━━━━━━━━━━━━
14. 배경
━━━━━━━━━━━━━━━━━━━━

배경은 [깨끗한 흰색 스튜디오 / 밝은 회색 스튜디오 / 연한 베이지 스튜디오 / 부드러운 크림색 배경 / 은은한 그라데이션 스튜디오 / 단정한 사무실 배경 / 전통미가 느껴지는 단순한 배경]으로 설정해 주세요.

이력서와 공식 프로필용 사진은 복잡한 소품이 없는 깨끗하고 단순한 배경으로 만들어 주세요.

한복 사진에 전통 배경을 적용하는 경우에도 궁궐, 병풍, 문양과 전통 장식을 지나치게 많이 배치하지 말고 인물이 중심이 되도록 구성해 주세요.

배경 사물이 인물의 머리, 얼굴과 신체를 가리지 않도록 해 주세요.

전신 사진에는 인물 아래에 은은하고 자연스러운 바닥 그림자를 적용해 주세요.

2×2 컬렉션을 제작하는 경우에는 네 개의 칸에 동일하거나 조화로운 배경을 적용하여 하나의 프로필 세트처럼 보이도록 해 주세요.

━━━━━━━━━━━━━━━━━━━━
15. 조명과 사진 스타일
━━━━━━━━━━━━━━━━━━━━

조명은 [밝고 균일한 증명사진 조명 / 부드럽고 자연스러운 스튜디오 조명 / 전문적이고 선명한 프로필 조명 / 따뜻하고 친근한 인물 조명 / 고급스럽고 입체적인 스튜디오 조명]으로 적용해 주세요.

얼굴 한쪽에 지나치게 강한 그림자가 생기지 않도록 해 주세요.

눈 아래, 코 옆과 턱 아래의 그림자가 지나치게 진해지지 않도록 자연스럽게 조절해 주세요.

안경을 착용한 경우 렌즈에 강한 빛이 반사되어 눈이 가려지지 않도록 해 주세요.

피부색과 의상의 실제 색상이 자연스럽고 정확하게 보이도록 표현해 주세요.

사진 스타일은 [실제 사진과 같은 사실적인 인물 촬영 / 전문 사진관에서 촬영한 프로필 사진 / 고급 인물 브랜딩 화보 / 단정한 이력서용 스튜디오 사진]으로 제작해 주세요.

일러스트, 3D 캐릭터, 만화, 회화 또는 인형처럼 표현하지 말고 실제 카메라로 촬영한 사진처럼 만들어 주세요.

16. 화면 비율과 해상도
━━━━━━━━━━━━━━━━━━━━

이미지 화면 비율은 [3:4 증명사진형 / 4:5 세로형 프로필 / 1:1 정사각형 프로필 / 9:16 세로형 전신 / 16:9 가로형 홍보 이미지]으로 제작해 주세요.

결과물은 선명한 고해상도로 제작하고 얼굴, 눈동자, 머리카락, 안경, 정장과 한복의 섬유 질감을 섬세하게 표현해 주세요.

작게 배치된 인물도 얼굴이 흐릿하거나 뭉개지지 않도록 충분한 크기와 선명도를 유지해 주세요.

특히 4종 세트를 한 장에 제작하는 경우에는 각 인물의 안면부가 충분히 크게 보이도록 여백과 인물 크기를 조절해 주세요.

얼굴의 눈, 눈썹, 코, 입술, 턱선과 헤어라인이 축소 과정에서 사라지거나 단순화되지 않도록 세밀하게 표현해 주세요.

얼굴에 과도한 선명도 효과, 인위적인 피부 필터와 빛 번짐 효과를 적용하지 말아 주세요.

인쇄물, 홈페이지, 강의 자료, 명함과 온라인 프로필에 사용할 수 있는 전문적인 품질로 완성해 주세요.

‘지정한 문구를 이미지에 표시’를 선택한 경우에는 입력한 문구의 철자, 띄어쓰기, 문장부호, 특수문자와 단어 순서를 변경하지 말고 그대로 표시해 주세요.

입력한 문구 외에 사용자가 지정하지 않은 이름, 직책, 회사명, 날짜, 숫자와 추가 문장을 임의로 만들지 말아 주세요.

회사 또는 개인 로고 적용 방식은 [로고를 넣지 않기 / 로고를 배치할 빈 공간 확보 / 첨부한 로고를 자연스럽게 배치]로 설정해 주세요.

첨부한 로고를 사용하는 경우에는 로고의 글자, 도형, 색상과 비율을 변경하거나 새롭게 해석하지 말아 주세요.

의미 없는 문자, 잘못된 한글, 임의의 로고, 서명과 워터마크를 만들지 말아 주세요.
