# AI 전문 프로필 사진 생성

기존 사진 속 인물의 얼굴과 고유한 인상을 유지하면서 의상, 배경, 조명과 구도를 전문 사진관 촬영처럼 자연스럽게 재구성하는 프롬프트입니다.

본 기능은 이력서, 회사 소개, 강사 소개, 명함, 홈페이지와 전문가 브랜딩용 프로필 사진 제작을 위한 기능입니다.

여권, 주민등록증, 운전면허증, 비자 등 공식 신분 확인용 사진에는 사용할 수 없습니다.

첨부한 인물 사진을 핵심 얼굴 참조 이미지로 사용하여, 사진 속 인물과 동일한 사람으로 즉시 알아볼 수 있는 사실적인 전문 프로필 사진 한 장을 제작해 주세요.

이 작업의 목적은 새로운 인물을 창작하는 것이 아니라, 기존 사진 속 인물의 얼굴 정체성을 유지하면서 의상, 배경, 조명과 촬영 구도를 실제 전문 사진관에서 촬영한 것처럼 자연스럽게 재구성하는 것입니다.

## 1. 사진 용도와 전체적인 인상

사진의 주요 용도는 [이력서·입사지원용 / 회사·기관 공식 프로필용 / 강사·교육자 소개용 / 전문가 브랜딩용 / 명함·홈페이지용 / SNS 비즈니스 프로필용]입니다.

전체적인 인상은 [전문적이고 신뢰감 있게 / 차분하고 단정하게 / 친근하고 따뜻하게 / 밝고 자신감 있게 / 세련되고 품위 있게] 표현해 주세요.

선택한 용도에 적합하도록 단정하고 자연스럽게 구성하되, 과도하게 연출된 광고 화보나 패션 화보처럼 표현하지 마세요.

## 2. 결과물 구성

결과물은 한 명의 인물이 나온 고해상도 상반신 프로필 사진 한 장으로 제작해 주세요.

분할 화면, 비교 이미지, 전신 사진, 여러 의상 조합, 2×2 컬렉션과 여러 장의 사진을 한 화면에 배치하지 마세요.

촬영 범위는 [가슴 위까지 보이는 상반신 / 가슴 아래까지 보이는 상반신 / 허리 위까지 보이는 상반신]으로 적용해 주세요.

인물의 얼굴이 충분히 크게 보이도록 구성하고, 머리 위와 어깨 주변에는 답답하지 않을 정도의 자연스러운 여백을 남겨 주세요.

## 3. 얼굴 정체성 유지

첨부한 사진은 단순한 분위기 참고 자료가 아니라 인물의 얼굴 정체성을 결정하는 가장 중요한 참조 이미지입니다.

생성된 인물이 첨부 사진 속 인물과 같은 사람으로 즉시 알아보이도록 다음 특징을 정확하게 유지해 주세요.

- 얼굴형과 전체적인 얼굴 비율
- 이마의 높이와 넓이
- 헤어라인과 머리 모양
- 눈의 크기, 간격, 방향과 고유한 눈매
- 눈썹의 모양, 두께와 위치
- 코의 길이, 너비와 형태
- 입술의 크기, 두께와 모양
- 볼, 광대와 턱선의 형태
- 귀의 형태와 위치
- 피부색과 자연스러운 피부 특징
- 점, 주름, 흉터 등 식별 가능한 고유한 특징
- 실제 연령대와 전체적인 분위기
- 안경을 착용한 경우 안경의 형태와 위치

얼굴의 정체성을 새롭게 해석하거나 다른 사람처럼 변경하지 마세요.

인물의 성별 표현, 인종적 특징과 실제 연령대는 첨부 사진에서 확인되는 모습 그대로 유지해 주세요.

얼굴을 임의로 서구화하거나 다른 인종적 특징으로 바꾸지 마세요.

실제보다 지나치게 젊거나 나이 들어 보이게 만들지 마세요.

눈을 크게 만들거나, 코를 높이거나, 턱을 가늘게 만드는 방식으로 얼굴을 미화하지 마세요.

얼굴의 좌우 비대칭과 고유한 눈매, 볼의 볼륨과 턱선을 과도하게 수정하지 마세요.

의상과 배경보다 얼굴 유사성과 실제 인물의 자연스러운 인상을 가장 높은 우선순위로 적용해 주세요.

## 4. 헤어스타일과 안경

헤어스타일은 [첨부 사진 그대로 유지 / 기존 헤어스타일을 유지하며 잔머리만 단정하게 정리 / 원래 인상을 해치지 않는 범위에서 자연스럽게 정돈]해 주세요.

머리 길이, 헤어라인, 가르마와 전체적인 실루엣을 임의로 크게 변경하지 마세요.

실제 머리숱을 과장해서 늘리거나 줄이지 말고, 비현실적으로 완벽한 헤어라인을 만들지 마세요.

안경은 [첨부 사진 속 착용 상태 그대로 유지 / 첨부 사진 속 안경을 자연스럽게 유지 / 안경을 제거하고 얼굴 특징은 그대로 유지]해 주세요.

안경을 유지하는 경우 안경테의 모양, 두께, 크기와 위치를 원본과 일관되게 표현하고, 렌즈 반사로 눈이 가려지지 않도록 해 주세요.

첨부 사진에 안경이 없는 경우 임의로 안경을 추가하지 마세요.

## 5. 얼굴과 피부 보정

사진 보정 정도는 [실제 모습 중심의 최소 보정 / 자연스럽고 단정한 사진관 보정]으로 적용해 주세요.

일시적인 피부 잡티, 과도한 번들거림, 심한 피로감과 촬영 환경으로 생긴 색 불균형만 자연스럽게 정돈해 주세요.

피부결, 모공, 잔주름과 실제 연령대에서 나타나는 자연스러운 특징을 완전히 제거하지 마세요.

얼굴을 다른 사람처럼 미화하거나 유명인과 비슷하게 변경하지 마세요.

얼굴형, 코, 눈, 입술, 광대와 턱의 구조를 성형한 것처럼 변경하지 마세요.

피부를 플라스틱, 밀랍 인형 또는 과도한 뷰티 필터처럼 매끄럽게 표현하지 마세요.

얼굴과 목의 피부색이 서로 다르게 보이지 않도록 자연스럽게 연결해 주세요.

## 6. 의상

의상은 [네이비 정장과 흰색 셔츠 / 차콜 정장과 흰색 셔츠 / 블랙 정장과 흰색 셔츠 / 베이지 재킷과 밝은 셔츠 / 단정한 비즈니스 캐주얼]로 구성해 주세요.

의상의 격식은 [이력서에 적합한 단정한 스타일 / 전문가다운 비즈니스 스타일 / 친근한 강사·컨설턴트 스타일 / 고급스럽고 품위 있는 스타일]로 표현해 주세요.

넥타이와 액세서리는 [의상에 맞는 단정한 넥타이 착용 / 넥타이 없이 셔츠 칼라를 단정하게 정리 / 액세서리를 최소화하여 자연스럽게 구성]해 주세요.

첨부 사진 속 인물의 실제 어깨와 체형에 자연스럽게 맞는 의상 실루엣을 적용해 주세요.

실제 체형을 과도하게 마르거나 넓어 보이도록 변경하지 마세요.

재킷의 라펠, 셔츠 칼라, 넥타이, 단추, 소매와 옷 주름을 실제 의상처럼 정확하게 표현해 주세요.

재킷과 셔츠가 신체에서 분리되어 보이거나, 칼라가 겹치거나, 단추와 넥타이 구조가 뒤틀리지 않도록 해 주세요.

지나치게 몸에 밀착된 의상, 불필요한 노출, 화려한 무늬와 비현실적인 액세서리는 사용하지 마세요.

## 7. 표정과 시선

인물의 표정은 [입을 다문 자연스러운 약한 미소 / 차분하고 신뢰감 있는 표정 / 친근하고 따뜻한 약한 미소 / 밝고 자신감 있는 자연스러운 표정]으로 표현해 주세요.

시선은 카메라 렌즈를 자연스럽게 바라보도록 해 주세요.

원본 사진에서 확인되는 인물 고유의 눈매와 표정 습관을 유지해 주세요.

미소를 적용하더라도 입꼬리를 과도하게 올리거나 얼굴 근육을 인위적으로 바꾸지 마세요.

입을 부자연스럽게 벌리거나, 치아를 임의로 생성하거나, 과장된 웃음을 만들지 마세요.

양쪽 눈동자가 서로 다른 방향을 바라보거나 시선이 어긋나지 않도록 해 주세요.

눈동자의 크기, 흰자 노출과 눈꺼풀의 형태를 자연스럽게 표현해 주세요.

## 8. 자세와 촬영 시점

상반신 자세는 [어깨를 자연스럽게 펴고 정면을 바라보는 자세 / 몸을 약간 돌리고 얼굴은 카메라를 바라보는 자세 / 편안하게 앉아 상체를 곧게 세운 자세]로 표현해 주세요.

카메라 시점은 [눈높이의 단정한 정면 시점 / 몸을 약간 돌린 자연스러운 프로필 시점 / 전문 스튜디오의 안정적인 인물 촬영 시점]으로 적용해 주세요.

몸을 약간 돌린 경우에도 얼굴 양쪽의 비율이 지나치게 달라지지 않도록 하고, 얼굴은 카메라를 자연스럽게 바라보게 해 주세요.

목, 어깨와 상체가 자연스럽게 연결되도록 표현해 주세요.

목이 지나치게 길거나 짧아 보이지 않게 하고, 한쪽 어깨가 비정상적으로 높거나 신체가 과도하게 기울어지지 않도록 해 주세요.

손은 기본적으로 촬영 범위 밖에 두어 손가락 생성 오류가 발생하지 않게 해 주세요.

팔짱, 손을 턱에 대는 자세, 과도하게 몸을 비트는 자세와 모델 같은 과장된 자세는 사용하지 마세요.

## 9. 배경

배경은 [깨끗한 흰색 스튜디오 / 밝은 회색 스튜디오 / 부드러운 크림색 스튜디오 / 연한 베이지 스튜디오 / 은은한 중성색 그라데이션 배경]으로 설정해 주세요.

배경은 실제 사진관의 배경지처럼 깨끗하고 단순하게 표현해 주세요.

복잡한 사무실, 가구, 식물, 창문, 액자, 문양과 장식물을 추가하지 마세요.

배경과 인물의 경계가 잘린 종이를 붙인 것처럼 보이지 않도록 머리카락, 귀, 어깨 주변을 자연스럽고 섬세하게 연결해 주세요.

머리카락 가장자리에 흰색 테두리, 번짐, 반투명한 흔적과 부자연스러운 배경 제거 흔적이 생기지 않도록 해 주세요.

배경 그림자는 거의 보이지 않거나 매우 부드럽고 자연스럽게 표현해 주세요.

## 10. 조명

조명은 [밝고 균일한 사진관 조명 / 부드럽고 자연스러운 스튜디오 조명 / 전문적이고 선명한 프로필 조명 / 은은한 입체감이 있는 스튜디오 조명]으로 적용해 주세요.

얼굴 전체의 피부색이 자연스럽고 균일하게 보이도록 해 주세요.

얼굴 한쪽이 지나치게 어둡거나 밝아지지 않도록 하고, 눈 아래, 코 옆과 턱 아래의 그림자는 부드럽게 표현해 주세요.

이마, 코와 볼에 과도한 광택이나 인위적인 빛 번짐이 생기지 않도록 해 주세요.

얼굴과 의상에 서로 다른 방향의 조명이 적용되지 않도록 하나의 실제 촬영 환경처럼 일관되게 표현해 주세요.

안경을 착용한 경우 렌즈 반사와 조명 번짐으로 눈이 가려지지 않도록 해 주세요.

## 11. 사진 스타일과 화면 비율

사진 스타일은 [실제 전문 사진관에서 촬영한 프로필 사진 / 단정한 이력서용 스튜디오 사진 / 자연스러운 전문가 브랜딩 사진 / 선명하고 신뢰감 있는 공식 프로필 사진]으로 제작해 주세요.

실제 카메라로 촬영한 사실적인 사진처럼 표현하고, 일러스트, 회화, 만화, 3D 캐릭터, 인형과 합성 이미지처럼 보이지 않게 해 주세요.

이미지 화면 비율은 [3:4 세로형 / 4:5 세로형 / 1:1 정사각형]으로 제작해 주세요.

선택한 비율 안에서 얼굴과 어깨가 안정적으로 배치되도록 하고, 머리나 어깨가 화면 가장자리에서 잘리지 않게 해 주세요.

배경보다 인물의 얼굴이 시각적인 중심이 되도록 구성해 주세요.

## 12. 출력 품질

결과물은 인쇄물, 이력서, 회사 홈페이지, 강의 자료, 명함과 온라인 프로필에 사용할 수 있는 고해상도로 제작해 주세요.

특히 다음 부분을 선명하고 자연스럽게 표현해 주세요.

- 눈동자와 눈꺼풀
- 눈썹과 속눈썹
- 코와 콧방울
- 입술과 입꼬리
- 턱선과 볼의 윤곽
- 헤어라인과 머리카락
- 귀와 안경테
- 셔츠 칼라와 재킷 라펠
- 넥타이, 단추와 의상 원단

과도한 선명도 효과, 인공적인 피부 필터, 색수차, 빛 번짐, 노이즈와 지나친 배경 흐림을 적용하지 마세요.

얼굴에만 과도하게 선명도가 적용되거나 의상과 목 부분이 흐릿해지지 않도록 전체 사진의 초점을 자연스럽게 유지해 주세요.

## 13. 문자와 로고

이미지에는 이름, 직책, 회사명, 날짜, 숫자, 문구, 로고, 서명과 워터마크를 넣지 마세요.

의미 없는 문자, 잘못된 한글, 임의의 영문, 사진관 로고와 생성형 이미지 표시를 만들지 마세요.

문구를 넣기 위한 과도한 빈 공간을 만들지 말고, 일반적인 전문 프로필 사진처럼 인물을 중심으로 구성해 주세요.

## 14. 공식 신분증 사진 사용 제한

이 결과물은 이력서, 회사 소개, 전문가 브랜딩과 일반 프로필 용도로만 제작해 주세요.

여권, 주민등록증, 운전면허증, 비자, 공무원증, 사원증, 자격증과 기타 공식 신분 확인용 사진으로 제작하지 마세요.

공식 신분증 규격을 흉내 내거나 여권사진이라고 표시하지 마세요.
