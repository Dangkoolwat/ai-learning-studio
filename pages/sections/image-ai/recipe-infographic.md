# 모던 레시피 인포그래픽 프롬프트 조립기

음식 이름만 입력하면 실제 재료, 분량, 조리 과정이 포함된 세련된 모던 레시피 인포그래픽을 만들어 주는 프롬프트입니다.

---

### 💡 실전 활용 꿀팁 (Quick Tips)

#### 1. 추천 음식명 선정 가이드
- 조리 과정이 명확한 대중적인 메뉴: '알리오 올리오 파스타', '클럽 샌드위치', '국물 떡볶이', '김치볶음밥', '프렌치 토스트'처럼 대중적이고 명확한 메뉴를 입력할 때 4단계 조리 일러스트와 실제 계량 수치가 가장 정확하게 매칭됩니다.
- 구체적인 메뉴명 사용: '파스타'보다는 '쉬림프 로제 파스타', '라면'보다는 '대파 해장 라면'처럼 핵심 재료가 포함된 명칭을 입력하면 더욱 풍성한 인포그래픽이 완성됩니다.

#### 2. 화면 비율별 최적 활용처
- 세로형 9:16 (릴스/쇼츠/스토리): 모바일 화면에 가득 차는 SNS 카드뉴스 및 숏폼 영상 표지로 활용하기 가장 좋습니다.
- 정방형 1:1 (인스타그램 피드): 인스타그램 피드 게시물이나 블로그 썸네일에 최적화된 레이아웃입니다.
- 가로형 16:9 (가로 콘텐츠): 유튜브 영상 중간 설명 자료나 요리 강의 프레젠테이션에 추천합니다.

#### 3. 실사 사진과 라인 아트의 조화
- 인포그래픽 하단에는 완성된 요리의 고화질 실사 사진이 배치되고, 상단 과정부에는 귀여운 미니멀 라인아트 캐릭터가 동작을 안내하여 요리 매거진 한 페이지 같은 세련된 비주얼을 제공합니다.

## 나만의 레시피 인포그래픽 프롬프트

아래에서 인포그래픽으로 만들 음식 이름을 입력하면 완벽한 지침 프롬프트가 자동으로 완성됩니다. 완성된 텍스트를 복사하여 이미지 생성 AI에 붙여 넣으세요.

```prompt-field
id: food-name
label: 음식명
placeholder: 파스타 / 샌드위치 / 떡볶이 / 김치볶음밥
description: 인포그래픽으로 만들 음식 이름을 입력하세요. 전체 프롬프트에 일괄 적용됩니다.
```

```prompt-field
id: aspect-ratio
label: 화면 비율
placeholder: 세로형 9:16 (릴스/쇼츠) / 정방형 1:1 (인스타그램) / 가로형 16:9 (가로 콘텐츠)
description: 인포그래픽의 화면 비율을 선택하세요.
```

```prompt-template
[범용 [[aspect-ratio]] 모던 레시피 인포그래픽 생성 프롬프트]

음식명: [[food-name]]

### 목표

[[food-name]]을 만드는 법을 단계별로 보여주는 [[aspect-ratio]] 모던 레시피 인포그래픽을 제작한다.

실사 음식 사진, 최소한의 수채화 워시 컬러가 더해진 미니멀 라인 아트 캐릭터, 현대적인 에디토리얼 일러스트레이션을 결합해 정보가 명확하면서도 SNS에서 시선을 끄는 세련된 레시피 콘텐츠로 표현한다.

먼저 [[food-name]]에 맞는 실제적이고 일반적인 레시피를 기준으로 다음 내용을 자동으로 구성한다.

- 음식의 특징을 설명하는 짧은 한 줄 문구
- 실제로 사용되는 대표 재료 4~6개
- 각 재료의 일반적이고 실제적인 분량
- 가장 널리 사용되는 일반적인 조리법
- 정확히 4단계로 요약한 조리 과정
- 완성 요리에 어울리는 짧은 플레이팅 팁 또는 맛있게 먹는 방법
- 음식에서 추출한 포인트 컬러 1~2개

재료명, 분량, 조리 순서, 조리 도구, 재료 상태, 아이콘, 캐릭터 행동이 서로 정확하게 일치하도록 구성한다.

잘못된 재료 조합, 비현실적인 분량, 실제 조리법과 맞지 않는 순서를 만들지 않는다.

### 1. 상단 타이틀

- 상단 중앙에 큰 한글 제목으로 “[[food-name]]”을 표시
- 제목 아래에 음식의 특징을 설명하는 짧고 자연스러운 한 줄 문구 추가
- 제목 주변에 음식이나 조리 도구와 상호작용하는 작은 미니멀 라인 아트 캐릭터 배치
- 캐릭터에는 선을 가리지 않는 매우 옅고 투명한 수채화 워시 컬러를 부분적으로 적용
- 캐릭터가 제목이나 설명 문구를 가리지 않도록 작고 절제되게 표현
- 넓은 여백을 활용한 모던 라이프스타일 매거진 스타일

### 2. 대표 재료

- [[food-name]]에 실제로 사용되는 대표 재료 4~6개를 자동으로 선정
- 일반적인 1인분을 기본 기준으로 하되, 음식 특성상 다른 기준이 더 자연스러우면 해당 기준을 사용
- 각 재료를 깨끗한 흰색 배경 위 realistic food photography, top-down view로 개별 배치
- 모든 재료 사진은 동일한 밝기, 자연광, 항공샷 시점, 사실적인 음식 질감을 유지
- 각 이미지 아래에 “재료명 + 정확한 분량”을 자연스럽고 정확한 한국어로 표기

표기 예시:

재료명
정확한 분량

- 작은 라인 아트 캐릭터들이 재료를 들고, 측정하고, 옮기거나 관찰하는 장면을 자연스럽게 추가
- 캐릭터의 행동은 해당 재료의 특성과 자연스럽게 연결
- 캐릭터의 의상, 소품 또는 신체 일부에만 희미한 수채화 워시 색감을 적용
- 실사 음식 사진과 자연스럽게 조화되도록 표현
- 캐릭터가 재료 사진이나 텍스트를 가리지 않도록 작고 절제되게 배치

### 3. 조리 과정

- [[food-name]]의 가장 일반적이고 실제적인 조리법을 기준으로 정확히 4단계로 요약
- 각 단계에 01, 02, 03, 04 번호를 명확하게 표시
- 각 단계는 다음 요소로 구성

1. 큰 단계 번호
2. 짧은 단계 제목
3. 심플한 선화 조리 아이콘
4. 짧고 이해하기 쉬운 한국어 조리 설명
5. 해당 조리 행동을 실제로 수행하는 작은 라인 아트 캐릭터

구성 형식:

01
[단계 제목]
[짧은 조리 설명]

02
[단계 제목]
[짧은 조리 설명]

03
[단계 제목]
[짧은 조리 설명]

04
[단계 제목]
[짧은 조리 설명]

- 각 단계를 얇은 점선 또는 자연스럽게 흐르는 곡선으로 연결
- 캐릭터는 썰기, 씻기, 섞기, 반죽하기, 볶기, 정제하기, 끓이기, 튀기기, 찌기, 기다리기, 맛보기, 플레이팅 등 각 단계에 맞는 행동을 정확하게 수행
- 음식에 필요하지 않은 조리 행동을 억지로 사용하지 않음
- 조리 도구, 재료 상태, 조리 순서가 실제 레시피와 자연스럽게 일치해야 함
- 아이콘, 조리 설명, 캐릭터 행동이 서로 다른 내용을 표현하지 않도록 일치시킴
- 각 캐릭터에는 음식에서 추출한 포인트 컬러를 물에 매우 연하게 번진 듯한 수채화 워시로 최소한 적용
- 컬러링은 선 내부를 완전히 채우지 않고, 붓 자국과 투명한 색 번짐이 살짝 보이는 정도로 표현

### 4. 완성 요리

- 최하단 중앙에 완성된 [[food-name]]의 먹음직스러운 realistic food photography, top-down view를 크게 배치
- 깔끔하고 실제적인 플레이팅
- 밝은 자연광
- 선명하고 사실적인 음식 질감
- 음식의 실제 형태와 색감을 자연스럽게 유지
- 완성 요리가 하단의 가장 중요한 시각적 초점이 되도록 구성

완성 요리 주변에는 다음과 같이 음식과 자연스럽게 상호작용하는 작은 라인 아트 캐릭터를 절제되게 배치한다.

- 향을 맡기
- 접시를 옮기기
- 완성된 음식을 바라보기
- 맛을 기대하기
- 기뻐하기

- 캐릭터에는 완성 요리의 색감과 조화를 이루는 옅은 수채화 워시 컬러를 부분적으로 적용
- 하단에 [[food-name]]에 어울리는 짧은 플레이팅 팁 또는 맛있게 먹는 방법을 자연스러운 한국어 한 줄로 표기

### 디자인 스타일

- modern editorial illustration
- minimalist recipe infographic
- premium lifestyle magazine layout
- realistic food photography combined with minimally watercolor-tinted line art characters
- clean white background
- 넓은 여백과 정돈된 비대칭 레이아웃
- 선명한 정보 위계와 리듬감 있는 편집 구성
- 검은색, 짙은 회색, 흰색을 중심으로 사용
- 음식에서 추출한 포인트 컬러 1~2개만 제한적으로 적용
- 실사 사진은 모두 동일한 밝기와 항공샷 시점 유지

음식 사진이 정보의 중심이 되고,
캐릭터와 수채화 워시는 보조적인 시각 요소로 사용한다.

시각적 우선순위:

1. 실제 음식과 재료 사진
2. 레시피 정보
3. 미니멀 라인 아트 캐릭터
4. 옅은 수채화 워시

### 라인 아트 캐릭터 스타일

- 얇고 섬세한 검은 선
- 점 형태의 눈
- 단순하고 자연스러운 표정
- 간결한 팔다리
- 현대적인 에디토리얼 일러스트레이션
- 위트 있고 친근하지만 유아적이지 않은 성인 취향의 캐릭터
- 과장된 만화풍 표현 제외
- 입체적인 3D 캐릭터 제외

캐릭터는 단순한 장식이 아니라 재료와 조리 과정을 직관적으로 설명하는 보조적인 시각 요소로 사용한다.

캐릭터를 지나치게 많이 배치하지 않는다.

### 수채화 컬러링 규칙

- 수채화 워시는 매우 옅고 투명한 농도로 표현
- 전체 캐릭터 면적의 약 20~35%에만 부분적으로 적용
- 색상은 음식에서 추출한 포인트 컬러 1~2개 이내로 제한
- 낮은 채도와 낮은 대비 유지
- 색이 선 밖으로 아주 미세하게 번지는 자연스러운 수작업 느낌 허용
- 종이에 물감이 스며든 듯한 자연스러운 농도 표현
- 불규칙하고 미세한 붓 터치 표현
- 캐릭터 전체를 진하게 채색하지 않음

수채화 컬러는 다음과 같은 일부 영역에만 제한적으로 적용한다.

- 의상
- 모자
- 앞치마
- 볼
- 작은 소품
- 캐릭터 주변의 매우 작은 워시 포인트

진한 채색, 불투명한 플랫 컬러, 디지털 셀 채색, 강한 명암, 강한 그라데이션 렌더링은 사용하지 않는다.

선화가 항상 선명하게 유지되며,
수채화 색이 캐릭터의 형태나 표정을 가리지 않도록 조절한다.

캐릭터마다 색 농도와 붓 터치를 일관되게 유지한다.

수채화는 실사 음식 사진보다 시각적으로 두드러지지 않도록 낮은 채도와 낮은 대비로 표현한다.

### 텍스트 규칙

- 모든 텍스트는 자연스럽고 정확한 한국어
- 가독성 높은 심플한 모던 고딕체
- 음식명, 재료명, 분량, 단계 번호, 단계 제목, 조리 설명을 명확하게 구분
- 조리 설명은 짧고 이해하기 쉬운 문장으로 작성
- 긴 설명문이나 불필요한 문장 사용 금지
- 한글 텍스트 오류, 오탈자, 깨짐, 중복, 잘림 없이 정확하게 표현

반드시 포함할 텍스트:

- 음식명
- 음식 특징 한 줄 설명
- 대표 재료명
- 각 재료의 정확한 분량
- 01, 02, 03, 04 단계 번호
- 각 단계의 짧은 제목
- 각 단계의 짧은 조리 설명
- 하단의 플레이팅 팁 또는 맛있게 먹는 방법

### 중요 정확성 규칙

- [[food-name]]에 맞는 실제 대표 재료와 일반적인 분량을 자동으로 선정
- 가장 널리 사용되는 조리법을 기준으로 정확히 4단계로 구성
- 재료명, 분량, 조리 순서, 아이콘, 캐릭터 행동이 서로 정확하게 일치
- 실제 조리에 사용하지 않는 재료를 임의로 추가하지 않음
- 비현실적인 분량을 사용하지 않음
- 조리 전과 조리 후의 재료 상태를 혼동하지 않음
- 잘못된 조리 도구를 사용하지 않음
- 설명과 캐릭터 행동이 서로 다르게 표현되지 않도록 함

### 금지 요소

- 복잡한 배경
- 과도한 장식
- 과도한 색상
- 캐릭터 과다 배치
- 음식 사진을 가리는 캐릭터
- 텍스트를 가리는 캐릭터나 일러스트
- 입체적인 3D 캐릭터
- 과장된 만화풍 표현
- 유아적인 캐릭터 디자인
```
