# 폰카 사진이 스튜디오 화보로

평범한 폰카 사진을 전문 에디터의 손길이 닿은 듯한 고품질 스튜디오 화보 느낌으로 보정해 보세요.

```prompt
title: 폰카 사진이 스튜디오 화보로
description: 평범한 폰카 사진을 전문 에디터의 손길이 닿은 듯한 고품질 스튜디오 화보 느낌으로 보정해 보세요.
---
### 1. 역할 및 목표
첨부한 사진을 전문 이미지 에디터처럼 자연스럽게 보정해 줘.
사진을 먼저 살펴보고 원본의 장점과 분위기는 최대한 유지하면서, 선택한 옵션에 맞게 필요한 부분만 자연스럽게 개선해 줘.

### 2. 선택 옵션
- 사진 유형: [자동 판단 / 인물 / 음식 / 풍경 / 제품 / 실내·공간]
- 원하는 보정 느낌: [자연스럽게 / 따뜻하게 / 밝고 화사하게 / 선명하게 / 시네마틱 / 비비드 / 미니멀]
- 보정 강도: [적당히 / 가볍게 / 확실하게]
- 보정 항목 (복수 선택): [+자동으로 필요한 부분 판단 / 색감 보정 / 화질 개선 / 잡티·방해 요소 정리 / 조명 보정 / 구도·크롭 개선 / 원근감 보정]
- 추가 요청: "[없음 / 새로운 배경 생성 / 아주 작은 나노 바나나의 디테일과 노란 색감을 선명하게 강조해 줘 / 원본의 매력을 살린 스타일 베리에이션 / 크리에이티브 편집(글로우, 파스텔 톤, 네온 등) 적용]"

### 3. 보정 기준 및 제약 조건
- 색감 보정: 색감 보정이 필요하면 화이트밸런스, 대비, 밝기, 채도 등을 자연스럽게 조절해 줘.
- 화질 개선: 화질 개선이 필요하면 노이즈를 줄이고 디테일과 선명도를 자연스럽게 개선해 줘.
- 잡티 제거: 잡티나 사진을 방해하는 불필요한 요소가 있다면 자연스럽게 정리해 줘.
- 조명 보정: 조명이 어색하면 너무 밝거나 어두운 부분을 조절하고 자연스러운 입체감을 살려 줘.
- 구도 개선: 구도 개선이 필요하면 피사체를 고려해 크롭과 프레이밍을 자연스럽게 조정해 줘.
- 과보정 금지: 선택한 보정 느낌과 강도를 반영하되 과도하게 가공된 사진처럼 만들지 마.
- 원본 훼손 금지: 원본의 중요한 피사체, 얼굴, 제품 형태, 공간 구조 등은 특별한 요청이 없으면 임의로 바꾸지 마.
- 환각 방지: 원본에 없는 요소를 불필요하게 추가하지 마.

### 4. 최종 출력 방향
최종 결과는 원본을 완전히 다른 이미지로 만드는 것이 아니라, 원래 사진의 장점을 살리면서 한 단계 더 완성도 높은 사진으로 보정해 줘.
```

### 💡 실전 활용 꿀팁 (Quick Tips)

#### 1. 자연스러운 고품질 보정 세팅
- 보정 강도: [적당히]를 기본으로 두고, [+자동으로 필요한 부분 판단]을 선택하면 AI가 사진의 노출, 화이트밸런스, 노이즈를 종합적으로 분석해 과하지 않은 스튜디오 톤으로 개선합니다.
- 원본 피사체와 인물의 얼굴 특징을 보존하면서 잡티와 거친 노이즈만 정리되어 실패 확률이 가장 낮습니다.

#### 2. 촬영 환경별 맞춤 보정 팁
- 역광이나 어두운 실내 사진: [조명 보정]과 [화질 개선]을 복수 선택하여 피사체의 자연스러운 입체감과 밝기를 복원해 보세요.
- 답답한 구도의 사진: [구도·크롭 개선]을 선택하면 피사체가 황금비율에 맞게 안정적으로 정돈됩니다.

#### 3. 사진 유형별 추천 무드 조합
- 인물 스냅 / 일상: [자연스럽게] 또는 [밝고 화사하게]
- 카페 / 음식 / 소품: [따뜻하게] 또는 [비비드]
- 도시 풍경 / 야경 / 건축: [시네마틱] 또는 [미니멀]
