# 나는 어떤 색일까?

지금까지 AI와 실제로 나눈 대화 기록과 성향, 창작 세계를 다각도로 분석하여 나만의 감성 DNA와 색(MAIN COLOR, SUPPORTING COLOR)을 도출하고, 이를 한 점의 현대 추상 미술(Emotional Abstract Color Portrait)로 시각화하는 프롬프트 조립기입니다.

사람이나 캐릭터로 그리지 않고, 오직 색, 빛, 질감, 형태, 여백을 활용해 깊이 있는 안료 질감과 부드러운 빛이 스며드는 갤러리 전시 작품 느낌을 연출합니다.

---

### 💡 실전 활용 꿀팁 (Quick Tips)

#### 1. 대화 기록이 충분한 창에서 실행하기
- 이 프롬프트는 AI와의 기존 대화에서 드러난 말투, 관심사, 선택 기준, 가치관을 분석하여 색을 결정합니다.
- 충분한 대화가 누적된 채팅창에서 실행할 때 나만의 고유한 성향이 담긴 색과 작품 제목이 가장 설득력 있게 도출됩니다.
- 대화 기록이 없는 새 창에서 실행할 경우 프롬프트의 자체 안내에 따라 3가지 성향 파악 질문이 먼저 제공됩니다.

#### 2. 추천 옵션 조합
- 인스타그램 및 모바일 감성 소장: [한국어] + [작품 분위기에 맞게 자동] + [세로형 4:5]
- 현대 미술 포스터 감성: [한국어] + [우아한 세리프] + [세로형 4:5]
- 서적/잡지 에디토리얼 커버: [English] + [클래식 에디토리얼] + [세로형 4:5]
- 미니멀 앨범 커버: [작품 분위기에 맞게 자동] + [정사각형 1:1]

#### 3. 샘플 갤러리 작품 안내
- Thoughtful Luminous (1번 샘플): 딥 블루와 선셋 골드, 웜 핑크 파스텔의 다층 레이어로 깊은 사유와 빛나는 내면을 표현한 영문 세로형 4:5 작품
- 햇살이 머무는 온도 (2, 4번 샘플): 웜 파스텔과 은은한 골드 안료 질감으로 다정한 창작 세계를 표현한 세로형 작품
- 고요한 확장 (3번 샘플): 딥 에메랄드와 블루, 골드 층위로 깊은 내면과 통찰을 표현한 세로형 작품
- 따뜻한 가능성 (5번 샘플): 버건디와 선셋 골드의 대비를 사방으로 균형 있게 확산시킨 정사각형 1:1 작품
- 새벽을 품은 옻빛 남청 (6번 샘플): 옻빛 남청과 자개빛 펄 텍스처로 깊은 몰입을 담아낸 세로형 4:5 작품

#### 4. 문자 표현과 이미지 완성도
- AI 이미지 생성 엔진에 따라 한글 글자가 깨지거나 어색하게 표현될 수 있습니다.
- 프롬프트 내부 지침에 따라, 글자 깨짐이 우려되는 경우 억지로 텍스트를 넣지 않고 순수한 추상 회화만 생성한 뒤 작품 캡션(작품명, 상단·하단 문구)을 대화창 텍스트로 따로 안내하도록 설계되어 있습니다.

#### 5. 퍼스널 브랜딩 및 SNS 시그니처 비주얼
- 인스타그램, 스레드, 브런치, 링크드인의 프로필 배경이나 헤더 커버로 활용해 보세요.
- 일반적인 얼굴 사진이나 캐릭터 대신, 나의 대화와 생각이 담긴 깊이 있는 '추상 자화상'을 대표 비주얼로 배치하면 지적이고 감각적인 크리에이터 무드를 연출할 수 있습니다.

#### 6. 프로젝트 및 브랜드 키 비주얼(Key Visual) 도출
- 개인의 대화뿐만 아니라 신규 기획 중인 서비스 기획서나 팀 회의록, 브랜드 소개 글을 대화창에 입력하고 실행해 보세요.
- 프로젝트 전체의 핵심 정서를 관통하는 메인 컬러와 서브 컬러 조합을 단 한 점의 회화 작품으로 시각화하여 프로젝트 무드보드나 브랜드 키 비주얼로 확장할 수 있습니다.

#### 7. 실물 굿즈 및 감성 선물 제작 (엽서·포스터)
- 세로형 4:5 비율은 엽서, 전시 포스터(A3/A4), 패브릭 포스터, 폰 케이스 인쇄에 최적화된 규격입니다.
- 소중한 사람과 나눈 대화나 편지글을 바탕으로 작품을 제작한 뒤, 캡션 문구와 함께 엽서로 출력해 전달하면 세상에 하나뿐인 특별한 감성 선물이 됩니다.

```prompt-template
# 나는 어떤 색일까?

지금까지 나와 실제로 나눈 대화를 바탕으로
나의 성향과 창작 세계를 분석하고,
그 느낌을 색으로 표현한 한 장의 추상 아트 작품을 만들어 주세요.

### 선택 옵션

- 출력 언어: [[output-language]]
- 메인 타이틀: [[main-title]]
- 상단 문구: [[top-text]]
- 하단 문구: [[bottom-text]]
- 타이포그래피: [[typography]]
- 화면 비율: [[aspect-ratio]]

### 1. 출력 언어 처리

지정된 출력 언어([[output-language]])를 작품의 최종 언어로 사용하세요.

- 한국어인 경우: 이미지 속 문구와 색 이름을 자연스럽고 감각적인 한국어로 작성하세요.
- English인 경우: 이미지 속 문구와 색 이름을 자연스럽고 감각적인 영어로 작성하세요. 한국어 표현을 먼저 만든 뒤 영어로 직역하지 마세요. 영어에서 처음부터 자연스럽게 느껴지는 표현을 만드세요.
- 한국어나 English가 아닌 다른 언어가 지정된 경우: 해당 언어를 최종 출력 언어로 사용하세요. 한국어나 영어로 문구를 먼저 만든 뒤 번역하지 말고, 해당 언어의 어감과 표현 방식에 맞게 처음부터 자연스럽게 작성하세요. 서로 다른 언어를 불필요하게 섞지 마세요.

### 2. 나를 색으로 해석하기

단순히 내가 좋아한다고 말한 색을 선택하거나 일반적인 색채심리 공식에 맞추지 마세요.

지금까지 나와 실제로 나눈 대화를 살펴보고 반복적으로 나타나는 특징을 종합적으로 분석하세요.

다음 내용을 중심으로 살펴봅니다.

- 말투와 표현 방식
- 관심사와 반복적으로 다루는 주제
- 선택하고 판단하는 방식
- 중요하게 생각하는 가치
- 반복적으로 나타나는 취향과 분위기

대화에서 확인되지 않는 성향은 임의로 만들어내지 마세요.
근거가 충분하지 않은 부분은 과장하지 말고, 실제 대화에서 확인할 수 있는 특징만 작품에 반영하세요.

### 3. 대화 기록이 부족한 경우

지금까지의 대화만으로 반복적인 성향이나 취향을 판단할 근거가 충분하지 않다면 임의로 성향을 지어내거나 일반적인 색채심리에 끼워 맞추지 마세요.

- 대화형 질의응답이 가능한 환경인 경우:
  작품을 생성하기 전에 사용자의 성향을 파악하기 위한 핵심 질문 3가지를 먼저 제시하세요.
  1) 평소 중요하게 생각하는 가치나 태도
  2) 자주 끌리는 분위기나 표현 방식
  3) 무언가를 선택하거나 만들 때 중요하게 보는 기준
  (사용자가 답변하면 그 내용과 기존 대화를 함께 반영해 작품을 제작하세요.)

- 단일 요청으로 이미지를 즉시 생성해야 하는 환경인 경우:
  추가 질문을 거치지 말고, 지금까지 확인 가능한 사용자의 말투나 태도, 최소한의 인상만을 바탕으로 가장 보수적이고 정갈하게 작품을 제작하세요.

대화 기록이 충분한 경우에는 추가 질문 없이 바로 진행하세요.

### 4. 작품에 사용할 색 도출하기

실제 대화에서 반복적으로 확인되는 특징을 바탕으로 감성 DNA 4가지를 작품 설계 기준으로 정하세요.

이 기준을 바탕으로 다음 세 가지 색을 선정합니다.

- MAIN COLOR 1개: 나의 가장 중심적인 성향과 작품 전체의 핵심 정서를 표현하는 색
- SUPPORTING COLOR 2개: MAIN COLOR와는 다른 나의 서로 다른 모습과 분위기를 표현하는 색

색을 선택할 때에는 각 색이 어떤 성향이나 분위기를 표현하는지 실제 대화에서 확인할 수 있는 근거가 있어야 합니다.
장문의 성향 분석이나 사고 과정을 사용자에게 설명하지 마세요.
분석 결과는 작품의 색과 분위기를 일관되게 정하기 위한 작업 기준으로 활용하세요.

### 5. 나만의 색 이름 만들기

선택 옵션의 '메인 타이틀'([[main-title]]) 값에 따라 작품 제목을 결정하세요.

- 'AI가 대화 분석 후 자동 작명'인 경우:
  대화 분석 결과를 바탕으로 한 점의 현대 미술 작품 제목처럼 감성적인 이름을 새롭게 만드세요.
  ‘파란색’, ‘보라색’, ‘초록색’처럼 일반적인 색 이름만 붙이지 마세요.
  색의 느낌과 나의 성향이 함께 느껴지고, 한 점의 현대 미술 작품 제목처럼 보이는 이름을 만드세요.
  짧고 기억하기 쉬우면서 지나치게 설명적이지 않은 표현을 우선합니다.

  - 출력 언어가 한국어인 경우: 한국어에서 자연스럽고 감각적으로 느껴지는 새로운 감성 이름을 직접 만들어 주세요. (예: 새벽을 품은 옻빛 남청, 햇살이 머무는 온도, 고요한 확장 - 예시는 표현 방식만 참고하고 그대로 따라 하거나 비슷한 이름을 반복하지 마세요)
  - 출력 언어가 English인 경우: 한국어 이름을 먼저 만든 뒤 영어로 번역하지 마세요. 영어에서 자연스럽고 현대 미술 작품 제목처럼 느껴지는 새로운 이름을 직접 만들어 주세요. (예: Dawnlit Indigo, Quiet Expansion, Warm Possibility - 예시는 표현 방식만 참고하고 그대로 따라 하거나 비슷한 이름을 반복하지 마세요)
  - 한국어나 English가 아닌 다른 언어가 지정된 경우: 해당 언어로 MAIN COLOR의 감성 이름을 직접 만들어 주세요. 한국어나 영어로 이름을 먼저 만든 뒤 번역하지 마세요. 해당 언어의 어감과 표현 방식을 고려해 그 언어에서 자연스럽고 감각적으로 느껴지는 현대 미술 작품 제목처럼 만들어 주세요. 짧고 기억하기 쉬운 표현을 우선하고, 다른 언어를 불필요하게 섞지 마세요.

- '없음'인 경우:
  작품 안에 메인 타이틀 텍스트를 포함하지 않고, 색과 형태 중심의 순수 추상 회화로 연출하세요. (단, 이미지 생성 후 대화창 텍스트로 안내하는 작품 캡션에는 대화 분석을 거쳐 도출된 MAIN COLOR 감성 이름을 표기해 주세요.)

- 사용자가 특정 이름을 직접 지정한 경우:
  사용자가 입력한 이름을 MAIN COLOR의 공식 작품 타이틀로 그대로 사용하세요.

### 6. 작품으로 표현하기

VISUAL STYLE: Emotional Abstract Color Portrait

나를 사람이나 캐릭터로 그리지 마세요.
나라는 사람을 색, 빛, 질감, 형태, 여백으로 표현한 추상 자화상으로 만들어 주세요.
화면 전체가 갤러리에 전시된 한 점의 현대 추상회화처럼 보여야 합니다.

다음과 같은 회화적 표현을 활용하세요.
- 반투명하게 겹쳐지는 색
- 깊이 있는 안료의 질감
- 부드럽게 스며드는 빛
- 서로 만나고 번지는 색의 경계
- 섬세한 붓의 흔적
- 자연스러운 레이어와 깊이
- 충분한 여백
- 작품과 어울리는 경우 절제된 금빛이나 빛의 흔적

MAIN COLOR가 작품 전체의 중심 정서를 만들도록 하세요.
SUPPORTING COLOR 2개는 MAIN COLOR와 경쟁하지 않고 서로 다른 층위에서 자연스럽게 만나고 스며들게 표현하세요.
MAIN COLOR가 화면 전체의 인상을 주도하되, 색을 일정한 비율이나 구역으로 기계적으로 나누지 마세요.
색 자체가 감정과 성향을 전달하도록 구성하세요.

### 7. 화면 비율

지정된 화면 비율([[aspect-ratio]])에 맞게 작품의 구도와 여백을 자연스럽게 구성하세요.

- '세로형 4:5' 계열인 경우:
  갤러리 포스터나 에디토리얼 아트워크처럼 세로 공간과 여백을 충분히 활용하세요.
  MAIN COLOR의 흐름과 텍스트가 들어갈 경우의 여백까지 고려해 위아래로 자연스러운 깊이가 느껴지도록 구성하세요.
  단순히 화면 중앙에 요소를 몰아넣지 마세요.

- '정사각형 1:1' 계열인 경우:
  화면 전체에서 색과 형태의 균형이 자연스럽게 느껴지도록 구성하세요.
  중앙에 모든 요소를 집중시키기보다 여백과 색의 흐름이 사방으로 자연스럽게 이어지게 표현하세요.

### 8. 추상 표현 원칙

사람, 얼굴, 신체, 캐릭터를 직접 표현하지 마세요.
또한 다음과 같은 대상이 명확하게 보이는 구상 작품으로 만들지 마세요: 산, 바다, 하늘, 꽃, 나무, 건물, 특정 사물, 명확한 풍경.
색과 형태의 흐름이 어떤 이미지를 은은하게 연상시키는 것은 괜찮지만, 특정 사물이나 풍경을 그린 작품처럼 보이지 않게 하세요.
비인물, 비캐릭터 중심의 현대적인 추상 회화로 표현하세요.

### 9. 사용하지 않을 표현

다음 형태로 만들지 마세요: 컬러 팔레트 표, 컬러칩이나 색상 견본, 색을 여러 칸으로 나눈 화면, 다꾸 스타일, 메모지, 캐릭터, 정보 카드, 인포그래픽, 분석 차트, 여러 개의 설명 박스, 감성 DNA를 나열한 포스터, 성향 분석 결과를 글로 설명하는 화면.

분석 결과를 보여주는 정보물이 아니라, 색 자체가 나를 이야기하는 작품이어야 합니다.

### 10. 이미지 속 글자

이미지 안의 글자는 최소화하세요. 상단 문구와 하단 문구는 선택 옵션 값을 우선 적용합니다.

사용자가 직접 입력한 메인 타이틀, 상단 문구, 하단 문구는 출력 언어 설정보다 우선합니다.
직접 입력된 문구는 번역하거나 바꾸지 말고 그대로 사용하세요.

- 값이 '자동'이면 출력 언어에 맞는 기본 문구를 사용하세요.
- 값이 '없음'이면 해당 문구는 이미지에 넣지 마세요.
- 사용자가 직접 문구를 입력한 경우에는 입력한 문구를 그대로 사용하세요.

세부 문구 및 출력 언어별 매핑 규칙:

- 출력 언어가 한국어인 경우:
  - 상단 작게: '자동'일 때 '나는 어떤 색일까?' 적용 ('없음' 시 제외, 직접 입력 시 해당 문구 사용)
  - 메인 타이틀: 'AI가 대화 분석 후 자동 작명'인 경우 5번 지침에 따라 결정된 한국어 감성 이름을 넣으세요. ('없음' 시 제외, 직접 입력 시 해당 이름 그대로 사용)
  - 하단 작게: '자동'일 때 '나를 색으로 번역하다.' 적용 ('없음' 시 제외, 직접 입력 시 해당 문구 사용)

- 출력 언어가 English인 경우:
  - 상단 작게: '자동'일 때 'WHAT COLOR AM I?' 적용 ('없음' 시 제외, 직접 입력 시 해당 문구 사용)
  - 메인 타이틀: 5번 지침에 따라 결정된 MAIN COLOR의 영어 감성 이름을 넣으세요. ('없음' 시 제외, 직접 입력 시 해당 이름 그대로 사용)
  - 하단 작게: '자동'일 때 'Translating myself into color.' 적용 ('없음' 시 제외, 직접 입력 시 해당 문구 사용)

- 한국어나 English가 아닌 다른 언어가 지정된 경우:
  - 상단 작게, 메인 타이틀, 하단 작게 각 문구를 해당 언어에 어울리는 자연스러운 전시 문구로 적용하세요. ('없음' 시 제외, 직접 입력 시 해당 문구 사용)
  - 한국어나 영어 문장을 그대로 직역하지 말고, 실제 현대 미술 전시 포스터에 사용해도 자연스럽게 느껴지는 표현을 사용하세요.

### 11. 이미지 속 텍스트 배치

위 요소 외에는 어떤 설명문도 이미지에 추가하지 마세요.
텍스트는 작품의 색, 형태, 흐름과 여백을 고려해 가장 자연스러운 위치에 배치하세요.
중앙 정렬을 무조건 사용하지 마세요. 작품에 따라 중앙, 상단, 하단, 좌측 또는 우측의 여백을 활용해 시각적으로 가장 안정적인 위치를 선택하세요.
글자가 작품보다 먼저 눈에 띄지 않도록 절제된 크기로 표현하세요.

### 12. 문자 표현이 어려운 경우

선택하거나 입력한 언어의 문자를 이미지 안에서 정확하게 표현할 수 있는 경우에만 텍스트를 작품 안에 넣으세요.
깨진 글자, 잘못된 철자, 의미 없는 문자, 읽기 어려운 문자 형태가 생성될 가능성이 높은 경우에는 억지로 텍스트를 넣지 마세요.
특히 한국어처럼 복잡한 문자 체계는 이미지 생성 모델에 따라 글자 깨짐이나 오탈자가 발생할 수 있습니다.
한국어 출력에서는 이미지 완성도를 우선하세요.
정확한 한글 표현이 어렵다고 판단되면 텍스트를 이미지 안에 억지로 넣지 말고, 텍스트 없는 순수 추상 회화로 완성하세요.

이 경우에는 이미지 생성 후 대화창에 현재 선택 옵션을 반영한 작품 캡션을 제공하세요.

작품 캡션 처리:
- 상단 문구가 '없음'이 아니면 해당 문구를 표시하세요.
- MAIN COLOR의 감성 이름은 작품명으로 표시하세요. 단, 사용자가 직접 지정한 메인 타이틀이 있으면 그 이름을 사용하세요.
- 하단 문구가 '없음'이 아니면 해당 문구를 표시하세요.
- '자동'인 항목은 출력 언어에 맞는 기본 문구를 사용하세요.
- 직접 입력한 항목은 출력 언어와 관계없이 입력값을 그대로 사용하세요.
- 직접 입력값이 없는 자동 생성 요소만 지정된 출력 언어에 맞게 작성하세요.

이미지의 완성도를 해치면서까지 문자 표현을 강제하지 마세요.

### 13. 타이포그래피

지정된 타이포그래피([[typography]]) 옵션을 작품 전체 분위기와 자연스럽게 연결하세요.

- '작품 분위기에 맞게 자동': 작품의 색, 감정, 질감과 여백을 고려해 가장 잘 어울리는 타이포그래피를 선택하세요. 세리프 또는 산세리프를 기계적으로 고정하지 말고, 작품의 정서에 맞춰 결정하세요.
- '우아한 세리프': 가늘고 정제된 획과 넉넉한 여백을 사용하세요. 현대 미술관이나 갤러리의 전시 포스터처럼 차분하고 우아하게 표현하세요.
- '미니멀 산세리프': 군더더기 없이 단정하고 현대적인 글자 형태를 사용하세요. 글자의 크기와 굵기를 절제하고 충분한 여백을 활용하세요.
- '클래식 에디토리얼': 예술 서적이나 문화 잡지의 표지처럼 세련되고 차분한 편집 디자인의 느낌을 살리세요. 작품을 방해하지 않으면서 타이틀 자체가 하나의 디자인 요소처럼 보이게 하세요.

### 14. 언어별 타이포그래피 처리

출력 언어의 문자 체계에 어울리는 자연스러운 타이포그래피를 사용하세요.
한국어라면 한글의 획, 자간, 글자 균형을 고려하세요.
English라면 알파벳의 세리프, 산세리프 특성과 자간을 자연스럽게 활용하세요.
한국어나 English가 아닌 언어가 입력된 경우에는 해당 언어의 문자 체계와 조형적 특성에 맞게 적용하세요.
선택한 타이포그래피 스타일의 전체 분위기는 유지하되, 특정 언어에서 어색한 글자 형태를 억지로 적용하지 마세요.
특정 폰트 이름을 그대로 재현하는 것보다 선택한 스타일의 분위기와 조형적 특성을 우선하세요.

### 15. 가장 중요한 원칙

대신 색, 빛, 질감, 형태, 여백이 나를 이야기하도록 만들어 주세요.

대화 기록이 충분하다면 추가 질문 없이 바로 작품을 제작하세요.
```
