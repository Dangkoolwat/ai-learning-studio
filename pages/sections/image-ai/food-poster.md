# 프리미엄 푸드 포스터 만들기

메뉴 사진과 옵션을 조합하여 잡지 화보 같은 고품질 프리미엄 푸드 포스터를 만들어 보세요.
원하는 비율과 분위기를 선택한 후 **[프롬프트 복사]** 버튼을 눌러 AI에게 요청하면 됩니다.

```prompt
title: 프리미엄 푸드 포스터 프롬프트
description: 파란색 칩을 클릭해 원하는 옵션을 선택하고, 완성된 텍스트를 복사하여 이미지 생성 AI에 붙여넣으세요.
---
## 입력

- **메뉴명**: "[직접 입력]"
- **메뉴 사진**: [사진 첨부 / 사진 없음]
- **포스터 비율**: [4:5 세로형 / 9:16 세로형 / 1:1 정사각형 / 16:9 가로형]
- **포스터 분위기**: [자동 추천 / 밝고 산뜻하게 / 따뜻하고 감성적으로 / 강렬하고 힙하게 / 차분하고 고급스럽게 / 우아하고 로맨틱하게]
- **포인트 색상**: [메뉴에서 자동 추출 / 옐로 / 오렌지 / 레드 / 그린 / 브라운 / 핑크 / 직접 입력]
- **메뉴 이미지 비중**: [균형 있게 / 음식을 더 크게 / 타이포그래피를 더 크게]
- **맛 표현**: [AI가 메뉴에 맞게 추천]
- **추가 요청**: "[없음]"

---

## 제작 요청

입력된 메뉴를 홍보하는 프리미엄 푸드 포스터를 제작해 줘.

프리미엄 푸드 광고와 현대적인 독립 잡지의 에디토리얼 디자인을 결합하고,
대담하고 선명한 타이포그래피, 화면의 중심이 되는 먹음직스러운 메뉴 이미지,
짧은 맛 표현과 세련된 손그림 장식을 활용해 구성해 줘.

선택한 옵션을 우선 반영하되,
메뉴의 종류와 실제 이미지에 어울리지 않는 요소는 억지로 적용하지 마.


## 메뉴명과 언어

- 입력된 메뉴명이 한글이라면 광고에 자연스럽게 어울리는 영어 메뉴명으로 변환해 줘.
- 포스터 안의 모든 문구는 영어로 작성하고 한글은 넣지 마.
- 메인 메뉴명은 정확한 영어 철자로 한 번만 명확하게 표시해 줘.
- 모든 영어 문구는 실제 광고처럼 짧고 자연스럽게 작성해 줘.
- 철자 오류, 깨진 문자, 의미 없는 문자열과 반복 문구를 만들지 마.


## 메뉴 사진 처리

### 사진이 첨부된 경우

- 사진 속 음식이나 음료를 포스터의 핵심 메뉴로 사용해 줘.
- 메뉴의 형태, 색상, 재료, 토핑, 소스, 용기, 플레이팅 등 식별 가능한 특징을 최대한 정확하게 유지해 줘.
- 메뉴를 다른 음식으로 바꾸지 마.
- 메뉴의 양, 모양, 층 구조, 토핑 위치 등 눈에 보이는 특징을 자연스럽게 반영해 줘.
- 원본 사진의 조명, 배경이나 촬영 상태가 좋지 않다면 메뉴 자체의 특징은 유지하면서 프리미엄 푸드 광고 사진처럼 개선해 줘.
- 첨부 사진을 사각형 프레임 안에 그대로 붙이지 말고, 메뉴를 포스터 레이아웃에 자연스럽게 어울리는 고품질 광고 이미지로 재구성해 줘.
- 사진에 사람이 등장하면 사람은 제외하고 메뉴만 사용해 줘.
- 사진 속 상호명, 브랜드명, 로고, 워터마크, 가격표, 바코드, QR 코드는 제거해 줘.
- 사진에서 확인되지 않는 재료나 토핑을 과도하게 새로 추가하지 마.
- 메뉴명은 제목과 맛 표현을 정하는 데 활용하고, 메뉴의 실제 외형은 첨부 사진을 우선해서 반영해 줘.

### 사진이 없는 경우

- 입력된 메뉴명을 기준으로 메뉴 이미지를 새롭게 만들어 줘.
- 메뉴명에서 일반적으로 연상되는 형태, 재료, 색상, 조리 방식과 플레이팅을 바탕으로 자연스럽고 사실적으로 표현해 줘.
- 가장 보편적이고 이해하기 쉬운 형태의 메뉴로 제작해 줘.
- 특정 매장이나 기존 브랜드의 메뉴를 복제하지 마.
- 특정 브랜드의 로고, 포장 디자인이나 고유 용기를 사용하지 마.
- 메뉴명이 모호하더라도 과도한 재료나 장식을 임의로 추가하지 마.
- 현실적이고 범용적인 프리미엄 메뉴 이미지로 구성해 줘.


## 포스터 기본 설정

- 선택한 **포스터 비율**에 맞춰 전체 레이아웃을 처음부터 구성해 줘.
- 기존 레이아웃을 단순히 늘이거나 잘라서 선택한 비율에 맞추지 마.
- 선택한 비율에 따라 메뉴 이미지, 메인 타이틀, 보조 문구, 장식 요소와 여백의 위치와 크기를 자연스럽게 재배치해 줘.
- 세로형에서는 위아래 공간을 활용해 타이틀, 메뉴 이미지와 보조 요소가 자연스럽게 이어지도록 구성해 줘.
- 정사각형에서는 중앙 집중형 구도를 활용하되 요소가 답답하게 몰리지 않도록 해 줘.
- 가로형에서는 좌우 공간을 활용해 메뉴 이미지와 타이포그래피가 균형 있게 보이도록 구성해 줘.
- 어떤 비율에서도 메뉴 이미지와 메인 타이틀이 충분한 시각적 비중을 유지하도록 해 줘.
- SNS 홍보와 디지털 콘텐츠, 인쇄 포스터에 활용할 수 있는 고해상도 디자인으로 제작해 줘.
- 프리미엄 푸드 광고와 현대적인 독립 잡지 에디토리얼을 결합한 스타일로 구성해 줘.
- 선명하고 정돈된 결과물로 만들어 줘.
- 복잡하거나 산만하지 않게 구성해 줘.
- 특정 브랜드의 광고처럼 보이지 않는 독립적인 메뉴 포스터로 제작해 줘.


## 분위기와 색감

선택한 **포스터 분위기**를 전체 디자인에 반영해 줘.

**자동 추천**을 선택했다면 메뉴의 종류, 색상, 형태와 분위기를 분석해 가장 잘 어울리는 방향을 선택해 줘.

포인트 색상이 **메뉴에서 자동 추출**이라면 메뉴의 대표 재료나 주요 색상에서 자연스러운 포인트 색상 하나를 선택하고, 타이포그래피와 장식에 일관되게 사용해 줘.

- 따뜻한 아이보리 또는 크림색 배경을 기본으로 사용해 줘.
- 필요한 경우 배경에만 아주 은은한 종이 질감을 적용해 줘.
- 첨부 사진이 있다면 메뉴의 주요 색상과 자연스럽게 어울리는 색감을 선택해 줘.
- 전체 색감은 선택한 분위기를 살리면서 메뉴가 먹음직스럽게 보이도록 조절해 줘.
- 부드러운 스튜디오 조명과 자연스러운 그림자를 사용해 줘.
- 실제 광고 촬영처럼 사실적이고 풍부한 음식의 색상과 질감을 표현해 줘.


## 메인 타이틀

- 메뉴의 영어 이름을 화면에서 강하게 보이는 초대형 영문 타이포그래피로 배치해 줘.
- 글꼴 스타일은 선택한 포스터 분위기와 메뉴의 성격에 맞게 결정해 줘.
- 밝고 산뜻하거나 강렬하고 힙한 분위기에는 굵고 선명한 산세리프 계열을 우선 고려해 줘.
- 차분하고 고급스럽거나 우아하고 로맨틱한 분위기에는 세련된 세리프 계열도 적극 활용해 줘.
- 필요한 경우 메인 타이틀과 짧은 필기체 또는 손글씨 문구를 조화롭게 조합해 줘.
- 메인 타이틀은 포스터에서 가장 강한 타이포그래피 요소가 되게 해 줘.
- 제목 일부가 메뉴 이미지 뒤로 자연스럽게 가려지는 구성은 허용해 줘.
- 제목은 깨끗하고 선명하게 표현하고 높은 가독성을 유지해 줘.
- 깨끗한 디지털 인쇄물처럼 글자의 가장자리를 또렷하게 표현해 줘.

메인 타이틀에는 다음 효과를 사용하지 마.

- 노이즈
- 필름 그레인
- 거친 종이 질감
- 빈티지 잉크 번짐
- 흐림
- 모션 블러
- 글리치
- 왜곡
- 스크래치
- 색 번짐
- 깨진 글자
- 낡은 인쇄 효과
- 반투명 필터
- 이중으로 겹친 문자
- 과도한 입체 효과
- 과도한 그림자
- 텍스트 위를 덮는 거친 질감


## 메뉴 이미지와 구도

선택한 **메뉴 이미지 비중**과 **포스터 비율**을 함께 반영해
메뉴와 타이포그래피의 크기와 관계를 조절해 줘.

- 메뉴 이미지는 화면에서 충분히 크고 존재감 있게 보여 줘.
- 균형 있게를 선택했다면 메뉴 이미지와 타이포그래피가 서로 경쟁하지 않도록 조화롭게 구성해 줘.
- 음식을 더 크게를 선택했다면 메뉴가 가장 먼저 눈에 들어오도록 클로즈업 비중을 높여 줘.
- 타이포그래피를 더 크게를 선택했다면 제목의 시각적 비중을 높이되 메뉴가 지나치게 작아지지 않게 해 줘.
- 메뉴 주변의 불필요한 빈 공간은 줄여 줘.
- 메뉴가 화면 밖으로 과도하게 잘리거나 답답하게 확대되지 않게 해 줘.
- 제목과 메뉴 이미지가 자연스럽게 겹치더라도 메뉴의 핵심 형태는 명확하게 보여 줘.
- 메뉴에서 가장 먹음직스럽거나 아름다운 면이 보이는 광고 촬영 구도를 선택해 줘.


## 메뉴 이미지 표현

- 사실적이고 고급스러운 프리미엄 푸드 광고 사진 스타일로 표현해 줘.
- 음식의 표면, 크림, 소스, 토핑과 재료의 질감이 선명하게 보이게 해 줘.
- 선명한 초점과 섬세한 재료 질감을 유지해 줘.
- 부드러운 스튜디오 조명과 자연스러운 접촉 그림자를 표현해 줘.
- 지나치게 인공적이거나 플라스틱처럼 보이지 않게 해 줘.
- 실제 음식의 색상과 재료 표현을 유지해 줘.
- 지나치게 완벽하고 부자연스러운 대칭 형태는 피해서 표현해 줘.
- 음식은 메뉴의 성격에 어울리는 미니멀한 접시, 볼 또는 트레이를 사용해 줘.
- 음료는 감각적인 무지 유리잔이나 로고가 없는 도자기 컵을 사용해 줘.
- 사진에 용기가 이미 있다면 전체적인 형태를 자연스럽게 반영하되 브랜드 표시는 제거해 줘.
- 사진에 없는 장식 재료를 과도하게 추가하지 마.


## 맛 표현

맛 표현이 **AI가 메뉴에 맞게 추천**으로 선택되었다면,
메뉴명과 실제 이미지에서 확인되는 맛, 향, 온도와 질감을 바탕으로 어울리는 영어 표현을 3~6개만 선택해 줘.

사용 가능한 표현 예시:

- CREAMY
- RICH
- SILKY
- SMOOTH
- CRISP
- CRUNCHY
- CHEWY
- FLUFFY
- MELTY
- FRESH
- SWEET
- BOLD
- NUTTY
- ZESTY
- EARTHY
- CHILLED
- JUICY
- TOASTY
- SO GOOD
- EXTRA CREAMY
- SWEET + SMOOTH
- RICH x SILKY
- ONE MORE BITE
- ONE MORE SCOOP!
- LOVE AT FIRST SIP
- FULL OF FLAVOR
- MADE TO MELT
- TASTE THE TEXTURE
- BEST SERVED COLD
- THE GOOD STUFF

### 맛 표현 선택 기준

- 차가운 음료 → CHILLED / SMOOTH / LOVE AT FIRST SIP
- 크림이나 우유가 강조된 메뉴 → CREAMY / SILKY / RICH
- 빵이나 구운 메뉴 → TOASTY / CRISP / FLUFFY
- 쿠키나 튀김류 → CRUNCHY / CRISP / ONE MORE BITE
- 과일 메뉴 → FRESH / JUICY / ZESTY

모든 표현을 한 번에 넣지 말고 실제 메뉴에 어울리는 것만 사용해 줘.

사용자가 맛 표현을 **직접 입력**했다면 입력한 표현을 우선 사용하되 메뉴와 명백하게 어울리지 않는 표현을 임의로 추가하지 마.


## 손그림과 장식

맛 표현과 메뉴의 특징을 다음과 같은 작은 그래픽 요소로 자연스럽게 표현해 줘.

- 손글씨 메모
- 작은 스탬프
- 타원형 배지
- 밑줄
- 얇은 화살표
- 별과 반짝임
- 하트
- 꽃과 잎
- 물방울
- 소용돌이와 물결선
- 핵심 재료를 단순화한 작은 스케치

선택한 포스터 분위기에 따라 장식의 성격도 조절해 줘.

예를 들어 강렬하고 힙한 분위기에는 자유로운 낙서, 스탬프와 선을,
우아하고 로맨틱한 분위기에는 섬세한 꽃, 잎, 얇은 선과 작은 손글씨 장식을 우선적으로 고려해 줘.

- 사진이 첨부된 경우 재료를 가리키는 화살표와 설명은 실제 사진에서 확인되는 요소에만 사용해 줘.
- 사진이 없다면 메뉴명에서 확실하게 연상되는 핵심 요소만 표시해 줘.
- 장식은 단순하고 세련되게 표현해 줘.
- 음식이나 주요 문구를 가리지 마.
- 기호와 장식을 무작위로 흩뿌리지 마.


## 레이아웃

- 선택한 **포스터 비율에 가장 적합한 레이아웃을 새롭게 설계**해 줘.
- 완벽하게 대칭적인 구성보다 살짝 비대칭적이고 자연스러운 에디토리얼 레이아웃을 기본으로 해 줘.
- 단, 우아하고 정돈된 메뉴에 더 잘 어울린다면 안정적인 균형 구성을 사용할 수 있어.
- 시각적 우선순위는 **메뉴 이미지 → 메인 메뉴명 → 맛 표현과 장식 문구** 순으로 만들어 줘.
- 초대형 타이틀과 메뉴 이미지를 자연스럽게 연결해 줘.
- 음식 주변의 장식 요소는 소량만 사용해 줘.
- 장식 문구가 메뉴의 핵심 부분이나 토핑을 가리지 않게 해 줘.
- 충분한 여백을 유지하면서도 메뉴 이미지가 작아 보이지 않게 해 줘.
- 현대적인 푸드 매거진이나 독립 잡지처럼 균형 있게 구성해 줘.
```
