# 타이포그래피 이미지 프롬프트

사용자가 입력한 문구를 바탕으로, 어린아이가 마커로 그린 듯한 순수한 감성의 손글씨 레터링 이미지를 생성합니다.

```prompt
title: 귀여운 손글씨 타이포그래피 프롬프트
description: 원하는 문구와 화면 비율, 배경색을 설정해 이미지를 생성해 보세요.
---
다음 문구를 중심으로 타이포그래피 이미지를 제작해 주세요.

문구:
"[여기에 문구 입력]"

출력 조건:
- 화면 비율은 [ 16:9 가로형 / 1:1 정방형 / 9:16 세로형 / 4:3 가로형 ]
- 배경색은 반드시 [ #F3F1ED / #FFFFFF / 투명 ]
- 이미지 안의 텍스트는 Pretendard 스타일을 참고
- 문구는 철자, 대소문자, 단어 순서를 절대 바꾸지 말 것
- 문구 외의 추가 텍스트는 넣지 말 것

전체 콘셉트:
- 귀엽고 손으로 직접 그린 듯한 타이포그래피
- 장난스럽고 삐뚤빼뚤한 손글씨 레터링
- 어린아이가 마커로 그린 듯한 순수한 감성
- 미니멀하면서도 빈티지한 키즈 브랜드 스타일
- 낙서 일러스트 감성의 만화 스타일

타이포그래피 스타일:
- 글자마다 크기와 형태가 조금씩 다른 불균형한 디자인
- 너무 정렬되지 않은 자연스러운 배치
- 두꺼운 검은색 외곽선
- 둥글고 통통한 손글씨 느낌
- 읽기 쉬우면서도 개성이 살아있는 레터링

색상:
- 톤다운된 빨강, 노랑, 파랑 사용
- 글자마다 다른 색상을 자연스럽게 배치
- 플랫한 단색 스타일
- 그라디언트, 메탈릭, 유리 질감 금지

일러스트 요소:
- 글자 안이나 주변에 작은 낙서 아이콘 배치
- 별, 하트, 구름, 꽃, 번개, 스마일, 왕관, 반짝이, 화살표 활용
- 아이콘은 글자를 방해하지 않게 작게 구성

레이아웃:
- 문구를 화면 중앙에 크게 배치
- 충분한 여백 확보
- 일부 글자는 살짝 기울거나 높이가 달라도 자연스럽게 표현
- 전체적으로 리듬감 있게 구성

분위기:
- 따뜻하고 밝은 느낌
- 손으로 그린 마커 드로잉 스타일
- 빈티지한 키즈 브랜드 감성
- 귀엽고 사랑스럽고 장난기 있는 분위기
- 완벽한 벡터 느낌보다 손맛이 살아있는 표현

제외 요소:
- 사실적인 질감
- 3D 효과
- 그림자 효과
- 광택 효과
- 복잡한 배경
- 포토리얼 스타일
- 기계적으로 정렬된 타이포그래피
```

### 💡 실전 활용 꿀팁 (Quick Tips)

#### 1. 추천 문구 길이 및 텍스트 구성 팁
- 2~5단어 내외의 짧고 리듬감 있는 문구: "Happy Sunday", "오늘의 기분", "Coffee Break", "작은 기적"처럼 간결한 영문 또는 한글 문구를 입력할 때 통통하고 장난스러운 레터링 매력이 가장 잘 살아납니다.
- 문맥에 어울리는 낙서 아이콘: 프롬프트에 하트, 스마일, 별, 반짝이 등의 미니멀 아이콘이 글자 주변에 자연스럽게 어우러지도록 설계되어 있습니다.

#### 2. 배경색 및 용도별 선택 가이드
- #F3F1ED (따뜻한 미색, 기본값): 포근하고 빈티지한 키즈 브랜드 감성과 감성 엽서 포스터 제작에 가장 잘 어울립니다.
- 투명: 유튜브 썸네일 제목 자막, 인스타그램 스토리 스티커, 디자인 굿즈 제작을 위한 PNG 그래픽 소스로 활용하기 좋습니다.
- #FFFFFF (순백색): 미니멀하고 깔끔한 웹 배너나 카드뉴스 타이틀로 추천합니다.
