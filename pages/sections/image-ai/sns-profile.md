# SNS 프로필 이미지 프롬프트

사진을 업로드한 후 아래 본문 안의 파란색 칩을 클릭해 원하는 옵션을 선택하세요. 선택한 조건에 맞춰 얼굴 정체성을 유지하면서 다양한 스타일의 프로필 이미지를 생성하는 프롬프트가 완성됩니다.

```prompt
title: 맞춤형 SNS 프로필 생성 프롬프트
description: 본문의 파란색 옵션을 클릭하여 원하는 조건을 선택하세요.
---
내가 첨부한 인물 사진을 바탕으로 얼굴형, 눈·코·입의 특징, 헤어스타일, 전체적인 인상과 개성을 최대한 유지하면서 SNS 프로필로 사용하기 적합한 이미지를 생성해 주세요.

## 1. 기본 설정

- 프로필 용도: [카카오톡 / 범용 SNS / 이력서 / 비즈니스 / 유튜브 / 게임 프로필 / 자동 추천]
- 시각적 스타일: [자동 추천 / 스튜디오 인물 사진 / 라이프스타일 사진 / 영화 같은 분위기 / 3D 캐릭터 / 3D 피규어 / SD 캐릭터 / 치비 / 애니메이션 / 웹툰 / 픽셀아트 / 점토(클레이) 인형 / 봉제인형 / 미니어처 / 팝아트 / 미니멀 일러스트 / 수채화 / 유화 / 아크릴화 / 연필 스케치 / 잉크 드로잉]
- 분위기: [자연스러운 / 밝고 친근한 / 차분한 / 감성적인 / 세련된 / 고급스러운 / 귀여운 / 시크한]
- 조명: [자연광 / 부드러운 실내 조명 / 스튜디오 조명 / 노을빛 / 야간 조명 / 자동 추천]
- 색감: [자연스러운 / 따뜻한 / 차가운 / 파스텔 / 필름 감성 / 빈티지 / 선명한 / 흑백]

## 2. 인물 연출

- 프로필 구도: [얼굴 크게 / 얼굴과 어깨 / 상반신 / 셀카 구도 / 자동 추천]
- 시선 방향: [정면 / 살짝 옆 / 옆모습 / 자동 추천]
- 표정: [원본 유지 / 은은한 미소 / 활짝 웃는 / 차분한 / 자신감 있는 / 자동 추천]
- 헤어스타일: [원본 유지 / 자연스럽게 정돈 / 스타일 변경]
- 의상: [원본 유지 / 캐주얼 / 비즈니스 캐주얼 / 정장 / 계절 의상]
- 보정 정도: [원본에 가깝게 / 자연스럽게 / 조금 더 세련되게]

## 3. 배경 설정

- 배경: [단색 / 카페 / 자연 / 바다 / 도시 / 야경 / 서재 / 계절 풍경 / 투명 배경(PNG)]
- 배경 효과: [원본 유지 / 단순화 / 흐림 / 완전히 변경 / 없음 / 자동 추천]

## 4. 필수 유지 요소

- 강제 유지 항목: [모두 유지 / 얼굴형 / 눈 / 코 / 입 / 헤어스타일 / 안경 / 액세서리 / 전체 인상]

사진 속 인물의 얼굴 특징, 표정, 헤어스타일, 전체적인 인상과 개성은 최대한 유지하고 다른 사람처럼 변경하거나 과도하게 미화하지 말아 주세요.

사진 속 인물의 성별, 연령대 등 기본적인 특성은 임의로 변경하지 말아 주세요.

## 5. 출력 설정

- 이미지 비율: [정사각형(1:1) / 자동 추천]
- 희망 출력 개수: [1장 / 2장 / 4장]

## 6. 스타일 표현 방식

"[일반적인 스타일명을 우선 사용(권장) / 특정 작품·브랜드 스타일 참고]"

## 7. 추가 요청

"[없음]"

## 생성 가이드라인

선택한 옵션을 모두 자연스럽게 반영하여 조화롭고 완성도 높은 이미지를 생성해 주세요.

선택하지 않은 항목은 선택한 옵션과 자연스럽게 어울리도록 판단하여 적용해 주세요.

선택한 **프로필 용도**에 가장 적합하도록 전체적인 분위기, 구도, 배경, 색감, 연출을 자연스럽게 조정해 주세요.

정사각형(1:1)을 기준으로 제작하고, 원형 프로필에서도 얼굴이 잘리지 않도록 중앙 안전 영역을 고려하여 배치해 주세요.

배경, 조명, 색감, 의상은 선택한 분위기와 자연스럽게 어울리도록 표현해 주세요.

'일반적인 스타일명을 우선 사용(권장)'을 선택한 경우에는 특정 작품, 브랜드 또는 작가의 스타일을 직접 모방하지 말고, 선택한 일반적인 스타일의 특징을 자연스럽게 반영해 주세요.

전체 이미지는 선명하고 자연스러운 고품질로 제작해 주세요.

가능한 경우 선택한 희망 출력 개수에 맞춰 이미지를 생성해 주세요.
해당 이미지 생성 AI가 한 번에 여러 장을 지원하지 않는 경우에는 가능한 개수만 생성해 주세요.
여러 장을 생성하는 경우에는 인물의 정체성과 선택한 조건은 유지하되, 구도나 세부 표현에 자연스러운 차이를 주세요.

사진 속 인물을 알아볼 수 있는 수준의 정체성을 유지하면서 선택한 스타일을 자연스럽게 적용해 주세요.
```

**💡 어떤 AI를 사용하면 좋을까요?**

**참고:** ChatGPT와 Gemini의 이미지 생성 모델 및 기능은 지속적으로 업데이트됩니다. 
아래 내용은 현재 기준의 일반적인 특징이며, 향후 모델 업데이트에 따라 결과나 성향이 달라질 수 있습니다.

- **ChatGPT**
  - 프롬프트에 작성한 조건과 지시사항을 비교적 충실하게 반영하는 경향이 있습니다.
  - 3D 캐릭터, 일러스트, 웹툰, 팝아트 등 다양한 그래픽 스타일 표현에 강점을 보이는 경우가 많습니다.
  - 여러 조건을 조합하거나 세부적인 스타일을 지정하는 작업에 적합합니다.

- **Gemini**
  - 자연스러운 빛, 질감, 색감 표현이 뛰어나 실사 스타일 이미지에서 좋은 결과를 보여주는 경우가 많습니다.
  - 스튜디오 인물 사진, 자연광, 필름 감성 등 사진 스타일의 프로필 이미지를 생성할 때 높은 품질을 기대할 수 있습니다.
  - 다만 모델 버전에 따라 결과의 특성과 표현 방식은 달라질 수 있습니다.
