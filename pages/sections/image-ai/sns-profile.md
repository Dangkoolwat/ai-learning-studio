# SNS 프로필 이미지 프롬프트

사진을 업로드한 후 아래 본문 안의 파란색 칩을 클릭해 원하는 옵션을 선택하세요. 선택한 조건에 맞춰 얼굴 정체성을 유지하면서 다양한 스타일의 프로필 이미지를 생성하는 프롬프트가 완성됩니다.

### 💡 실전 활용 꿀팁 (Quick Tips)

#### 1. SNS 플랫폼 및 분위기별 추천 스타일 조합
- 카카오톡·메신저 (친근하고 귀여운 무드): [3D 캐릭터 / SD 캐릭터] + [밝고 친근한 분위기] + [단색 또는 파스텔 배경]
- 인스타그램·개인 SNS (감성적인 일상 스냅): [라이프스타일 사진 / 영화 같은 분위기] + [필름 감성 색감] + [카페 또는 자연 배경] + [은은한 미소]
- 유튜브·크리에이터 (개성 있는 시그니처): [팝아트 / 미니멀 일러스트 / 웹툰] + [선명한 색감] + [단색 배경] + [자신감 있는 표정]
- 비즈니스·링크드인 (신뢰감 있는 첫인상): [스튜디오 인물 사진] + [세련되고 차분한 분위기] + [비즈니스 캐주얼 의상] + [단색 배경]

#### 2. 원형 프로필 안전 영역 확보 요령
- 대부분의 메신저와 SNS는 프로필 이미지를 원형으로 잘라서 표시합니다.
- 인물의 정수리와 양쪽 어깨 끝이 잘려나가지 않도록 [프로필 구도]에서 '얼굴과 어깨' 또는 '상반신'을 선택하고 얼굴이 정중앙에 오도록 배치하는 것을 권장합니다.

#### 3. 캐릭터 변환 시 얼굴 정체성 유지 팁
- 3D 캐릭터, 웹툰, 일러스트 등 그래픽 스타일로 변환할 때 내 얼굴의 개성을 살리고 싶다면 [강제 유지 항목]을 '모두 유지' 또는 '얼굴형', '헤어스타일', '안경' 등으로 지정하세요.
- 원본 사진은 얼굴 윤곽과 이목구비가 가려지지 않고 밝은 조명 아래서 찍힌 사진을 사용하는 것이 좋습니다.

#### 4. 어떤 AI를 사용하면 좋을까요?
- ChatGPT: 프롬프트에 작성한 조건과 세부 옵션을 충실하게 반영하며, 3D 캐릭터, 일러스트, 웹툰, 팝아트 등 다양한 그래픽 스타일에 강점을 보입니다.
- Gemini: 자연스러운 빛과 질감, 부드러운 피부 톤 표현이 뛰어나 스튜디오 인물 사진, 자연광 스냅 등 실사 스타일의 프로필 제작에 적합합니다.
