# 바로 써보기

처음부터 프롬프트를 새로 쓰지 않아도 됩니다.

이곳에서는 이미 준비된 프롬프트를 살펴보고, 내 상황에 맞게 필요한 부분만 바꿔서 사용할 수 있습니다.

이름, 날짜, 대상, 목적, 말투처럼 달라지는 정보만 바꿔도 훨씬 내게 맞는 결과를 얻을 수 있습니다.

## 이렇게 활용해 보세요

1. 필요한 프롬프트를 고릅니다.

2. 괄호 안의 예시를 내 정보로 바꿉니다.

3. 필요 없는 조건은 지웁니다.

4. 부족한 내용은 한두 줄 더 적습니다.

5. 완성된 프롬프트를 복사해 AI에게 요청합니다.

6. 결과를 읽고 사실과 조건이 맞는지 다시 확인합니다.

## 무엇을 바꾸면 될까요?

프롬프트를 열어 보면 다음과 같은 항목이 들어 있습니다.

- 누구에게 필요한 결과인지
- 무엇을 만들고 싶은지
- 어떤 내용을 꼭 넣어야 하는지
- 원하는 말투와 길이
- 결과를 어떤 형식으로 받을지
- AI가 추측하지 말아야 할 내용

모든 항목을 바꿀 필요는 없습니다.

내 상황과 다른 부분만 찾아 바꾸면 됩니다.

## 바로 쓸 수 있는 프롬프트

현재 준비된 프롬프트부터 하나씩 사용해 보세요.

## 프롬프트를 고를 때

같은 글이라도 읽는 사람과 목적에 따라 문장이 달라집니다.

예를 들어 업무 이메일을 쓸 때는 다음 내용을 먼저 확인하면 좋습니다.

- 누구에게 보내는가
- 무엇을 알리거나 요청하는가
- 꼭 들어가야 할 내용은 무엇인가
- 언제까지 답이 필요한가
- 정중한 말투가 필요한가
- 짧고 간결하게 써야 하는가

이 정보가 분명할수록 AI의 답변도 더 쓸 만해집니다.

## 사용할 때 주의할 점

준비된 프롬프트는 완성본이라기보다 출발점에 가깝습니다.

예시에 있는 이름, 날짜, 숫자를 그대로 두지 말고 실제 정보로 바꿔 주세요.

고객 정보, 연락처, 계좌번호, 비밀번호처럼 민감한 내용은 그대로 입력하지 않는 것이 좋습니다.

또한 AI가 만든 결과에 사실과 다른 내용이 섞일 수 있으므로, 보내거나 게시하기 전에 사람이 다시 확인해야 합니다.

## 사용 전 확인

- [ ] 예시 문구를 내 상황에 맞게 바꿨나요?
- [ ] 이름, 날짜, 숫자가 정확한가요?
- [ ] 꼭 필요한 조건이 빠지지 않았나요?
- [ ] 필요 없는 조건은 지웠나요?
- [ ] 민감한 정보가 들어가 있지 않나요?
- [ ] AI의 결과를 다시 확인했나요?

## 기억할 점

좋은 프롬프트를 처음부터 완벽하게 쓰려고 애쓰지 않아도 됩니다.

준비된 문장에서 내 상황과 다른 부분만 하나씩 바꾸면 됩니다.

작게 고치고, 결과를 확인하고, 필요한 부분을 다시 요청하는 방식으로 사용해 보세요.
