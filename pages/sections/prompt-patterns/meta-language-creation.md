상황: 자격증 공부 (반복하는 학습 요청을 짧은 단축어 명령으로 줄여 쓰기)

매번 "쉽게 설명하고, 일상 비유를 붙이고, 퀴즈 1문제 내 줘"처럼 길게 치는 대신, 대화 초반에 나만의 단축어나 기호 규칙을 약속해 두고 짧게 입력하는 패턴입니다.

---

## 1단계. 패턴 없이 먼저 해보기

실습 방법: 1단계와 2단계는 반드시 **같은 AI 모델의 새 대화 두 개**에서 각각 실행해 비교해 보세요.

단축어 없이 공부할 개념마다 매번 긴 지시문을 반복해서 입력하는 방식을 먼저 겪어 봅니다.

```prompt
title: 1단계 · 패턴 없이 매번 길게 지시하기
description: 개념 하나를 물을 때마다 같은 조건을 매번 풀어서 입력합니다.
---
'트랜잭션의 ACID 속성'을 비전공자 눈높이로 3줄 요약하고, 일상 비유 1개를 붙여 설명해 줘.
```

---

## 2단계. 패턴을 넣어 다시 해보기

대화 시작 시 나만의 단축어 3개를 먼저 정의해 두세요. 그다음부터는 `/개념 트랜잭션`처럼 짧게 치기만 해도 같은 조건의 답이 나옵니다.

```prompt
title: 2단계 · 나만의 단축어 만들기 패턴 적용하기
description: 반복 학습 지시를 짧은 단축어 명령으로 정의하고 바로 테스트합니다.
---
지금부터 이 대화에서는 아래 단축어 규칙을 사용해 줘. 내가 단축어와 주제를 함께 입력하면 지정된 방식대로만 답해 줘.

- /개념 <주제>: 비전공자 눈높이 3줄 요약 + 일상 비유 1개
- /퀴즈 <주제>: 헷갈리기 쉬운 OX 퀴즈 2문제 (정답과 해설은 내가 답한 뒤 공개)
- /비교 <A> vs <B>: 공통점 1줄 + 핵심 차이점 3가지 + 시험 함정 포인트 1줄

이해했으면 바로 첫 테스트로 '/개념 트랜잭션의 ACID 속성'을 실행해 줘.
```

이어서 두 대화에서 같은 새 주제 '데이터베이스 인덱스'를 한 번 더 물어보세요. 1단계 대화에서는 조건을 다시 길게 적어야 하고, 2단계 대화에서는 `/개념 데이터베이스 인덱스` 한 줄만 입력해 비교할 수 있습니다.

---

## 3단계. 두 답변 비교하기

새 대화 두 개에 나온 1단계와 2단계 진행 방식을 나란히 놓고 직접 관찰해 보세요.

- 두 번째, 세 번째 개념을 이어서 물을 때 입력 길이와 출력 일관성은 각각 어떻게 달랐나요?
- 어떤 점이 달라졌나요? 차이가 거의 없다면 어떤 내용이 공통으로 나왔나요?
- 여러 개념을 연속으로 공부하거나 반복 업무를 처리할 때 더 편한 쪽은 어느 쪽이었나요?

---

## 4단계. 패턴 해설

- 한 줄 정의: 사용자가 AI와의 대화에서 쓸 나만의 약어, 명령어, 기호 규칙(메타 언어)을 미리 정의해, 복잡한 지시를 짧고 정확하게 전달하는 패턴입니다.
- 언제 쓰나요: 자격증 개념 정리, 이력서 다듬기, 이메일 톤 변환, 회의록 정리처럼 같은 형태의 요청을 한 대화방에서 여러 번 반복할 때 매우 효율적입니다.
- 핵심 문장 구조:
  - 규칙 선언: "지금부터 내가 [단축어/기호]를 쓰면 [구체적인 의미와 수행 방식]으로 이해해 줘"
  - 목록 정의: 2~4개의 짧은 명령어를 `- 명령어: 동작` 형태로 간결하게 등록
  - 즉시 테스트: "이해했으면 바로 [첫 번째 단축어 예시]를 실행해 줘"

---

## 상황별 실전 예제 (취업 · 이직 · 공부 · 업무)

- 취업 (자소서 문단 다듬기 단축어): "앞으로 이 대화에서 `/임팩트`는 수치가 들어갈 자리를 표시하며 두괄식으로 고치기, `/축약`은 핵심만 남겨 200자 이내로 줄이기, `/꼬리`는 면접관 예상 질문 2개 뽑기로 이해해 줘. 먼저 `/임팩트`로 아래 문단을 고쳐 줘."
- 이직 (채용 공고 분석 단축어): "앞으로 `/핵심`은 공고의 필수 역량 3줄 요약, `/갭`은 내 경력과 비교해 부족한 점 2가지, `/질문`은 면접에서 회사에 역질문할 거리 2개로 이해해 줘. 이해했으면 아래 공고에 `/핵심`을 적용해 줘."
- 공부 (자격증 반복 학습 단축어): "앞으로 `/쉽게`는 중학생 눈높이 3줄 설명, `/함정`은 시험에서 자주 틀리는 오답 포인트 2개, `/암기`는 앞글자나 비유 암기 팁 1개로 이해해 줘. 먼저 `/쉽게 데이터베이스 정규화`를 실행해 줘."
- 업무 (이메일·메신저 톤 변환 단축어): "앞으로 `/정중`은 외부 고객·임원용 정중한 이메일 톤, `/간결`은 슬랙·메신저용 3줄 핵심 공유, `/요청`은 마감 기한과 담당자가 분명한 협조 요청문으로 이해해 줘. 아래 메모에 `/간결`을 적용해 줘."

---

## 5단계. 내 주제로 바꾸기

내가 자주 반복하는 작업 분야를 고르고, 가장 자주 쓰는 단축어 1개의 동작을 직접 정해 보세요.

개인정보 안내: 실명, 연락처, 회사명, 내부 기밀 문서는 입력하지 마세요.

```prompt
title: 5단계 · 나만의 작업 단축어 세트 만들기
description: 반복 업무·학습에 바로 쓸 나만의 단축어 규칙을 정의합니다.
---
작업 분야: [ 취업 자소서·면접 준비 / 이직 공고·경력 분석 / 자격증·시험 공부 / 실무 이메일·문서 작성 ]
내가 추가할 핵심 단축어와 동작: "[내 단축어와 동작 입력]"

지금부터 이 대화에서는 위 단축어와 아래 기본 단축어를 함께 사용해 줘.
- /쉽게: 비전공자 눈높이 3줄 설명
- /점검: 빠진 정보나 약점 2가지 짚기
- /간결: 핵심만 3줄로 압축하기

규칙을 이해했으면 짧은 확인 인사 후, 내가 바로 단축어를 입력할 수 있게 대기해 줘.
```

---

## 6단계. 주의점과 조합

- 주의할 점: 단축어를 한 번에 10개씩 너무 많이 정의하면 나도 헷갈리고 AI도 규칙을 섞어 쓰기 쉽습니다. 자주 쓰는 3~4개만 간결하게 정하고, 자주 쓰는 세트는 `나만의 AI 만들기` (Gemini 스킬/지침서)로 저장해 두면 매번 다시 입력하지 않아도 됩니다.
- 함께 쓰면 좋은 패턴:
  - [출력 틀 지정하기 · Template](/prompt-patterns/template/): 단축어 하나를 실행할 때마다 정해진 출력 틀이 나오도록 결합하면 생산성이 극대화됩니다.
  - [대화 맥락 지정하기 · Context Manager](/prompt-patterns/context-manager/): 긴 대화에서 단축어 규칙이 흐려질 때 맥락 규칙을 다시 상기시켜 일관성을 유지할 수 있습니다.
- 바로 쓰는 실전 연결: 원리는 패턴 연습에서 익히고, 실무에서 바로 복붙할 때는 프롬프트 한 스푼을 활용하세요. → [글 다듬기](/prompt-snippets/refine-text/) · [설명 수준 바꾸기](/prompt-snippets/change-level/)
- 꼭 확인할 점: AI가 만든 결과는 그대로 믿지 말고 반드시 직접 확인하세요. 단축어로 빠르게 만든 초안이라도 중요한 수치, 공식 용어, 대외 발송 문구는 꼭 한 번 더 검토하세요.
