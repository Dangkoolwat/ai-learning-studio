상황: 실무 업무 (반복되는 폴더 정리·파일명 통일 작업을 말로 설명받는 대신 실행 스크립트로 받기)

AI가 "먼저 이 폴더를 만들고, 다음으로 파일 이름을 바꾸세요"처럼 수작업 절차만 길게 알려 주는 대신, 그 단계를 한 번에 처리할 수 있는 자동화 스크립트(엑셀 수식, 파이썬, 셸 명령 등)를 함께 만들게 하는 패턴입니다.

---

## 1단계. 패턴 없이 먼저 해보기

실습 방법: 1단계와 2단계는 반드시 **같은 AI 모델의 새 대화 두 개**에서 각각 실행해 비교해 보세요.

자동화 생성 요청 없이 단순하게 작업 방법만 물어봅니다.

```prompt
title: 1단계 · 패턴 없이 작업 방법만 묻기
description: 자동화 요청 없이 수작업 절차 설명을 요청합니다.
---
매주 월요일마다 프로젝트 폴더 안에 '기획', '디자인', '회의록', '최종본' 하위 폴더를 만들고 날짜를 붙여서 정리하려고 해. 어떻게 하면 좋을까?
```

---

## 2단계. 패턴을 넣어 다시 해보기

결과가 여러 단계의 반복 작업을 포함한다면, 그 과정을 자동으로 수행할 수 있는 단일 스크립트(예: Python 또는 macOS/Windows 명령어)를 함께 생성해 달라고 지시해 보세요.

```prompt
title: 2단계 · 실행 자동화 만들기 패턴 적용하기
description: 반복 작업 절차를 한 번에 실행할 수 있는 안전한 자동화 스크립트로 출력하게 합니다.
---
매주 월요일마다 프로젝트 폴더 안에 'YYYY-MM-DD_주간업무' 폴더와 그 하위 폴더('01_기획', '02_디자인', '03_회의록', '04_최종본')를 만들려고 해.

앞으로 내가 여러 단계의 반복 작업을 요청하면, 수작업 설명으로 끝내지 말고 그 단계를 한 번에 실행할 수 있는 Python 스크립트를 함께 작성해 줘.
기존 파일을 덮어쓰거나 삭제하지 않도록 안전한 조건을 넣고, 실행 전 내가 확인해야 할 사항도 3줄로 정리해 줘.
```

## 3단계. 두 답변 비교하기

새 대화 두 개에 나온 1단계와 2단계 결과물을 나란히 놓고 직접 관찰해 보세요.

- 1단계와 2단계에서 사람이 직접 해야 하는 수작업과 자동 처리되는 부분은 각각 어떻게 달랐나요?
- 어떤 점이 달라졌나요? 차이가 거의 없다면 어떤 안내가 공통으로 나왔나요?
- 매주 반복되는 폴더 정리 업무에 실제로 적용해 보고 싶은 쪽은 어느 쪽이었고, 실행 전 어떤 점을 확인해야겠다고 느꼈나요?

---

## 4단계. 패턴 해설

- 한 줄 정의: AI의 답변에 여러 단계의 실행 절차가 포함될 때, 그 단계를 자동으로 수행할 수 있는 실행 스크립트나 수식을 함께 생성하게 만드는 패턴입니다.
- 언제 쓰나요: 파일 정리, CSV/엑셀 데이터 가공, 반복 문서 템플릿 생성, 개발 환경 세팅처럼 손으로 반복하면 실수하기 쉬운 작업을 자동화하고 싶을 때 유용합니다.
- 핵심 문장 구조:
  - 자동화 지시: "네가 여러 단계의 실행 절차를 제안할 때마다, 그 단계를 자동으로 수행할 수 있는 [언어/도구] 스크립트를 함께 작성해 줘"
  - 안전 조건 지정: "기존 파일을 삭제하거나 덮어쓰지 않도록 안전 장치를 넣고, 실행 전 확인 포인트를 알려 줘"

---

## 상황별 실전 예제 (취업 · 이직 · 공부 · 업무)

- 취업 (지원 기업별 폴더·체크리스트 자동 생성): "지원하는 기업 이름 목록을 넣으면 각 기업별 폴더(자소서, 포트폴리오, 면접준비)와 지원 현황 CSV 초안을 자동으로 만들어 주는 Python 스크립트를 함께 작성해 줘."
- 이직 (경력 자료·포트폴리오 파일명 일괄 정리): "폴더 안의 PDF와 이미지 파일 이름 앞에 '2026_포트폴리오_'를 붙이되, 실제 변경 전에 바뀔 이름 목록만 먼저 미리 보여 주는(Dry-run) 안전 스크립트를 만들어 줘."
- 공부 (단어장·암기 카드 CSV 자동 변환): "내가 붙여 넣는 '용어: 뜻' 메모를 Anki나 엑셀에 바로 가져올 수 있는 UTF-8 CSV 파일로 변환해 주는 Python 스크립트를 작성해 줘."
- 업무 (주간 보고서 초안·엑셀 수식 자동화): "매달 지출 내역 엑셀에서 카테고리별 합계와 전월 대비 증감률을 자동 계산하는 엑셀 수식(또는 구글 시트 수식)과 적용 순서를 한 번에 쓸 수 있게 만들어 줘."

---

## 5단계. 내 주제로 바꾸기

반복해서 손으로 하고 있는 작업을 적고, 내가 쓸 수 있는 도구에 맞춘 자동화 초안을 받아 보세요.

개인정보 안내: 실명, 연락처, 회사명, 내부 서버 주소·계정 정보는 입력하지 마세요.

```prompt
title: 5단계 · 내 반복 작업을 자동화 스크립트로 바꾸기
description: 반복 절차를 내가 다루기 편한 도구의 자동화 코드·수식으로 생성합니다.
---
자동화할 분야: [ 취업 지원 관리 / 이직 자료 정리 / 공부 암기·노트 정리 / 실무 반복 업무 ]
반복하고 있는 작업: "[여기에 매번 손으로 반복하는 작업 입력]"

이 작업을 사람이 일일이 수작업하지 않도록, 한 번에 처리할 수 있는 자동화 초안을 만들어 줘.
원하는 출력 형태: [ 엑셀·구글 시트 수식 / Python 스크립트 / Notion·마크다운 템플릿 자동 생성 ]
기존 데이터를 삭제하거나 덮어쓰지 않는 안전 조건을 반드시 포함하고, 실행 전에 내가 검토해야 할 위험 요소 3가지를 함께 적어 줘.
```

---

## 6단계. 주의점과 조합

- 주의할 점: AI가 만든 스크립트나 명령어는 의도치 않게 파일을 삭제하거나 덮어쓸 위험이 있습니다. 실행하기 전에 반드시 코드 내용을 한 줄씩 확인하고, 중요한 원본 파일은 복사본으로 백업한 뒤 테스트 폴더에서 먼저 시험하세요.
- 함께 쓰면 좋은 패턴:
  - [중간 단계 채우기 · Recipe](/prompt-patterns/recipe/): 먼저 전체 실행 순서를 레시피로 정리한 뒤, 그 단계를 자동화 스크립트로 변환하면 누락이 줄어듭니다.
  - [스스로 점검하게 하기 · Reflection](/prompt-patterns/reflection/): 생성된 자동화 코드에서 파일 손실이나 예외 오류가 발생할 수 있는 부분을 AI가 스스로 점검하게 하세요.
- 바로 쓰는 실전 연결: 원리는 패턴 연습에서 익히고, 실무에서 바로 복붙할 때는 프롬프트 한 스푼을 활용하세요. → [AI 답변 검토하기](/prompt-snippets/review-answers/) · [미리 실패했다고 생각해 보기](/prompt-snippets/pre-mortem/)
- 꼭 확인할 점: AI가 만든 스크립트와 수식은 그대로 믿지 말고 반드시 직접 검토한 뒤 테스트 환경에서 확인하세요. 사내 보안 정책상 외부 스크립트 실행이 제한되는 환경인지도 미리 확인해야 합니다.
