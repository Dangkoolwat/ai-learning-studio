상황: 취업 준비 (이력서 경력·활동 항목을 정해진 틀로 정리하기)

AI가 길고 제멋대로인 줄글을 쓰지 않도록, 내가 원하는 항목과 자리 표시자(Placeholder)가 담긴 출력 틀을 미리 건네주는 패턴입니다.

---

## 1단계. 패턴 없이 먼저 해보기

실습 방법: 1단계와 2단계는 반드시 **같은 AI 모델의 새 대화 두 개**에서 각각 실행해 비교해 보세요.

출력 형식을 지정하지 않고 경험 정리를 부탁해 봅니다.

```prompt
title: 1단계 · 패턴 없이 경험 정리 요청하기
description: 출력 형식 없이 이력서 경력 항목 작성을 요청합니다.
---
카페 아르바이트하면서 재고 발주 실수를 줄인 경험을 이력서에 넣을 수 있게 정리해 줘.
```

---

## 2단계. 패턴을 넣어 다시 해보기

정확한 항목과 순서가 정해진 템플릿을 제공하고, 꺾쇠(< >) 안만 채우도록 지시해 보세요. 여러 경험을 같은 형식으로 통일할 때 특히 강력합니다.

```prompt
title: 2단계 · 출력 틀 지정 패턴 적용하기
description: 정해진 이력서 항목 틀에 맞춰 빈칸만 채우게 합니다.
---
카페 아르바이트하면서 재고 발주 실수를 줄인 경험을 이력서 항목으로 정리해 줘.

내가 제공하는 아래 틀을 그대로 유지하고, 꺾쇠(< >) 안의 내용만 채워 줘. 없는 수치는 지어내지 말고 (확인 필요)로 남겨 줘.

- 활동명: <활동 또는 직무명>
- 핵심 문제: <당시 겪은 문제 1줄>
- 내가 한 행동: <구체적 실행 내용 1~2줄>
- 변화와 성과: <결과 또는 개선 효과 1줄>
- 어필 역량 키워드: <키워드 3개>
```

---

## 3단계. 두 답변 비교하기

새 대화 두 개에 나온 1단계와 2단계 결과물을 나란히 놓고 직접 관찰해 보세요.

- 1단계와 2단계 결과물의 항목 구성, 길이, 가독성은 각각 어떻게 달랐나요?
- 어떤 점이 달라졌나요? 차이가 거의 없다면 어떤 내용이 공통으로 나왔나요?
- 다른 경험 2~3개를 같은 형식으로 통일해 이력서에 옮겨 쓰기 더 편한 쪽은 어느 쪽이었나요?

---

## 4단계. 패턴 해설

- 한 줄 정의: AI가 결과를 출력할 정확한 서식과 항목 틀을 미리 제시해, 빈칸만 채워 넣게 만드는 패턴입니다.
- 언제 쓰나요: 이력서 항목, 회의록, 학습 노트, 주간 업무 보고처럼 매번 같은 형식으로 반복 작성해야 하는 문서를 만들 때 가장 효과적입니다.
- 핵심 문장 구조:
  - 틀 준수 지시: "내가 제공하는 아래 출력 틀을 그대로 유지하고, 꺾쇠(< >) 안의 내용만 채워 줘"
  - 창작 방지 조건: "없는 사실이나 수치는 지어내지 말고 (확인 필요)로 남겨 줘"
  - 템플릿 본문: 항목명과 `<채울 내용 설명>`을 줄바꿈으로 명확히 제시

## 상황별 실전 예제 (취업 · 이직 · 공부 · 업무)

- 취업 (이력서 활동 요약 틀): "내 프로젝트 경험을 아래 틀에 맞춰 정리해 줘. 틀을 바꾸지 말고 없는 수치는 [확인 필요]로 남겨 줘. / - 프로젝트명: [이름] / - 맡은 역할: [역할] / - 해결한 문제: [1줄] / - 결과: [1줄]"
- 이직 (지원 공고 비교 틀): "관심 있는 채용 공고 내용을 아래 틀로 정리해 줘. / - 핵심 직무: [3줄 요약] / - 필수 역량: [목록] / - 내 보유 경험과 겹치는 점: [항목] / - 보완·확인할 점: [항목]"
- 공부 (오답 노트 정리 틀): "방금 틀린 자격증 문제 해설을 아래 틀로 정리해 줘. / - 핵심 개념: [1줄] / - 내가 헷갈린 이유: [1줄] / - 시험 직전 기억할 키워드: [3개] / - 비슷한 함정 예시: [1줄]"
- 업무 (회의록·액션아이템 틀): "아래 회의 메모를 다음 틀로 정리해 줘. 결정되지 않은 내용은 [미확정]으로 표시해 줘. / - 회의 목적: [1줄] / - 확정 사항: [목록] / - 할 일(담당·기한): [목록] / - 다음 확인 사항: [목록]"

## 5단계. 내 주제로 바꾸기

원하는 문서 유형과 정리할 초안을 넣어 나만의 출력 틀 프롬프트를 만들어 보세요.

개인정보 안내: 실명, 연락처, 회사명, 내부 기밀 데이터는 입력하지 마세요.

```prompt
title: 5단계 · 내 상황에 맞춰 출력 틀 지정하기
description: 문서 용도에 맞는 고정 형식으로 초안을 깔끔하게 정리합니다.
---
정리할 문서 용도: [ 이력서 경험 항목 / 이직 공고 비교표 / 공부 오답 노트 / 업무 회의록·보고서 ]
정리할 내용: "[여기에 정리할 메모나 경험 입력]"

아래 출력 틀의 항목과 순서를 그대로 유지하고 꺾쇠(< >) 부분만 채워 줘. 입력에 없는 사실이나 수치는 지어내지 말고 (확인 필요)로 표시해 줘.

- 핵심 요약: <1줄 요약>
- 주요 내용: <핵심 항목 3가지>
- 강조할 포인트 또는 다음 행동: <1~2줄>
- 직접 확인할 항목: <사실 확인이 필요한 부분>
```

---

## 6단계. 주의점과 조합

- 주의할 점: 템플릿에 항목을 너무 많이 넣으면 AI가 빈칸을 채우려고 없는 사실을 지어낼 수 있습니다. "없는 정보는 [확인 필요]로 남기기" 조건을 꼭 함께 쓰세요.
- 함께 쓰면 좋은 패턴:
  - [역할 부여하기 · Persona](/prompt-patterns/persona/): 전문가 역할로 분석하게 한 뒤, 결과를 내가 원하는 고정 틀로 정리시킬 때 궁합이 좋습니다.
  - [사실 확인 목록 뽑기 · Fact Check List](/prompt-patterns/fact-check-list/): 템플릿 마지막 항목에 "직접 확인할 사실 목록"을 고정해 두면 오류를 줄일 수 있습니다.
- 바로 쓰는 실전 연결: 원리는 패턴 연습에서 익히고, 실무에서 바로 복붙할 때는 프롬프트 한 스푼을 활용하세요. → [보기 쉽게 정리하기](/prompt-snippets/format-clearly/) · [STAR 기법](/prompt-snippets/star-framework/)
- 꼭 확인할 점: AI가 만든 결과는 그대로 믿지 말고 반드시 직접 확인하세요. 이력서 수치, 자격 요건, 업무 일정은 원본 자료와 대조해야 합니다.
