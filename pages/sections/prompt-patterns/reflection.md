상황: 취업 준비 (면접 답변 초안을 AI가 스스로 점검하고 허점을 밝히게 하기)

AI가 결과만 던지고 끝내지 않고, 왜 그렇게 답했는지 근거와 숨은 전제, 부족한 지점을 스스로 되돌아보게 만드는 패턴입니다.

---

## 1단계. 패턴 없이 먼저 해보기

실습 방법: 1단계와 2단계는 반드시 **같은 AI 모델의 새 대화 두 개**에서 각각 실행해 비교해 보세요.

근거 설명이나 자기 점검 요청 없이 면접 답변 초안만 만들어 달라고 요청해 봅니다.

```prompt
title: 1단계 · 패턴 없이 면접 답변 요청하기
description: 별도 점검 지시 없이 면접 예상 답변 작성을 요청합니다.
---
"팀원과 의견이 충돌했을 때 어떻게 해결했나요?"라는 면접 질문에 대한 모범 답변을 써 줘.
```

---

## 2단계. 패턴을 넣어 다시 해보기

답변을 만든 뒤 그 안에 깔린 전제와 약점, 면접관이 파고들 만한 빈틈을 AI가 스스로 설명하도록 지시해 보세요.

```prompt
title: 2단계 · 스스로 점검하기 패턴 적용하기
description: 답변의 의도, 가정, 약점과 보완 질문을 AI가 스스로 점검하게 합니다.
---
"팀원과 의견이 충돌했을 때 어떻게 해결했나요?"라는 면접 질문에 대한 답변 초안을 써 줘.

답변을 작성한 뒤, 아래 항목으로 네 답변을 스스로 점검해 줘.
- 이 답변이 좋다고 판단한 근거
- 내 실제 경험을 모르기 때문에 AI가 임의로 가정한 부분
- 실제 면접관이 이 답변을 들었을 때 꼬리 질문으로 지적할 만한 약점 2가지
- 내가 내 실제 경험으로 바꿔 끼워야 할 부분
```

---

## 3단계. 두 답변 비교하기

새 대화 두 개에 나온 1단계와 2단계 답변을 나란히 놓고 직접 관찰해 보세요.

- 두 답변 중 AI가 임의로 가정한 부분이나 약점을 스스로 드러낸 지점은 어디였나요?
- 어떤 점이 달라졌나요? 차이가 거의 없다면 어떤 조언이 공통으로 나왔나요?
- 초안을 내 실제 경험으로 고쳐 쓰는 데 더 도움이 된 쪽은 어느 쪽이었고, 그 이유는 무엇인가요?

---

## 4단계. 패턴 해설

- 한 줄 정의: AI가 답변을 제시할 때 자신의 추론 근거, 숨은 가정, 한계와 약점을 함께 설명하고 스스로 점검하게 만드는 패턴입니다.
- 언제 쓰나요: AI가 준 초안이나 조언을 그대로 써도 될지 확신이 없을 때, 또는 답의 논리적 허점과 숨은 전제를 미리 찾아내고 싶을 때 효과적입니다.
- 핵심 문장 구조:
  - 근거 설명 지시: "네가 그렇게 답한 이유와 판단 근거를 함께 설명해 줘"
  - 가정·한계 점검: "네 답변에 깔린 가정이나 불확실한 부분, 놓친 관점이 무엇인지 스스로 짚어 줘"
  - 보완 포인트 요청: "내가 직접 확인하거나 수정해야 할 부분을 알려 줘"

---

## 상황별 실전 예제 (취업 · 이직 · 공부 · 업무)

- 취업 (면접 답변 자기 점검): "지원 동기 1분 자기소개 초안을 써 줘. 작성 후에는 어떤 근거로 구성했는지, 다른 지원자와 겹칠 만한 흔한 표현은 무엇인지, 내가 직접 보완해야 할 구체적 경험이 어디인지 스스로 점검해 줘."
- 이직 (경력 어필 전략 점검): "운영 직무에서 기획 직무로 이직할 때 강점으로 내세울 포인트 3가지를 제안해 줘. 각 포인트마다 왜 통할지 근거와, 반대로 채용담당자가 의심할 만한 전제·약점을 스스로 짚어 줘."
- 공부 (개념 이해·풀이 점검): "이 문제의 풀이 과정을 설명해 줘. 풀이를 마친 뒤, 단계별로 숨겨진 조건이나 초보자가 가장 많이 실수하는 비약이 없는지 스스로 점검해서 알려 줘."
- 업무 (기획안·보고서 리스크 점검): "아래 신규 이벤트 기획안을 바탕으로 제안 요약을 작성해 줘. 이어서 이 기획안이 성공하기 위해 암묵적으로 깔고 있는 가정 3가지와 실패할 수 있는 약점을 스스로 점검해 줘."

## 5단계. 내 주제로 바꾸기

AI에게 요청할 작업과 점검 기준을 골라, 근거와 한계까지 함께 받아 보세요.

개인정보 안내: 실명, 연락처, 회사명, 내부 기밀 문서는 입력하지 마세요.

```prompt
title: 5단계 · 내 요청에 자기 점검 붙이기
description: 결과물과 함께 근거, 숨은 가정, 약점 점검을 함께 받습니다.
---
분야: [ 취업 면접·자소서 / 이직 전략·경력 정리 / 시험·개념 공부 / 업무 기획·보고서 ]
요청 내용: "[여기에 AI에게 맡길 요청 입력]"

답변을 작성한 뒤, 아래 기준으로 네 답변을 스스로 점검해 줘.
중점 점검 기준: [ 판단 근거와 숨은 가정 밝히기 / 상대방이 지적할 약점·반론 찾기 / 근거·가정·약점·보완할 점 모두 점검 ]
내가 직접 확인하거나 내 경험으로 바꿔야 할 부분도 함께 표시해 줘.
```

---

## 6단계. 주의점과 조합

- 주의할 점: AI가 스스로 점검하더라도 본인이 만든 오류를 100% 잡아내지는 못합니다. 자기 점검은 "판단 근거를 투명하게 드러내 사람이 검토하기 쉽게 만드는 도구"로 활용하고, 최종 판단은 직접 내리세요.
- 함께 쓰면 좋은 패턴:
  - [사실 확인 목록 뽑기 · Fact Check List](/prompt-patterns/fact-check-list/): 자기 점검으로 논리와 가정을 살피고, 사실 확인 목록으로 외부 수치·규정 오류를 함께 잡을 수 있습니다.
  - [역할 부여하기 · Persona](/prompt-patterns/persona/): "깐깐한 팀장 역할로 네 답변을 다시 점검해 줘"처럼 결합하면 훨씬 객관적인 약점 점검이 가능합니다.
- 바로 쓰는 실전 연결: 원리는 패턴 연습에서 익히고, 실무에서 바로 복붙할 때는 프롬프트 한 스푼을 활용하세요. → [AI 답변 검토하기](/prompt-snippets/review-answers/) · [먼저 진단받기](/prompt-snippets/diagnose-first/)
- 꼭 확인할 점: AI가 만든 결과는 그대로 믿지 말고 반드시 직접 확인하세요. 채용 기준, 경력 조언, 업무 의사결정은 실제 현장 기준과 함께 검토해야 합니다.
