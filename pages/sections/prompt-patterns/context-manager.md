상황: 자격증 공부 (몇 주에 걸친 긴 학습 대화에서 고려할 맥락과 뺄 맥락 지정하기)

AI와 여러 번 대화를 주고받다 보면 이전 주제가 섞이거나 방향이 흐려질 때가 많습니다. 이때 "지금부터는 무엇만 고려하고, 무엇은 빼라"고 맥락 경계를 분명히 정해 주는 패턴입니다.

---

## 1단계. 패턴 없이 먼저 해보기

실습 방법: 1단계와 2단계는 반드시 **같은 AI 모델의 새 대화 두 개**에서 각각 실행해 비교해 보세요.

먼저 필기 개념, 실기 오답, 시험 접수 메모가 함께 섞인 가상 학습 메모를 주고, 맥락 제한 없이 정리본을 요청해 봅니다.

```prompt
title: 1단계 · 패턴 없이 학습 메모 정리 요청하기
description: 포함·제외 맥락 지정 없이 섞여 있는 메모 전체로 정리본을 요청합니다.
---
아래 학습 메모를 바탕으로 시험 직전 3분 안에 읽을 분량으로 핵심 정리본을 만들어 줘.

학습 메모:
- 필기 1과목: OSI 7계층은 물리-데이터링크-네트워크-전송-세션-표현-응용 순서.
- 실기 오답 1: SQL에서 WHERE는 그룹화 전 필터, HAVING은 GROUP BY 후 집계 조건 필터 (자꾸 반대로 씀).
- 실기 오답 2: 정규화 2NF는 부분 함수 종속 제거, 3NF는 이행 함수 종속 제거 (예시 구분 헷갈림).
- 시험 접수 메모: 접수 일정을 다시 확인하기.
```

## 2단계. 패턴을 넣어 다시 해보기

같은 AI 모델의 **또 다른 새 대화**를 열고, 완전히 같은 학습 메모와 같은 분량 요청에 **"실기 오답은 포함하고 필기·접수 메모는 제외해 줘"** 한 문장만 더해 실행해 보세요.

```prompt
title: 2단계 · 대화 맥락 지정 패턴 적용하기
description: 같은 메모와 같은 분량 조건에 포함·제외 맥락 한 문장만 더합니다.
---
실기 오답은 포함하고 필기·접수 메모는 제외해 줘.

아래 학습 메모를 바탕으로 시험 직전 3분 안에 읽을 분량으로 핵심 정리본을 만들어 줘.

학습 메모:
- 필기 1과목: OSI 7계층은 물리-데이터링크-네트워크-전송-세션-표현-응용 순서.
- 실기 오답 1: SQL에서 WHERE는 그룹화 전 필터, HAVING은 GROUP BY 후 집계 조건 필터 (자꾸 반대로 씀).
- 실기 오답 2: 정규화 2NF는 부분 함수 종속 제거, 3NF는 이행 함수 종속 제거 (예시 구분 헷갈림).
- 시험 접수 메모: 접수 일정을 다시 확인하기.
```

## 3단계. 두 답변 비교하기

새 대화 두 개에 나온 1단계와 2단계 답변을 나란히 놓고 직접 관찰해 보세요.

- 1단계와 2단계 정리본에 각각 어떤 메모 항목이 남았고, 어떤 항목이 빠졌나요?
- 어떤 점이 달라졌나요? 차이가 거의 없다면 어떤 내용이 공통으로 나왔나요?
- 시험 직전 3분 안에 빠르게 훑어보기에 내게 더 쓸모 있었던 쪽은 어느 쪽이었고, 그 이유는 무엇인가요?

## 4단계. 패턴 해설

- 한 줄 정의: 긴 대화 속에서 AI가 답변에 반영해야 할 맥락(포함)과 무시해야 할 맥락(제외)을 명시적으로 통제하는 패턴입니다.
- 언제 쓰나요: 한 대화방에서 여러 날에 걸쳐 공부·이직 준비·업무 프로젝트를 이어갈 때, 이전 대화의 잡음이 섞이거나 방향을 전환하고 싶을 때 씁니다.
- 핵심 문장 구조:
  - 포함 맥락 지정: "앞으로 이 대화에서는 [계속 반영할 기준·대상]만 고려해 줘"
  - 제외 맥락 지정: "[이미 끝난 주제·제외할 조건]은 고려하지 마"
  - 초기화 옵션: 필요하면 "이전 대화의 조건은 모두 잊고 지금부터 새로운 조건으로 시작하자"라고 선언

## 상황별 실전 예제 (취업 · 이직 · 공부 · 업무)

- 취업 (지원 기업별 맥락 분리): "지금부터는 B사 마케팅 직무 지원 기준으로만 답해 줘. 앞서 이야기한 A사 영업 직무 조건과 이전 자소서 초안은 모두 제외하고, B사 공고의 핵심 키워드만 고려해서 문단을 다듬어 줘."
- 이직 (면접 단계별 맥락 전환): "1차 실무 면접 준비는 끝났어. 지금부터는 2차 임원 면접 맥락만 고려해 줘. 기술 세부 질문은 빼고, 커리어 방향성·협업 태도·조직 적합성 관점에서만 질문과 피드백을 줘."
- 공부 (취약 파트 집중 모드): "이번 주에는 3과목 기출 오답만 집중할 거야. 이전에 다룬 1·2과목 개념과 기초 용어 설명은 생략하고, 3과목 계산 문제 풀이 실수 줄이기 맥락만 유지해 줘."
- 업무 (보고 대상별 맥락 전환): "방금 정리한 프로젝트 분석 내용을 경영진 보고용으로 바꿀 거야. 개발 세부 구현 과정과 내부 시행착오 내용은 제외하고, 일정·예산·기대 효과 맥락만 고려해서 5줄 요약으로 다시 써 줘."

## 5단계. 내 주제로 바꾸기

지금 이어가고 있는 대화에서 꼭 지킬 맥락과 뺄 맥락을 직접 지정해 보세요.

개인정보 안내: 실명, 연락처, 회사명, 내부 기밀 자료는 입력하지 마세요.

```prompt
title: 5단계 · 내 대화의 포함·제외 맥락 지정하기
description: 긴 대화에서 유지할 기준과 무시할 내용을 분리해 답변 초점을 맞춥니다.
---
대화 분야: [ 취업 준비 / 이직 준비 / 자격증·시험 공부 / 실무 업무 진행 ]
지금 요청할 작업: "[여기에 지금 필요한 작업 입력]"

지금부터 답변할 때는 아래 맥락 규칙을 지켜 줘.
- 반드시 유지할 맥락: [ 현재 단계의 핵심 목표와 대상 독자 / 내가 지정한 제약 조건과 톤 / 핵심 목표·독자·제약 조건 모두 ]
- 제외할 맥락: 이전 대화에서 이미 끝난 주제, 일반론적인 서론·마무리 멘트
```

## 6단계. 주의점과 조합

- 주의할 점: 대화가 아주 길어지면 AI가 초반에 정한 맥락 규칙을 서서히 잊을 수 있습니다. 대화가 10~15턴 이상 길어졌거나 주제가 완전히 바뀌었다면, 핵심 맥락만 요약해 새 대화방으로 옮기는 편이 훨씬 정확합니다.
- 함께 쓰면 좋은 패턴:
  - [역할 부여하기 · Persona](/prompt-patterns/persona/): "임원 면접관 역할 + 2차 면접 맥락만 유지"처럼 결합하면 대화 일관성이 크게 높아집니다.
  - [출력 틀 지정하기 · Template](/prompt-patterns/template/): 맥락을 고정한 뒤 매번 같은 요약 틀로 정리하게 하면 장기 프로젝트 기록에 유용합니다.
- 바로 쓰는 실전 연결: 원리는 패턴 연습에서 익히고, 실무에서 바로 복붙할 때는 프롬프트 한 스푼과 바로 써보기를 활용하세요. → [이어서 작업하기](/prompt-snippets/continue-work/) · [AI 작업 이어가기](/ready-to-use/universal-handoff/)
- 꼭 확인할 점: AI가 만든 결과는 그대로 믿지 말고 반드시 직접 확인하세요. 긴 대화에서 이전 조건이 섞여 잘못된 수치나 내용이 들어가지 않았는지 마지막에 한 번 더 살펴보세요.
