상황: 취업 준비 (면접 예상 질문과 핵심 답변 포인트를 원하는 만큼 같은 형식으로 계속 뽑아내기)

같은 형식의 예시, 연습 문제, 아이디어 카드를 여러 번 뽑아야 할 때 매번 긴 지시를 다시 입력하지 않고, "다음" 또는 "더" 한 마디만으로 계속 이어서 생성하게 만드는 패턴입니다.

---

## 1단계. 패턴 없이 먼저 해보기

실습 방법: 1단계와 2단계는 반드시 **같은 AI 모델의 새 대화 두 개**에서 각각 실행해 비교해 보세요.

반복 생성 규칙 없이 몇 개만 요청해 봅니다.

```prompt
title: 1단계 · 패턴 없이 일회성으로 몇 개만 요청하기
description: 반복 규칙 없이 면접 질문 3개만 요청합니다.
---
신입 서비스 기획자 면접 예상 질문 3개와 답변 포인트 알려 줘.
```

---

## 2단계. 패턴을 넣어 다시 해보기

고정된 출력 형식, 한 번에 생성할 개수(예: 3개씩), 계속 이어 가는 신호("다음")와 중단 신호("그만")를 한 번에 약속해 보세요. 이전과 겹치지 않는 새 항목을 원하는 만큼 편하게 뽑아낼 수 있습니다.

```prompt
title: 2단계 · 같은 형식 계속 생성하기 패턴 적용하기
description: 출력 형식과 반복·중단 규칙을 정해 중복 없이 원하는 만큼 계속 생성합니다.
---
지금부터 신입 서비스 기획자 면접 예상 질문 카드를 계속 생성해 줘.

반복 생성 규칙:
1. 한 번에 3개씩 생성하고, 내가 "다음"이라고 입력할 때마다 이전과 겹치지 않는 새로운 3개를 같은 형식으로 계속 만들어 줘.
2. 내가 "그만"이라고 입력하면 생성을 멈춰 줘.
3. 모든 카드는 아래 형식을 그대로 지켜 줘.
   - 질문: <면접 질문 1줄>
   - 면접관 의도: <확인하려는 역량 1줄>
   - 답변 팁: <꼭 넣어야 할 요소 1줄>

지금 첫 번째 3개부터 시작해 줘.
```

---

## 3단계. 두 답변 비교하기

새 대화 두 개에 나온 1단계와 2단계 결과를 나란히 놓고 직접 관찰해 보세요.

- 추가 질문을 계속 뽑아낼 때 출력 형식의 일관성과 중복 여부는 각각 어떻게 달랐나요?
- 어떤 점이 달라졌나요? 차이가 거의 없다면 어떤 항목이 공통으로 나왔나요?
- 면접 질문 뱅크나 연습 문제를 여러 묶음 만들 때 더 편한 쪽은 어느 쪽이었나요?

---

## 4단계. 패턴 해설

- 한 줄 정의: 사용자가 프롬프트를 매번 다시 입력하지 않아도, 정해진 형식과 규칙에 따라 새로운 결과물을 중단 신호 전까지 계속 생성하게 만드는 패턴입니다.
- 언제 쓰나요: 면접 질문 뱅크 만들기, 자격증 연습 문제 대량 생성, 마케팅 카피·제목 후보 뽑기, 테스트용 더미 데이터 만들기처럼 "같은 형식의 다양한 후보가 많이 필요할 때" 효과적입니다.
- 핵심 문장 구조:
  - 지속 생성 지시: "지금부터 [주제]를 아래 형식에 맞춰 계속 생성해 줘"
  - 배치·중복 규칙: "한 번에 [N개]씩 만들고, 내가 '다음'이라고 하면 이전과 겹치지 않게 이어서 생성해 줘"
  - 중단 조건: "내가 '그만'이라고 말하면 멈춰 줘"

---

## 상황별 실전 예제 (취업 · 이직 · 공부 · 업무)

- 취업 (면접 예상 질문 뱅크 생성): "신입 데이터 분석가 면접 질문을 '질문 / 출제 의도 / 핵심 키워드' 형식으로 한 번에 3개씩 계속 만들어 줘. '다음'을 치면 이전과 겹치지 않는 새 질문 3개를 주고, '그만'을 치면 멈춰 줘."
- 이직 (경력 면접 꼬리 질문·반론 연습): "3년 차 이직 사유와 성과 검증 관련 꼬리 질문을 한 번에 3개씩 계속 생성해 줘. 형식은 '압박 질문 / 숨은 의도 / 방어 포인트'로 고정하고, '다음'마다 새 주제로 이어 가 줘."
- 공부 (자격증 OX 연습 문제 무한 생성): "정보처리기사 기출 범위에서 헷갈리기 쉬운 OX 문제를 한 번에 5문제씩 계속 내 줘. 내가 답을 보내면 채점과 1줄 해설을 주고, '다음'을 치면 겹치지 않는 새 5문제를 이어서 내 줘."
- 업무 (SNS·뉴스레터 제목 후보 계속 뽑기): "2030 직장인 대상 생산성 뉴스레터 제목 후보를 '제목 / 타깃 감정 / 클릭 포인트' 형식으로 한 번에 5개씩 계속 생성해 줘. '다음'을 칠 때마다 톤을 조금씩 바꿔서 중복 없이 제안해 줘."

---

## 5단계. 내 주제로 바꾸기

계속 뽑아 보고 싶은 주제와 한 번에 받을 개수를 골라 반복 생성을 시작해 보세요.

개인정보 안내: 실명, 연락처, 회사명, 내부 기밀 자료는 입력하지 마세요.

```prompt
title: 5단계 · 내 주제로 같은 형식 계속 생성하기
description: 지정한 형식과 개수 단위로 중복 없이 결과물을 이어서 생성합니다.
---
분야: [ 취업 면접 질문 / 이직 예상 질문·체크리스트 / 자격증 연습 문제 / 업무 카피·아이디어 후보 ]
생성할 주제: "[여기에 계속 뽑고 싶은 주제 입력]"

지금부터 위 주제로 결과물을 계속 생성해 줘.
한 번에 생성할 개수: [ 3개씩 / 5개씩 ]
내가 "다음"이라고 입력하면 이전과 겹치지 않는 새로운 항목을 같은 형식으로 이어서 만들고, "그만"이라고 입력하면 멈춰 줘.
출력 형식은 '번호 / 핵심 내용 / 실전 활용 포인트 1줄'로 고정해 줘. 지금 첫 묶음부터 시작해 줘.
```

## 6단계. 주의점과 조합

- 주의할 점: 한 번에 너무 많은 양(예: 50개)을 요청하면 뒤로 갈수록 품질이 떨어지거나 비슷한 표현이 반복됩니다. 3~5개 단위로 끊어 받고, "중복 금지"와 "그만" 중단 조건을 꼭 함께 쓰세요.
- 함께 쓰면 좋은 패턴:
  - [출력 틀 지정하기 · Template](/prompt-patterns/template/): 매번 생성되는 항목의 서식을 단단히 고정할 때 함께 쓰면 일관성이 유지됩니다.
  - [대화 맥락 지정하기 · Context Manager](/prompt-patterns/context-manager/): 3~4번째 묶음에서 난이도를 높이거나 특정 관점으로 방향을 틀고 싶을 때 맥락을 조절하세요.
- 바로 쓰는 실전 연결: 원리는 패턴 연습에서 익히고, 실무에서 바로 복붙할 때는 프롬프트 한 스푼을 활용하세요. → [다양한 아이디어 얻기](/prompt-snippets/get-ideas/) · [이어서 작업하기](/prompt-snippets/continue-work/)
- 꼭 확인할 점: AI가 만든 결과는 그대로 믿지 말고 반드시 직접 확인하세요. 특히 시험 연습 문제나 사실 기반 문구는 오답이 섞일 수 있으므로 공식 자료와 대조해야 합니다.
