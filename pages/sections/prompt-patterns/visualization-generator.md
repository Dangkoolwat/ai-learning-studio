상황: 이직 준비 (복잡한 이직 의사결정 흐름을 글 대신 한눈에 보이는 Mermaid 도표로 만들기)

텍스트 기반 AI가 그림을 직접 깔끔하게 그리기 어려울 때, 도표 제작 도구(Mermaid, PlantUML, 차트 코드, 이미지 생성 프롬프트 등)에 바로 넣을 수 있는 시각화 입력문을 생성하게 하는 패턴입니다.

---

## 1단계. 패턴 없이 먼저 해보기

실습 방법: 1단계와 2단계는 반드시 **같은 AI 모델의 새 대화 두 개**에서 각각 실행해 비교해 보세요.

시각화 도구 형식 없이 말로만 설명해 달라고 요청해 봅니다.

```prompt
title: 1단계 · 패턴 없이 의사결정 흐름 묻기
description: 도표 형식 지정 없이 이직 결정 기준을 글로만 설명받습니다.
---
지금 회사에 남을지, 이직을 준비할지, 사내 직무전환을 신청할지 결정하는 판단 흐름을 정리해 줘.
```

---

## 2단계. 패턴을 넣어 다시 해보기

줄글 대신 Mermaid 순서도(Flowchart) 코드를 생성하도록 지시해 보세요. 생성된 코드는 ChatGPT·Gemini의 미리보기(Canvas)나 웹 도구(mermaid.live)에 붙여 넣으면 즉시 깔끔한 도표로 변환됩니다.

```prompt
title: 2단계 · 도표·그림 입력 생성 패턴 적용하기
description: 복잡한 의사결정 흐름을 바로 시각화할 수 있는 Mermaid 순서도 코드로 생성합니다.
---
지금 회사에 남을지, 외부 이직을 준비할지, 사내 직무전환을 신청할지 결정하는 판단 흐름을 정리해 줘.

줄글로만 설명하지 말고, 바로 도표로 렌더링할 수 있는 Mermaid flowchart TD 코드를 생성해 줘.
조건 분기(연봉·성장 만족도, 사내 이동 가능 여부, 준비 기간 확보 여부)는 6~8개 노드 이내로 간결하게 구성하고, 각 노드의 라벨은 특수문자 오류가 나지 않게 큰따옴표로 감싸 줘.
```

---

## 3단계. 두 답변 비교하기

새 대화 두 개에 나온 1단계 줄글과 2단계 Mermaid 도표(미리보기 또는 mermaid.live 확인 결과)를 나란히 놓고 직접 관찰해 보세요.

- 여러 갈래의 이직 판단 조건이 두 결과물에서 각각 얼마나 한눈에 들어왔나요?
- 어떤 점이 달라졌나요? 차이가 거의 없다면 어떤 판단 기준이 공통으로 나왔나요?
- 다른 사람에게 공유하거나 발표 자료에 넣기에 더 적합한 쪽은 어느 쪽이었나요?

---

## 4단계. 패턴 해설

- 한 줄 정의: 텍스트 설명만으로 전달하기 어려운 구조를, 별도의 시각화 도구(Mermaid, 차트 도구, 이미지 생성 AI 등)가 바로 그릴 수 있는 입력 코드나 묘사문으로 생성하게 만드는 패턴입니다.
- 언제 쓰나요: 의사결정 트리, 학습 로드맵, 업무 프로세스 순서도, 발표용 인포그래픽 초안처럼 "글보다 그림 한 장이 10배 빠른 상황"에서 활용합니다.
- 핵심 문장 구조:
  - 도구 지정: "내 설명을 바탕으로 [Mermaid / 마인드맵 / 이미지 생성 프롬프트]용 입력을 생성해 줘"
  - 구조 제약: "노드 수는 8개 이내로 간결하게, 한국어 라벨은 큰따옴표로 감싸 줘"
  - 확인 방법 안내: 생성된 Mermaid 코드는 ChatGPT·Gemini의 코드 미리보기(Canvas)나 브라우저의 mermaid.live 에디터에 붙여 넣어 이미지(PNG/SVG)로 저장해 활용합니다.

---

## 상황별 실전 예제 (취업 · 이직 · 공부 · 업무)

- 취업 (자기소개서 경험 구조도): "내 프로젝트 경험 3가지가 지원 직무 핵심 역량 2가지와 어떻게 연결되는지 한눈에 보이게 Mermaid flowchart LR 코드로 만들어 줘. 포트폴리오 첫 장 도표로 쓸 거야."
- 이직 (커리어 선택 의사결정 트리): "외부 이직, 사내 직무전환, 현직 유지 중 선택하는 기준을 Mermaid flowchart TD 코드로 그려 줘. 각 분기 조건은 '예 / 아니오'로 명확히 나눠 줘."
- 공부 (자격증 개념 관계도·로드맵): "데이터베이스 정규화(1NF -> 2NF -> 3NF -> BCNF)의 단계별 조건과 예시를 한눈에 외울 수 있게 Mermaid flowchart TD 코드로 정리해 줘."
- 업무 (신규 업무 프로세스 순서도): "고객 문의 접수 -> 1차 분류 -> 담당자 배정 -> 처리 완료 -> 만족도 조사 흐름과 예외 분기(긴급 장애)를 Mermaid sequenceDiagram 또는 flowchart 코드로 작성해 줘."

---

## 5단계. 내 주제로 바꾸기

시각화하고 싶은 내용과 원하는 도표 형식을 골라 바로 Mermaid 입력 코드를 만들어 보세요.

개인정보 안내: 실명, 연락처, 회사명, 내부 시스템 구조 기밀은 입력하지 마세요.

```prompt
title: 5단계 · 내 내용을 Mermaid 도표 코드로 바꾸기
description: 복잡한 글이나 계획을 한눈에 보는 도표 입력 코드로 변환합니다.
---
분야: [ 취업 포트폴리오 정리 / 이직 의사결정 / 자격증 개념·로드맵 / 실무 업무 프로세스 ]
도표로 만들고 싶은 내용: "[여기에 도표로 정리할 내용이나 흐름 입력]"

위 내용을 줄글 대신 바로 시각화할 수 있는 Mermaid 코드로 작성해 줘.
도표 유형: [ 위에서 아래로 흐르는 순서도 (flowchart TD) / 왼쪽에서 오른쪽 로드맵 (flowchart LR) / 주체 간 주고받는 절차도 (sequenceDiagram) ]
노드는 핵심만 6~10개 이내로 간결하게 정리하고, 한글 라벨에 특수문자 오류가 생기지 않도록 큰따옴표로 감싸 줘.
```

---

## 6단계. 주의점과 조합

- 주의할 점: Mermaid 코드에 괄호나 콜론 같은 특수문자가 따옴표 없이 들어가면 렌더링 문법 오류가 날 수 있습니다. 오류가 나면 에러 문구를 그대로 AI에게 붙여 넣고 "문법 오류를 고쳐 줘"라고 요청하세요. 이 사이트 자체에서는 Mermaid를 직접 렌더링하지 않으므로, ChatGPT·Gemini의 미리보기 기능이나 mermaid.live에 붙여 넣어 결과를 확인하세요.
- 함께 쓰면 좋은 패턴:
  - [중간 단계 채우기 · Recipe](/prompt-patterns/recipe/): 먼저 빠진 실행 단계를 레시피로 완성한 뒤, 그 절차를 Mermaid 순서도로 시각화하면 완성도가 높습니다.
  - [출력 틀 지정하기 · Template](/prompt-patterns/template/): 도표 코드와 함께 "도표 아래에 3줄 요약"을 고정 틀로 받으면 발표 자료에 바로 쓰기 좋습니다.
- 바로 쓰는 실전 연결: 원리는 패턴 연습에서 익히고, 실무에서 바로 복붙할 때는 프롬프트 한 스푼을 활용하세요. → [보기 쉽게 정리하기](/prompt-snippets/format-clearly/) · [결과물 다양하게 재활용하기](/prompt-snippets/reuse-content/)
- 꼭 확인할 점: AI가 만든 도표 코드는 내용이 빠지거나 화살표 방향이 뒤바뀔 수 있으므로, 시각화한 이미지를 반드시 눈으로 검토한 뒤 발표·보고 자료에 사용하세요.
