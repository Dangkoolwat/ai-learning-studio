# 웹 접근성 및 성능 가이드라인

이 문서는 **AI Learning Studio** 프로젝트의 키보드 접근성, ARIA 표준, 포커스 관리 및 반응형/성능 준수 사항을 다룹니다.

---

## 1. 웹 접근성 (Accessibility First)

### 키보드 및 포커스 관리
- 모든 상호작용 요소(버튼, 링크, 폼 필드)는 키보드로 접근 및 조작이 가능해야 합니다.
- 포커스 표시(Focus outline)를 대체 스타일 지정 없이 시각적으로 제거해서는 안 됩니다.
- 현재 선택된 메뉴/페이지는 `aria-current="page"`를 명시합니다.
- 드로어/모달을 닫을 경우 포커스를 이전 요소로 복원하고, `Escape` 키 닫기를 지원합니다.

### ARIA 및 스크린리더 대응
- 펼침/접힘 상태 요소에는 `aria-expanded`를 제공합니다.
- 비동기 알림 메시지나 생성 결과는 `aria-live` 영역으로 알립니다.
- 폼 컨트롤 요소에는 상응하는 `<label>`을 반드시 제공합니다.
- 의미 있는 이미지에는 적절한 `alt` 텍스트를 제공하고, 장식용 이미지는 `alt=""`로 설정합니다.

### 모바일 및 사용자 설정 대응
- **320px 최저 해상도**: 320px 모바일 화면에서도 깨짐 없이 조작 가능해야 합니다.
- `prefers-reduced-motion` 및 고대비 모드를 존중합니다.

---

## 2. 성능 규칙 (Performance & Minimal Asset)

- 브라우저 표준 API(Vanilla JS)를 우선 사용하고 외부 고용량 라이브러리 도입을 자제합니다.
- 첫 화면에 필요하지 않은 비초기 이미지는 `loading="lazy"` 속성을 사용합니다.
- 긴 프롬프트 텍스트나 코드가 화면 밖으로 넘치지 않도록 적절한 CSS overflow 처리를 적용합니다.
