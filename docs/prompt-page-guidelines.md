# 프롬프트 페이지 유형 가이드라인

이 문서는 **AI Learning Studio** 프로젝트에서 사용하는 3가지 정식 프롬프트 페이지 유형과 세부 구현 규칙을 다룹니다.

---

## 1. 프롬프트 페이지 유형 개요

프로젝트에서는 사용자 승인 없이 새 페이지 유형을 추가하지 않으며, 오직 다음 3가지 유형만 사용합니다.

1. `static-prompt`
2. `prompt-builder`
3. `practice-timeline`

---

## 2. 프롬프트 본질 및 미리보기 노출 철칙 (Source of Truth)

모든 프롬프트 UI는 다음 2가지 본질적 구분에 따라 엄격히 동작하며, 불필요한 미리보기 상자를 남발하지 않습니다.

1. **그냥 프롬프트 (Standard Static Prompt)**:
   - **본질**: 별도 사용자 조건 설정 없이, 완성된 최적의 프롬프트를 있는 그대로 읽고 직관적으로 복사하는 프롬프트.
   - **UI 규칙**: 불필요한 미리보기 박스(`✨ 완성된 프롬프트`)를 **절대 렌더링하지 않으며**, 본문 카드 하단 `footer`에 바로 **[프롬프트 복사]** 버튼을 직접 배치함.

2. **설정에서 그 값을 받아서 바로 반영하는 프롬프트 (Configurable Dynamic Prompt)**:
   - **본질**: 사용자가 폼/드롭다운 옵션을 고르거나 텍스트 조건(인라인 태그 칩 등)을 입력하면, 그 변경된 값을 실시간으로 받아 바로 조합해 주는 프롬프트.
   - **UI 규칙**: 오직 조절 태그나 빌더 필드가 존재하는 경우에만 하단에 **`✨ 완성된 프롬프트 (실시간 미리보기)` 독립 카드**가 동적으로 노출되어 실시간 조립 결과와 복사 기능을 제공함.

---

## 3. 유형별 명세 및 규칙

### A. `static-prompt`
- **목적**: 완성된 최적의 프롬프트를 바로 확인하고 복사할 수 있는 정적 페이지.
- **특징 및 인라인 스마트 콤보박스 규칙**:
  - 프롬프트 본문 텍스트 내 `[ 선택지1 / 선택지2 / 선택지3 ]` 포맷 사용 시, 브라우저가 자동 파싱하여 **드롭다운 선택과 직접 텍스트 입력(자유 타이핑)을 동시에 지원하는 인라인 스마트 태그 칩**으로 자동 전환됨.
  - 단, 대괄호 묶음이 단독으로 한 줄을 차지하면 섹션 헤더(예: `[작성 지침]`)로 오인되어 칩으로 변환되지 않으므로, 레이블과 같은 줄에 두거나(`- 목적: [선택지]`) **자유 텍스트 입력 필드의 경우 반드시 양쪽에 따옴표를 추가(`"[텍스트 입력]"`)**하여 옵션 칩으로 정상 제공되게 해야 함.
  - 사용자가 선택하거나 타이핑한 커스텀 값이 반영된 정돈된 최종 프롬프트가 **[프롬프트 복사]** 버튼을 통해 클립보드에 원형 복사됨.
  - 복사 버튼(`CopyButton`) 및 외부 AI 열기(`ExternalAiActions`) 기능 제공.

### B. `prompt-builder`
- **목적**: 사용자가 입력한 조건/선택지를 조합하여 상황 맞춤형 프롬프트를 즉시 조립하는 페이지.
- **흐름**:
  ```text
  입력·선택 → 프롬프트 만들기 → 결과 확인 → 복사 → ChatGPT/Gemini 열기
  ```
- **핵심 규칙**:
  - **외부 AI API를 직접 호출하지 않습니다.** (클라이언트 사이드 문자열 템플릿 조합 방식 사용)
  - 빈 선택 필드는 결과 조합 시 자동으로 생략합니다.
  - 사용자가 입력하지 않은 사실을 임의로 지어내지 않습니다(환각 금지).
  - 결과물은 사용자가 직접 수정 및 복사할 수 있어야 합니다.
  - 외부 AI 연결 시 "자동 입력되는 것이 아니며, 복사 후 붙여넣어야 함"을 명확히 안내합니다.

### C. `practice-timeline`
- **목적**: 단계별로 AI 프롬프트 활용법을 실습하며 변화를 관찰하는 세로형 타임라인 페이지.
- **특징**:
  - 세로형 연속 흐름 페이지 (Wizard, Tab, Slide UI 형태 사용 금지).
  - JSON 배열 데이터를 기반으로 정적 HTML 생성.
- **단계별 포함 요소**:
  - 단계 제목, 학습 포인트, 프롬프트, 복사 버튼, 설명, 변경점(무엇이 달라졌는지), 예상 결과.
  - 마지막 최종 완성 프롬프트는 시각적으로 명확히 강조 표시.
