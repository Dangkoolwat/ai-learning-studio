# 코딩 스타일 및 코드 수정 정책

이 문서는 **AI Learning Studio** 프로젝트에서 자바스크립트, 파이썬, CSS를 작성하거나 기존 코드를 수정할 때 지켜야 할 가이드라인입니다.

---

## 1. 언어별 코딩 스타일

### JavaScript (ES Modules)
- ES Module (`import` / `export`)을 사용하며 이름 있는 export(named export)를 선호합니다.
- 기본적으로 `const`를 사용하고, 값이 재할당되는 변수에만 `let`을 사용합니다.
- 비동기 처리에는 `async`/`await`를 사용합니다.
- 동적 DOM 생성 시 긴 HTML 문자열 대입 대신 DOM API 또는 안전한 `textContent`를 사용합니다.
- 새 전역 변수를 생성하지 않습니다.

### Python (Build Script)
- Python 표준 라이브러리를 우선 사용합니다 (`pathlib` 사용 권장).
- 빌드/생성/검증의 책임을 명확히 분리합니다.
- 오류가 발생할 경우 적절한 오류 메시지와 함께 종료 코드 `1`로 빌드를 중단합니다.

### CSS
- BEM 또는 명확한 kebab-case 클래스명을 사용합니다.
- 임의의 하드코딩 색상 대신 테마 토큰(CSS 변수)을 활용합니다.
- 320px, 태블릿, 데스크톱 레이아웃 반응성을 보장합니다.

---

## 2. 수술적 수정 원칙 (Surgical Edit Rules)

- **최소 범위 수정**: 요청받은 목적을 달성하는 최소한의 코드만 수정합니다.
- **불필요한 리팩터링 금지**: 요청받지 않은 코드 포맷팅 변경, 변수 재이름 지정, 불필요한 추상화 추가를 금지합니다.
- **주석 및 계약 유지**: 기존 코드 주석, 안전 검증문, 에러 핸들링 코드를 무단 삭제하지 않습니다.
- **생성 파일 수정 금지**: `dist/` 하위 결과물이나 Python이 자동 생성하는 테마 CSS/JSON을 직접 수정하지 말고 원본 템플릿/데이터를 수정합니다.

---

## 3. 작업 결과 기록 (Work Logging)

- 코드 수정이 포함된 작업 완료 시 `agent-log/YYYY-MM-DD-모델이름/progress-log.md` 파일 하나로 정리하여 작업 내용과 검증 결과를 기록합니다.
